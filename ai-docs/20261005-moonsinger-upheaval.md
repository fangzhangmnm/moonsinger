## 3. 设计拍板（user 原话）

## 6. AI 的读法（未拍板）

1. **简谱 + 数字键盘 ≈ 原来的心智模型**：08-18 定的起名哲学是「nokia的彩铃编辑器」。Nokia 作曲器本来就是用数字键 1–7 输音符、0 输休止——几乎就是简谱。所以「简谱 + 数字键盘」可能不是新方向，而是把最初的心智模型做彻底。（Nokia 键位细节待 peek 核实。）
2. **简谱天生是唱歌的记法**：首调——转调只改「1=C」一处，不碰黑键（user 08-18 说过怕转调和多黑键）；「-」和下划线是离散时值（治「piano roll 不知道拖多长，总是差两倍」）；歌词一字一音写在音符下面，是中文儿歌本的原生排版。user 平时在聊天里写旋律就是这个格式（如 `65 1- | 1- 2-`）。
3. **《小兔子乖乖》样张里的结构**（AI 看图描述）：头部「1 = C　2/4　中速　民间儿歌」；四行谱，下划线 = 八分音符，带连音弧和高音点；每行下面两行歌词 = 两段词共用一条旋律；词前标角色——（大灰狼唱）/（兔妈妈唱）/（小兔子唱）。即：一首儿歌本身就有「谁在唱哪一段」，是对唱。
4. **排练室以她为圆心**：有了歌手，舞台就有中心；伴奏乐器围着她摆，远近 / 左右 = 混响 / pan。物化可能只需要一张俯视图，不需要 live2d。
