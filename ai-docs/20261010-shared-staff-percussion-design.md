## 1. 合租（几位歌手画在同一行谱上）

- **有主人**：一位歌手（房客）挂在另一位（主人）的谱线上，例：钢琴的小花挂在钢琴上。⚑ `score.json parts[]` 加可选 `host: <partId>`。
- **两种房客**：
  - **(a) 自己有轨**：自己的歌手 / 混音台卡片 / 乐器 / 表情 / 歌词，只是画在主人那行。和声、鼓件用这个。**先做这种。**
  - **(b) 纯记谱**：主人的第二个声部——用主人的乐器、走主人那条轨（混音台没有自己的卡片）。= (a) + 「从主人那儿出声」。
- **表情**：各管各的（user「合租表情是各管各的」）。跟着音符的（演奏法、音头）照画在那个音上；跟着谱子的（力度、渐强渐弱）——合租那一行上**房客的不画**，不按「上声部写上面、下声部写下面」硬放（user「不同意，会confusion…关键是宁缺误骗/obfuscate」「表情不是跟着音符吗？我们现在应该只有跟着谱子的和跟着音符的两种articulation」）。
- **排序**：房客紧跟在主人后面；挪主人 = 一家一起挪（user「排序同意」）。
- **折叠的名字**：谱号左边写这一行上所有人的名字。
- **画法 = 先做一个看个大概的**（user「我的想法就是先做一个看上去大概的，因为这个representation本来就是有一个nonzero kernel的，ambiguity没关系，让人看个热闹就行了。主要就是总览监视用。所以撞一起就撞」）：
  - 符干照每个音自己的规矩（不按声部写死上下；user「两位 = 第一位符干朝上…也不同意，还是智能。关键是两者不一定一个是高音一个是低音」）；
  - 撞在一起就撞，不做避让；
  - 先不着色（user「先不建议着色」）。

## 2. 鼓、大炮：不分音高的「一下」

- **歌** = 音高 + 时值 + 字；长短、连不连都有意义。**鼓** = 什么时候 + 哪个声音 + 多响；「音高」只是挑哪个声音，时值没意义（采样自己响到完）。**大炮**也是这样——一下、尾巴很长的音效——**本质上就是鼓**，和歌不是一类。
- **做法**：乐器（休息室候选）的元数据写「不分音高」+ 鼓谱表（谱上哪一线 → 哪个采样）⚑；谱上那个位置 = 挑哪个声音、不管写的音高；录音房当「一下」放（不管时值）。一套鼓可以是**一位歌手**（MuseScore 的 drumset、DAW 一条鼓轨的做法），各个鼓件在谱上各占一线；要各自混音再拆成合租的房客（DAW 的「分轨输出」）。
- **性能**：几十位小歌手不怕——录音房的开销跟正在响的声音走，不跟轨数；卡片多了靠混音台的固定卡片 / 全屏看。
- **「大炮」= 所有音效的代称**（user「canon is a joke. 这首歌不用literally canon，我用这个代指所有的sfx」；edited by Claude Opus 5.5 2026-10-10）：不用找大炮采样；音效一律是不分音高的「一下」，走上面这套。

## 3. 反向镲（采样要右对齐）

- 采样的元数据记一个**着力点**（user「着力点同意」）（离采样开头几秒；反向镲 = 它的结尾）⚑；**在谱上写在「砸下去的那一拍」**，录音房提前「着力点」那么多秒开始放。
- 和月读的辅音提前量是同一个机制（已经支持负的起点），所以跨曲段开头也照样对；改速度也还在拍子上——所以不做「拖一段音频按开始时间摆」。

## 4. 曲段连排预览

- 只读的看法（适合「听」和录演示视频）：按编排的顺序，上一段完了直接接着排、不另起一行；谱表 = 所有出场过的歌手，每行里没音的那几位收起来。中等工作量，和合租一起做效果最好。
