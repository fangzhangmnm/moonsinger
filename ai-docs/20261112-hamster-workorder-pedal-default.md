## 要什么

目录里每个乐器概念多一栏（名字那边定，下面叫「余音」），三个值之一，并且每条带一句依据（出处或常识的说法，能给人看）：

- **自己响**：拨了、敲了之后自己一直响，要人去止才停。例：筝、竖琴、扬琴（它的踏板是踩下去止音）、钟琴、管钟。
- **平时止住**：平时是止住的，要踩踏板或一直按着才响。例：钢琴、电钢、颤音琴。
- **不适用**：按住不会自己衰减的（风琴、弦乐、管乐、人声），和鼓这类敲一下就放完的。

两可的（吉他、贝斯、马林巴、木琴、三味线、班卓…）请判一边并写明为什么；判不了的写「不确定」，app 会当「平时止住」。

## app 怎么用（背景）

写歌软件里每位乐手有一项「延音踏板（没写踏板记号时）」：自动 / 默认踩着 / 默认不踩。「自动」就读这一栏：自己响 = 默认踩着，其余 = 不踩。user 已经定了钢琴不默认踩着。设计全文 = 写歌软件仓 `ai-docs/20261112-pedals-and-ring-design.md`。

## 交付

照以前的做法：导出一版新的目录（版本号 +1），写歌软件这边取货。没到货之前 app 里「自动」一律当不踩，并且照实写「目录里还没有这一栏」。

## 第二件（2026-11-12 加，同一张工单一起跑就行）：补几个概念

写歌软件要把早期的「预设声部」拆掉，以后「这个声部是什么」只从目录来。查下来目录里缺这几样，新建的声部选不到：

- **合唱四部的人声**：女高音、女低音、男高音、男低音（现在目录里同名的只有萨克斯管）。
- **整套鼓**（架子鼓 / 鼓组）：现在鼓是按件分的，没有「一整套」这个概念。
- **贝斯（不分电声原声的那种）**：现在只有电贝斯。同上，由目录这边判。

**原则（user 2026-11-12：「对，乐器就是语义，不要功能语义」）**：目录里的条目回答的是哪件乐器在发声，不收「在编曲里干什么」的条目。所以「伴唱」「合成器主音」「合成器铺底」不进目录（合成器就是一件乐器）；写歌软件里由 user 自己起名字。嗓子的种类（女高音…）、整套鼓算乐器。以后加条目照这条判。

另外一处请看一眼：「人声」那个概念谱上的英文叫法现在是 Voice（简写 Vo.）。写歌软件以前的预设写的是 Vocals。哪个更合适由目录这边定、写明依据；写歌软件照目录的来，不在软件里特判。
