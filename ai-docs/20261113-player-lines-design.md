# 一位乐手演几条线：设计稿（乐手和线分两层）

> created 2026-11-13 by Claude Fable 5.2（MoonSinger 统筹会话）
> as-of v0.17.51 / 2026-11-13。状态：设计稿，等 user 看。没定之前不排活。

## 一、这份稿要解决什么

现在一位乐手（比如一台钢琴）在一张纸上只有一行谱，这一行里叠在一起的音必须一样长。左手按两拍、右手弹两下，这种写法做不了。

眼下的绕路：开两三台一样的钢琴，合租到一行谱上；混音台上各占一条通道，再一条条接线。

user 的话：

- 2026-11-11 夜（语音；「合珠」= 合租）：「如果是左手两拍，右手一拍做不了的话，就说明了我们不同的 track 合珠必须要和弦是一起分析的，因为它们语义上其实就是同一条轨，甚至是以后可以想想，就是能让一个乐手、一个歌手演。好几条轨，这个样子我就不用设置两三个一样的钢琴，然后还要接线。对，这个不是可以，而是必须要。这个我确实很想要。」
- 同一晚：「好，能叠音的乐手才有几条线。如果是两个人一起唱双声部的话，就是两个不同的乐手。同意。」
- 2026-11-13 夜（语音）：「我让你是做 UX，做 UI 这些按钮一按一去用省的，但是我们架构必须要用最好的、最认真的方法来做。」随后纠正：「不是界面省，是界面相关的debug和测试省。」

这件事动歌的数据模型和文件格式，是要背几个月的决定，所以先出这份稿。

## 二、要你定的，和我先定了默认的

### 要你定的（两件）

**1. 力度记号是每条线各自一套，还是一位乐手一套。我推荐每条线各自一套。**

- 这是什么：谱上的 p、f、渐强渐弱，决定后面的音弹多重。
- 每条线各自一套：左手可以比右手轻，旋律可以压过伴奏。代价是每条线在每张纸开头各有一个强制写的力度（程序自动补，和现在每一行一样）。
- 一位乐手一套：谱面干净一点。但左右手没法分轻重，想分还得回去开两台钢琴，这件事就白做了一半。

**2. 分四步做，排在键盘剩下的两版之后（这个顺序你批过）。**

- 四步是：地基（看上去没有变化）→ 出声 → 谱上的画法和操作 → 两颗转换的钮和读别家的谱。细的在第十一节。
- 大小：我估总量是今晚那四版的一倍半到两倍。是估的，第一步最重。
- 你可以只批第一步，做完看了再批后面的。

### 我先定了默认的（你可以否）

1. **调号、拍号、人插的小节线、速度、反复记号，只写在这位的第一条线上，别的线跟着它。** 同一样东西只存一份。理由在第六节。
2. **踏板写在哪条线上都行，都管整位乐手。** 一台琴只有一个踏板。
3. **老歌不动。** 三台钢琴合租的老歌，打开还是三台钢琴。另给两颗你自己点的钮：把一位乐手并成另一位的一条线；把一条线拆成一位新乐手。看得见，能撤销。
4. **换上不能叠音的乐手时**，多出来的线留在歌里，画灰，不出声，明说。和现在「叠音给单声乐器画灰」是同一条规矩。
5. **混音台上一位乐手一张卡、一条通道。**
6. **谱上的画法照现有合租那一套**：光标在这位身上就展开成一条线一行，离开就叠成一行。

## 三、现在是什么样（读代码核过）

- 歌里有一张声部表。每个声部 = 一位歌手 = 一行谱。每张纸按声部的编号存一串音。
- 2026-10-08 定的规矩：一张纸上，同一位歌手最多一行。这份稿要改的就是这一条。
- 合租只管画：几位乐手叠在一行谱上。出声、乐器、混音台照旧各是各的。认和弦时一家合起来认（2026-11-11 定的）。
- 调号、拍号、速度，每一行谱头各带一份。新加一行时从别的行抄一份过来，之后各管各的。
  - 速度只有每张纸最上面那一行算数。别的行存的是没人看的旧数，靠程序在几个动作里把它们写齐。
  - 这个做法出过毛病。仓说明里 2026-10-08 记着一条「已知没管」：最上面那位离开这张纸，它中途的变速不会跟到新的最上面那位身上。现在还在不在，我没核。
- 混音台的通道是按声部建的。两个声部指着同一条麦克风轨时，各得一条通道，参数相同，效果链各跑各的，不是合成一路。
- 别的软件存的谱：一个声部里的第二条旋律现在不读（打开时会说丢了几个音）。所以别的软件存的钢琴谱，左手常常读不进来。

## 四、模型：乐手和线

一位乐手 = 哪件乐器、谁来演、混音台上一条通道。
一条线 = 一串音，展开时是谱上的一行。

| 东西 | 归谁 | 说明 |
|---|---|---|
| 乐器、谁来演、演奏的设置 | 乐手 | 不变 |
| 混音通道：推子、声像、效果、发送 | 乐手 | 几条线合成一路再进通道 |
| 静音、独奏、隐藏 | 乐手 | |
| 认和弦、和弦选项 | 乐手 | 几条线合起来认 |
| 调号、拍号、人插的小节线、反复和跳转 | 乐手 | 只写在第一条线上 |
| 速度 | 整张纸 | 现状不变：最上面那位说了算；写在它的第一条线上 |
| 踏板 | 乐手 | 可以写在任何一条线上 |
| 音、休止、歌词、句号 | 线 | |
| 演奏法、连线 | 线 | 本来就在音身上 |
| 力度记号、渐强渐弱 | 线 | 我的推荐，见第二节 |
| 谱号、八度线 | 线 | |
| 风格记号 | 整张纸 | 现状不变 |

几条规矩：

- 每位乐手有一条**第一条线**，永远在。它就是今天的那一行。多出来的线可以有任意条。
- 一张纸上有这位乐手 = 它的第一条线在场（可以全是休止）。多出来的线，每张纸各自定有没有。
- 一条线里照旧可以叠音（一样长的和弦）。要不一样长，就是另一条线。
- 只有能叠音的乐手才给「加一条线」。
- 两个人唱双声部 = 两位乐手。不变。

## 五、文件里怎么写

目标：只拿到文件、没有我们的程序，也看得出这是一台钢琴的两只手。

- **每张纸的谱**（标准乐谱格式 MusicXML）：一位乐手是一个声部，每条线是这个声部里的一个独立的声音（格式里叫 voice）。调号、拍号、小节线在这个声部里只写一次。
  - 这是这个格式本来的写法。别的打谱软件打开是一台钢琴两只手，不是三台钢琴。
  - 两条线一高一低时，另外标上「上面那行 / 下面那行」。这只是写给别的软件看的，我们自己读不靠它。
- **歌的扩展表**里，这位乐手那一条多一个键 `moreLines`：多出来的每条线的编号，和它在谱里是第几个 voice。
  - 第一条线不用列：它的编号就是这位乐手的编号，永远是第 1 个 voice。
  - 键名施工前可以改，定了就不再变。
- 例子（一台钢琴，多一条线）：
  - 扩展表：`{ "id": "P1", …, "moreLines": [ { "id": "Lk3f9a", "voice": 2 } ] }`
  - 谱里：声部 P1 的每个小节先写第 1 个 voice 的音，再退回小节开头，写第 2 个 voice 的音。
- **编号**：多出来的线用随机铸的编号，不重用。voice 的数字只是这份文件里的代号，对照表明写在文件里，每次保存两边一起重写。这是照家规「编号只能是对照表的代号」。
- **按什么当键**：按线存的东西（每张纸的音、句号、音内起伏、每段的谱号选择）用线的编号。按乐手存的（人插的小节线清单、静音独奏、合租）用乐手的编号。
  - 第一条线的编号等于乐手的编号，所以现有文件里的键一个都不用改。

### 老歌怎么办

- 老歌没有 `moreLines` 这个键 → 用模板补成空表，意思是「没有多出来的线」。保存时明写成空表。
- 这和今天的意思一模一样。没有转换，不需要对话框。
- 模板值 = 空表，也就是每一首老歌会补上的值。
- 不替人把三台钢琴并成一台（第二节第 3 条）。
- 谱的格式小版本号加一（照现有纪律：老版本打开时提示一次）。

### 老版本程序打开新歌（账上留一行，现在不处理）

- 老版本只读得到第一条线，会说丢了几个音；再存，多出来的线就没了。
- 你 2026-11-13 说过这类事平时不花时间，发正式版时再考虑。到时候的办法之一：带多条线的歌记成更新的大版本，老版本不开。

## 六、程序里怎么放

- **歌的模型**：乐手表里每位多一份「多出来的线」的清单。每张纸的音照旧按一个编号存：第一条线用乐手的编号，多出来的用线的编号。
  - 所以现有代码里「这位在这张纸上的那一串音」不用动，它的意思自动成了「第一条线」。
- **一处入口**回答两个问题：这位有哪几条线；这条线是谁的。别处不自己拼。
- **小节网格**（新模块）：从第一条线算出每个小节从哪一刻到哪一刻、是什么调、什么拍。多出来的线在排版、算拍子轻重、存文件时都问这个网格，不看自己那一串（它那一串里没有这些记号）。

为什么不让每条线各带一份调号拍号：

- 同一样东西存几份，就会对不上。第三节说的速度就是这么出的毛病。
- 有一种情况各带一份根本写不出来：第一条线上插了一条小节线，正好落在另一条线一个长音的中间。记号只能放在两个音之间，放不进一个音的中间。按网格走就没事：长音跨过小节线，画成连着的两段，和现在自动小节线的画法一样。

它以后会长成什么：

- 速度、拍号、反复其实是整张纸的东西，不是哪一行的。现在的「最上面那位说了算」是同一个问题的另一处。
- 小节网格这个模块就是以后把它们收成「整张纸一份」的接口。到那天只换网格从哪来，排版和出声不用动。
- 这一轮不做那一步，只把口子留对。这个结构问题记一条账，归统筹。

文件不受这一节影响：这一节讲的是程序里怎么放，文件里已经是「一位乐手一份」（第五节）。以后程序里换放法，不用动文件。

## 七、出声

- 每条线各自出音符表：各自的力度、演奏法、拍子轻重。
- 踏板：这位所有线上的踏板记号按时间合成一条，管这位所有线的音。每个踏板记号本来就写明是踩下、抬起还是换，所以合起来没有歧义。
- **每条线一条发声的轨，几条轨合成一路，再进这位的那一条通道**（过这位的效果链、推子、发送）。
  - 为什么不把几条线的音并成一张表：音内渐强渐弱是乘在整条轨上的音量曲线。并成一张表，左手一个音的渐弱会把右手正在响的音一起压下去。
  - 要动录音房一处：现在一条发声的轨就是一条通道，改成「几条轨可以进同一条通道」。
- 自动低切、不出声清单、播放时的高亮，按乐手算。
- 换上不能叠音的乐手：只有第一条线出声，别的画灰、明说。

## 八、谱上怎么画、怎么操作

界面本身照正常标准做；界面的自动测试照你说的攒成批。

- 一位乐手的几条线算一家，和现有合租同一套画法：
  - 光标在这一家里 → 展开，每条线一行，左边一条括号。
  - 光标不在、或者在「听」里 → 叠成一行（音域宽时自动成上下两行），同一时刻两条线的音一个符干朝上、一个朝下。
- 合租照旧。别的乐手还可以挂上来，一家 = 主人的几条线 + 房客们的几条线。
- 新加的入口，都能撤销：
  - 「加一条线」：在声部的小卡里，只有能叠音的乐手有。
  - 「这张纸上去掉这条线」「整首删掉这条线」。
  - 「并成某位的一条线」：把一位乐手变成另一位的一条线。它自己的乐器设置和通道会删掉，按钮上说清楚。
  - 「拆成一位新乐手」：反过来；乐器设置照抄一份。
- 在多出来的线上，调号、拍号、小节线、速度、反复这几个键是灰的，点了说「这些写在这位的第一条线上」。展开时每一行谱头照样画调号拍号，点它改的是第一条线上的那一个。
- 选好几行、整块贴：一行就是一条线，照现在的规矩。
- 插入、删除一个小节：对这位的几条线一起做。
- 现有的「这一行交给别的歌手」：按整位乐手算，它在这张纸上的几条线一起交。

一条欠账，这一轮不改：叠成一行时现在只画打头那一行的力度和歌词（合租一直这样）。有了多条线，这件事会更显眼。它和「显示要全量」的规矩有出入，记一条账。

## 九、和合租的分界

| | 一位乐手的几条线 | 合租 |
|---|---|---|
| 是什么 | 同一位乐手、同一件乐器 | 不同的乐手挤一行谱 |
| 例子 | 钢琴的左右手；一套鼓的手和脚 | 钟琴加木琴；几件单独的鼓 |
| 混音台 | 一条通道 | 各一条通道 |
| 踏板 | 共用 | 各管各的 |
| 调号、拍号、小节线 | 共用一份 | 各带各的（现状） |
| 认和弦 | 合起来认 | 合起来认（现状） |
| 文件里 | 一个声部里的几个 voice | 几个声部，各记着挂在谁身上 |
| 画法 | 同一套 | 同一套 |

## 十、顺带得到的

- 别的软件存的钢琴谱，两只手都能读进来。现在第二条旋律是丢掉的。
- 整套鼓可以分手和脚两条线，这是鼓谱的标准写法。
- 「不同长短的音混着写」和钢琴卷帘的地基：卷帘里重叠的音 = 同一位乐手的几条线叠着画。那两件这一轮不做。

## 十一、施工怎么分

每一步推开发版时升一个补丁号。

1. **地基，看上去没有变化。**
   - 做什么：歌的模型里乐手和线分开；那一处入口；文件的读和写（`moreLines`、几个 voice）；小节网格模块；多出来的线照网格排版。
   - 没有界面入口。用手写的测试歌验。
   - 守死的：现有每一份测试歌读出来逐个相同；存出去只多一个空的 `moreLines`；带两条线的测试歌存了再读，逐个相同；写出来的谱过标准格式的校验。
   - 统筹审文件格式这一处（发版只审一次）。
2. **出声。**
   - 做什么：每条线一条发声的轨、合进一条通道；踏板合起来；和弦合起来认；不能叠音时只出第一条线。
   - 守死的：没有多条线的歌，出声逐样本不变。
3. **谱上的画法和操作。**
   - 做什么：一家的展开和叠起来；加线、去线、删线；灰键；点谱头改的是第一条线。
4. **两颗转换的钮，和别家的谱。**
   - 做什么：「并成一条线」「拆成一位乐手」；别的软件的谱里一个声部的几条旋律读成几条线；写给别的软件时两只手放上下两行。

## 十二、没核实的和风险

- 排版那一层吃的是一串记号。多出来的线要先按网格配上调号、拍号、小节线再交给它。我看到现成的先例（合租叠成一行时的虚拟轨、行尾补的淡色小节都是这么做的），但没有逐行读排版的代码。第一步开工前，施工方先侦察这一处，报给统筹。
- 录音房「几条轨进一条通道」的改动量没读代码估。
- 写音的规矩里「撞到人插的小节线就停」，在多出来的线上要问网格。第一版可以先不停（长音跨过去，画成连着的两段），以后再补；施工单里写明选了哪一种。
- 这份稿没有量过性能。多条线的乐手每次改第一条线的调号拍号，别的线要重排。
