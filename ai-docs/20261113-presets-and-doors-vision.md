## 二、两句话

**每个人从自己最熟的那种媒介进门，门里面是同一首歌。**

- 门说的是工作的模态：五线谱、简谱、tracker、钢琴卷帘、录音。进来时歌长什么样。
- 依据是 user 的那条理论：人最熟的是小时候第一眼看到的那种媒介。
- 它同时是防线：多一扇门不等于往里搬一个 DAW。

**每样习惯是一个独立的开关，不从一样推另一样。**

- 看什么谱是一个开关，要不要移调显示是另一个开关。谁也不决定谁。
- 不从「你看什么谱」去猜你会多少、要不要辅助。那是刻板偏见：简谱不等于新手，五线谱不一定是专家，看级数的反而多半是行家。
- 模态和水平是两回事。水平不做成一个档位。

## 三、门里面只有一份

不管从哪扇门进来，看的、改的都是这三样：

- **谱**：一串音，带拼写的实际音高和记谱的时值。
- **谁来演**：小月相、乐器音色。
- **怎么混**：混音台。

只有录音会多出一样东西：人录的声音。那是内容，不是画法，所以录音单独算一个纪元（第七节）。

## 四、几扇门

- **五线谱**：现在有。
- **简谱**：现在有。
- **tracker**：还没做。现在只有字母谱能不完美地顶一下（都是把音写成字母），不一样的地方很多。做出来之后是：时间往下走，一位歌手一列，格子里写音名；那时字母谱退役。
- **钢琴卷帘**：还没做，现在没有东西能顶。user 说过这个放最后。
- **录音**（只用过 Audacity 的人）：还没做，现在没有东西能顶。录音纪元。

user：「字母谱只能不完美兜住tracker呀，兜不住钢琴卷帘和录音。」（第三稿里统筹把这三种写成一个占位、都先给字母谱，写过头了。）

## 五、开关：哪些值得单独一个、单独问一次

**判据（照 user 的话归出来的）：开着没坏处的不问，默认开着。两种人要的正好相反、默认错了会难受的，才单独做一个开关。**

现在够格的四样。卡上只有第一样带预览：三小格并排，缩小的真排版，看个大概。另外三样各一行小下拉框，不认识的人看一眼不用碰（user：「让人看一眼不知道也不用碰它」；看了真卡之后：「谱子预览太大了…看个大概就行了」「只有谱子要预览，其他的就是小下拉框」）。

1. **习惯看什么谱。**
2. **要不要移调显示**（调号多的时候把谱换到 C 调来画）。
3. **中央 C 叫 C 几**（C4 / C3 / C5）。user：「要」。FL Studio 叫 C5，雅马哈那一系叫 C3，国际通用是 C4。它管的是界面上所有把音写成「字母 + 八度数字」的地方；文件里的八度永远是标准的那一种。
4. **和弦标级数还是根音**（V7 还是 G7）。user 一开始要的就是和弦名，后来用了级数觉得好；现在两种都要，默认级数。它是「和弦辅助」那一项多一种标法。开了移调辅助，根音跟着谱换到 C 调写——这一件是自动的，没有开关。施工单第 19 条。

不问的：

- 和弦辅助：开着没坏处，默认开。
- 自动小节线、自动谱号、自动八度线、演奏法和表情：同理。

**定了不做成开关的：**

- **键盘上写音名还是级数：跟着谱种走，绑死。** user：「这个不是跟着五线谱还是简谱还是字母谱走吗？绑死。」五线谱写音名，简谱写数字，字母谱写音名。怎么对齐的细节归键盘那一轮（愿望单 W-69）。
- **键盘在左还是在右**：user 以后要大整改键盘的位置，现在不动。

**同一类、以后可能要的**（现在都不做）：

- **拼音**：不只是小朋友版的事。user 要的是中文歌词能直接写拼音让她唱（愿望单 W-93）。
- **纸张是 A4 那一系还是 Letter**：只影响打印，是地区的习惯。不值得问，放设置里。

以后每加一个这样的开关，都照同一个做法：歌里没单独选过的跟着设备上的习惯走，设备上没选过的跟着软件的默认走，三层各管各的，不互相推。

## 六、现在就定的（只影响手上「第一次打开的卡」那一件）

1. **卡上问三样，第 19 条做完后四样**：你习惯看什么谱；要不要移调显示；中央 C 叫 C 几；和弦标级数还是根音。都可以不选。只有第一样带预览，别的各一行小下拉框。
2. **设备上每样习惯各记各的。** 不捆成一组，没有「预设」，没有「你是哪一种人」。
3. **看什么谱那一问**：五线谱、简谱、字母谱三小格并排。格子下面一行小字照实写：字母谱，玩 tracker 的可以先用这个，不完全一样；钢琴卷帘和录音还没做，做好了会加在这里。以后有新的就多一格。
4. **每一格的预览用真的排版画带表情记号的同一句**（力度、连线、跳音、重音…），缩小到看个大概：一眼认得出是哪种谱、上面带着记号就行。移调显示那一问不带预览（第一版带过，user 看了嫌大）。
5. 设置里一样一行。
6. **给人看的音名要和眼前的谱对得上**：中央 C 的叫法、移调辅助开着时各处写出来的音名和根音，先让施工方把所有出口查一遍，再写成纪律和守卫（user：「让小弟好好查一下，然后也写成纪律和测试」）。

## 七、以后每扇门开工前要先回答的

每一扇新的门都要守同一条已有的规矩：**显示全量、不静默**。谱上的每个音和它身上的每样东西都要画出来，可以小，不能没有。

**tracker**

- 我们的谱记的是记谱的时值（附点、三连音、连音线），不是一格一格的。一行一格的表里，三连音放哪、比一格还短的音放哪？
- 力度、演奏法、歌词，在格子里各占哪一列？
- 它是所有歌手并排的视图。现在的排版是一页一页的纸，这是另一种框架，要先把谱面再分一层。10-13 说的「显示可以拆」就是这一刀，谱面分家时留了口子。
- 不加 tracker 才有的数据（效果列那一类）。格子只是同一份谱的另一种画法。

**钢琴卷帘**

- 同样是另一种框架，和 tracker 共用那一层。
- 卷帘上力度、演奏法、歌词怎么露出来，才不违反显示全量？
- 它的主场是大屏和鼠标。触屏上能用就行，不必最顺。
- user 自己读卷帘吃力，所以它排最后，并且要有人真的用它来验。

**录音**

- 录的声音放哪：歌文件里，还是只留在这台设备上。数据契约里早就给它留了位置，没定。
- 同不同步到网盘。家规里那句「语音字节不离开设备」当时说的是语音识别，10-13 的远景文档已经记着这件要 user 说一句。到开工时问，现在不问。
- 录进来的声音和谱怎么对齐（延迟补偿）、节奏提示长什么样。
- 不做成多轨剪辑软件。它是「人声代替小月相」那一条轨，加上 Audacity 的人最常用的那几下。

## 八、顺序上的建议

版本号和纪元什么时候开，由 user 定。这里只说先后和为什么。

1. **近的**：第一次打开的卡 → 踏板 → 键盘那一轮。键盘那一轮本来就要把键盘拆成几种，也要定键盘上的字跟谁走。
2. **谱面再分一层**：把「一页一页的纸」和「格子」分成两种框架。这是 tracker 和卷帘共用的地基，做完之后看上去没有变化。
3. **tracker**：先做它。它离现在的谱近（一格一个字），做完能把字母谱替掉。
4. **钢琴卷帘**：放最后。
5. **录音**：单独一个纪元，和上面几件不在一条线上。先定第七节那三件再动。

## 九、不建议做的

- 从一样设置去猜另一样（看什么谱 → 要不要辅助、会多少）。
- 把人分成新手和专家两档。
- 某一扇门里做出来的东西，换一扇门看不到。
- 为了像 tracker 或 DAW，往歌里加只有那一种门才认识的数据。
- 第一次打开时问一串问题。卡上只问默认错了会难受的那几样，带预览的只有看什么谱。
