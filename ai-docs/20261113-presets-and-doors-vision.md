## 二、一句话

**每个人从自己最熟的那种媒介进门，门里面是同一首歌。**

- 预设是一扇门：进来时歌长什么样、手往哪儿放。它不是另一个软件，也不是一套专属功能。
- 这句话直接来自 user 的那条理论：人最熟的是小时候第一眼看到的那种媒介。所以第一次打开问的是「你是哪一种人」，不是「你要哪些功能」。
- 它同时是防线：加一扇门不等于往里搬一个 DAW。门越多，里面那一份越要只有一份。

## 三、门里面只有一份

不管从哪扇门进来，看的、改的都是这三样：

- **谱**：一串音，带拼写的实际音高和记谱的时值。
- **谁来演**：小月相、乐器音色。
- **怎么混**：混音台。

只有录音会多出一样东西：人录的声音。那是内容，不是画法，所以录音单独算一个纪元（第七节）。

## 四、一个预设定哪几样

一个预设 = 把下面四样的「没单独选过时是什么」一次填好。

1. **怎么看**：谱面。五线谱、简谱、以后的 tracker、钢琴卷帘、录音的波形。
2. **怎么写**：键盘。现在的数字键盘、电脑键盘、MIDI 琴；以后 tracker 那种把电脑键盘当琴、卷帘那种用笔画、麦克风。
3. **帮多少**：辅助。和弦辅助、移调辅助、键上写音名还是级数、各种提示。
4. **新歌带什么**：新建一首时里面有什么。现在是一位小月相；录音的人以后是一条录音轨。

三条规矩：

- **预设只是一键填好默认。** 每一样以后都能在设置里单独改，每首歌也能单独选。没有藏在预设里、别处看不到的开关。
- **一首歌自己选过的，盖过预设。** 这就是刚做完的「跟着软件」：歌里没选的项跟着这台设备的预设走，选过的照选的。
- **预设记在设备上，不进歌。** 同一首歌，看简谱的人打开是简谱，看五线谱的人打开是五线谱。

现在的事实：三个预设之间只差「怎么看」。辅助的默认是同一套（和弦辅助开、演奏法和表情显示、移调辅助不用）。结构上允许以后不一样，比如给刚开始的人多开几样。

## 五、几种人

- **看五线谱的人**（学过琴、学过乐理）：现在有。
- **看简谱的人**（唱歌的、刚开始的、孩子）：现在有。
- **用字母想音的人**（玩过 tracker）：现在用字母谱顶着。以后换成真的 tracker：时间往下走，一位歌手一列，格子里写音名。换了之后字母谱退役。
- **用钢琴卷帘的人**（用过 FL Studio 这类）：以后。user 说过这个放最后。
- **自己唱的人**（只用过 Audacity）：录音纪元。
- 孩子、三岁那一档：统筹的看法是它更像「帮多少」里的一档，不是另一种谱。到做尊老爱幼时再定。

## 六、现在就定的（只影响手上「第一次打开的卡」那一件）

1. **设备上记的是「预设」，不是「谱种」。** 现在三个预设只差谱种，但记的是哪一种人。以后给某种人多开一样辅助，不用再问一遍。
2. **卡上的问法换成「你是哪一种？」**，每一格的标题写人。现在三格，以后有新的门就多一格。
3. **预设的名字和谱种的名字分开。** 以后一种谱可以有两个预设（比如简谱的新手和熟手），一个预设也可以换谱种（用字母的人以后换成 tracker）。
4. **设备上记着的预设哪天退役了**：当成没选，卡再出一次。不替人换成别的。
5. 设置里那一行叫「我是」。

这五条已经写进施工单第 18 条。

## 七、以后每扇门开工前要先回答的

每一扇新的门都要守同一条已有的规矩：**显示全量、不静默**。谱上的每个音和它身上的每样东西都要画出来，可以小，不能没有。

**tracker**

- 我们的谱记的是记谱的时值（附点、三连音、连音线），不是一格一格的。一行一格的表里，三连音放哪、比一格还短的音放哪？
- 力度、演奏法、歌词，在格子里各占哪一列？
- 它是所有歌手并排的视图。现在的排版是一页一页的纸，这是另一种框架，要先把谱面再分一层。10-13 说的「显示可以拆」就是这一刀，谱面分家时留了口子。
- 不加 tracker 才有的数据（效果列那一类）。格子只是同一份谱的另一种画法。

**钢琴卷帘**

- 同样是另一种框架，和 tracker 共用那一层。
- 卷帘上力度、演奏法、歌词怎么露出来，才不违反显示全量？
- 它的主场是大屏和鼠标。触屏上能用就行，不必最顺。
- user 自己读卷帘吃力，所以它排最后，并且要有人真的用它来验。

**录音**

- 录的声音放哪：歌文件里，还是只留在这台设备上。数据契约里早就给它留了位置，没定。
- 同不同步到网盘。家规里那句「语音字节不离开设备」当时说的是语音识别，10-13 的远景文档已经记着这件要 user 说一句。到开工时问，现在不问。
- 录进来的声音和谱怎么对齐（延迟补偿）、节奏提示长什么样。
- 不做成多轨剪辑软件。它是「人声代替小月相」那一条轨，加上 Audacity 的人最常用的那几下。

## 八、顺序上的建议

版本号和纪元什么时候开，由 user 定。这里只说先后和为什么。

1. **近的**：第一次打开的卡（预设）→ 踏板 → 键盘那一轮。键盘那一轮本来就要把键盘拆成几种，它是「怎么写」那一层的地基。
2. **谱面再分一层**：把「一页一页的纸」和「格子」分成两种框架。这是 tracker 和卷帘共用的地基，做完之后看上去没有变化。
3. **tracker**：先做它。它离现在的谱近（一格一个字），做完能把字母谱替掉。
4. **钢琴卷帘**：放最后。
5. **录音**：单独一个纪元，和上面几件不在一条线上。先定第七节那三件再动。

## 九、不建议做的

- 每种预设各有一套别人没有的功能。
- 某一扇门里做出来的东西，换一扇门看不到。
- 为了像 tracker 或 DAW，往歌里加只有那一种门才认识的数据。
- 第一次打开时问一串问题。卡上只有一个问题。
