## 现在能改什么

| 改什么 | 键盘（大屏的主场） | 触屏 / 笔 | 选区菜单（「操作…」） |
|---|---|---|---|
| 音高 一级 / 半音 / 八度 | ↑↓ / Shift+↑↓ / Alt+↑↓（光标前那个音，选中 = 整组） | 长按拖（笔、鼠标长按之后；手指 = 长按是选中） | 移调 ±半音 / 全音 / 八度、转调 |
| 时值 | 8 / 9 只改「接下来写多长」 | 横拖（同上） | ÷2 / ×2 / 都改成长短档 |
| 记号 | 符号层 | 符号层 | 清掉记号 |

缺的：**触屏上不拖也能改一个音的高低和长短**；以及「单音的微调」到底指什么，要先说清。

## 「单音 tweak」可能是两件不同的事

1. **改谱**：这个音高一点 / 低一点、长一点 / 短一点。改的是谱，印出来就变。
2. **改演奏**（不改谱）：这个音力度大一点、早一点 / 晚一点、实际奏得长一点 / 短一点。印出来不变，只有出声变。打谱软件把这个放在「播放 / 演奏」面板里（MuseScore 的 velocity / 偏移、DAW 的 piano roll）。

第 2 件要在音上加新字段（格式红线：可选字段 + 形状快照），和「记号承重」的路线（用记号说演奏、演奏者配置去解读）会打架，要你先定方向。**我建议先只做第 1 件**；第 2 件等「记号 + 演奏者配置」真的不够用时再说。

## 小控件的三个方案（都是第 1 件）

**A. 选区条多一排「微调」**（改动最小）：选区条已经在走带胶囊下面（全选 / 复制 / 剪切 / 粘贴 / 操作… / 删）。选中时多一排：`↑` `↓`（一级）、`♯` `♭`（半音）、`时值 ÷2` `×2` `· 附点`。点了不收，可以连着点；每一下一步撤销。
- 好：手指、笔、鼠标都一样；离音远，不会误触谱面。
- 坏：眼睛要在音和条之间来回看。

**B. 音旁边的小把手**：只选中一个音时，符头上下各一个小箭头（音高），右边一个小把手（时值），按指尖大小做点击区域（同 v0.6.2 手指碰撞箱的教训）。
- 好：直接、眼睛不离开音。
- 坏：挨得近的音会挡住别的音；多选时没法这样摆；画在谱上的东西多了，又回到「误触」的老问题。

**C. 选中时把 pad 换成「微调盘」**：音键的位置换成两个大滚轮（音高 / 时值），像 1= 那种滑窗，按住上下滑一格一格地拨；放手回到音键。
- 好：大、不会误触、iPad 上手指最舒服（pad 本来就是触屏的主场）；单选多选一样。
- 坏：要切换 pad 的样子，概念多一个。

**我的建议**：A 先做（最小、最不误触，和「键盘只做纯粹的打谱、整组操作 = 菜单」的老规矩一致），用一阵看还缺不缺；B 不做（又把可点的东西堆在谱上）；C 留着，等 iPad 上真觉得 A 不顺手再说。

## 要你定的

1. 「单音 tweak」是第 1 件（改谱）还是第 2 件（改演奏），还是都要？
2. 小控件走 A / B / C 哪个（或者组合）？
