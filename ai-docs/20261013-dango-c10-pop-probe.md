## 0. 一句话

**v0.10.38 的 packInt16 跟这一下没关系**：按 app 同一条路在 node 里唱出含第 10 小节的那一块，原始合成的峰值 0.34 ～ 0.38（三轮），离满幅差一倍多，packInt16 的「超过满幅才缩」根本不会触发；缩与不缩这一块逐样本相同。月读这一块在「そ」起音处的波形跳变和力度曲线都没有异常。**爆音（如果还在）不在月读的合成里，在它后面的路上或别的轨上**——下面列了剩下的嫌疑和一分钟能分清的办法。

## 3. 排除了什么、还剩什么

排除（量过）：
- **转 16 位削顶**（v0.10.38 packInt16）：这一块 raw 从没超过满幅，缩不缩逐样本一样。那个修复本身没错（WORLD 理论上能冲过满幅），但不是这一下的原因。
- 月读合成里「そ」的起音：没有异常跳变。
- 这条轨的力度曲线：连续。
- 块边界：「そ」在块中间（边界在 m9 的休止，那里本来没声音）。

剩下的嫌疑（**没核**，按便宜到贵排）：
1. **不是月读、是那一拍上的别的轨**：m10 第一拍有 10 条声部一起（钢琴 ×3、合成器、太鼓、木鱼、钟琴 / 木琴…）。SoundFont 一声的采样头、或复音到上限时**偷声（voice stealing）把一个正在响的采样掐断** = 真 click。
2. **总轨限幅**：前瞻 9 ms（`LIM_ATTACK 3 ms × 3`），一拍上好几件打击乐同时砸下去、峰超过前瞻能压的斜率 = 过冲到天花板上；`studio.test` 守的是「母线不超天花板」，没守「压得不突兀」。
3. **m1 上的压缩器**：阈值 −15、比例 2.8、补偿 +2.4（10-11 那一版），攻击时间 / 增益计算是逐块还是逐样本没查——逐块更新 = 每 128 帧一个台阶。
4. piper 的 noise 是随机的：块按内容键缓存，所以同一次打开里每次听都是同一份；换一次缓存（清念缓存 / 改了这句）就是另一份。user 听到的那份我这里复现不出来（三轮 raw 都干净，不代表第四轮也干净）。

一分钟分清 1 vs 2/3 vs 4（归 user 的耳朵，这里只写怎么分）：
- 谱上歌手名下面点月读的「独」从 m9 放：还爆 → 在月读这条路（4 或 3）；不爆 → 在别的轨 / 总轨（1 或 2）。
- 混音台「效果全关」再放：3 的嫌疑随之去掉（限幅不在「全关」里，2 还在）。
- 要进一步在 node 里离线渲整条混音（`Studio` 类能在 node 跑，`test/studio.test.ts` 就是）来查 1 / 2：能做，是另一轮（要把 10 条轨的 SoundFont 子集、链、发送按 main.ts `pushChannels` 原样接进去），这次没做。

## 6. user 听了（2026-10-15）+ 代码里的台阶（edited by Claude Fable 5.1）

user：「好像只有齐平多少有用」（level 关到 0 才不破；cleanMax 0.3 / 0.5、breath、levelMaxDb 12 都没用）。

对着代码（`sing-core.mjs` 合成前那一圈）：齐平的增益**只乘在元音段**，从这个字的 `noteStart` 起 30 ms 内 `w` 从 0 爬到 1（`gg = 10^(w·gainDb/10)`），辅音段不乘。所以相邻一轻一重的两个字之间：前一个字元音末尾在 g₍k−1₎（「も」≈ −4 dB）→ 辅音 s 段回到 0 dB → 「そ」元音起点从 0 dB 在 30 ms 内冲到 +6 dB。两个台阶都压在 s 进 o 那一下；这和 §5 量到的「起音处 +12 / +7 dB 能量台阶」同一位置。它解释为什么：level 0 = 没有增益 = 没有台阶（有用）；cleanMax 0.3 让「そ」改成借、它自己的增益归 0，但「も」末尾到 s 的那一跳还在（没用）；levelMaxDb 12 只让台阶更高（没用）；breath 管杂度不管响度（没用）。

→ v0.12.9：核心加 `levelContinuous`（默认 false = 原路逐样本不变，node 里核过 sha256 相同）：true = 增益从前一个字的目标起、经过这个字的辅音、到元音起点后 30 ms 线性过渡到这个字的目标（休止后从 0 起），辅音也跟着过渡；乐器页第五行「齐平过渡：每字重起 / 连续」。齐平本身保留（它是为「有些音突然很轻」加的）。听感归 user。
**拍板（2026-10-15 user）**：「应该leverage就是齐平，我觉得不开没什么影响吧，默认不开，然后月相可以设置，齐平和其他的也都放在高级设置里面可以持久化」「嗯你试一下连续也行」→ v0.12.9：`TSUKUYOMI_DEFAULTS = { level: 0, levelMaxDb: 6, cleanMax: 0.4, breath: 0, levelContinuous: 0 }`（app 永远显式传 level，唱法核心自己的 0.8 只剩 Lab 命令行用）；五个旋钮住候选的 `defaults`（by value，乐器页「高级」改，走 undo、进文件、换人跟人走）；v0.12.4 的实验行退场。旧歌候选里没写 = 默认表 = 齐平关（user「不开没什么影响」）。
