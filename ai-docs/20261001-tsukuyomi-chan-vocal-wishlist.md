## 是谁

つくよみちゃん = 免费素材角色（CV. 夢前黎），官方定位「高音ウィスパー系の14歳前後の少女声」。家族里第一次碰到她是 2026-10-01 做逐句朗读（TTS）评估：她有一个六语朗读模型，日语在浏览器里实测能跑、很快，user 听了说话的样本后觉得可以。来龙去脉 = 家族根 `../ai-docs/20261001-read-aloud-shared-lib-assessment.md`。

## 今天核到的事实

（都是 2026-10-01 取官方页面、由取页工具摘要的；日文引文是它摘的原文。**动真格之前把条款页自己再读一遍。**）

1. **官方 UTAU 音源存在**：「フリー素材キャラクター「つくよみちゃん」（CV.夢前黎）の公式UTAU音源」。
   - 介绍页 https://tyc.rei-yumesaki.net/material/utau/ ，条款页 https://tyc.rei-yumesaki.net/material/utau/terms/ ，下载 https://tyc.rei-yumesaki.net/files/voice/tyc-utau.zip （没下、没看内容）。
   - 录音形式（单独音 / 连续音 / CVVC）、音高、体积：介绍页没写，**未核**。
2. **条款对我们相当宽**：
   - 「個人・法人、営利・非営利を問わず、大抵のことにはご利用いただけます」；明列允许「販売用の楽曲や音楽素材の制作に使う」和「本品の声質を再現した音声合成ソフトを作って配布・販売する」。
   - **做歌声合成软件（含 web app）发布**：要么事先联系作者，要么在显眼处放指定署名块——「本ソフトウェアの音声合成には、フリー素材キャラクター「つくよみちゃん」（© Rei Yumesaki）が無料公開している音声データを使用しています。■つくよみちゃんUTAU音源（CV.夢前黎）https://tyc.rei-yumesaki.net/material/utau/」。
   - 软件自己的条款里要禁止用户拿合成的声音去：攻击他人、政治 / 宗教 / 思想号召、无分级的强刺激内容、以素材形式二次发布。
   - 不许强制最终用户署名这个声音；不许把这个声音用到别的角色身上（要另行许可）。
   - **音源本身再分发要事先邮件许可**（例外：原始发布消失且作者失联 6 个月以上）。→ 和家族「模型包分发仓」的做法直接相关：把 UTAU 音源挂到 `pwa-models` 之前得先问作者，或者改成「指路让用户自己下载再导入」。
   - 拿它训练 / 转换成机器学习歌声模型并公开：有额外限制（摘要没展开），**未核**。
3. **朗读那边的语料条款**（つくよみちゃんコーパス，另一份）也明文允许「歌声合成ソフト」，署名块同形（把 UTAU音源 换成 コーパス）。
4. 她的六语**说话**模型（`ayousanz/piper-plus-tsukuyomi-chan`，38 MB）在浏览器单线程下实测约为实时的 8 倍速（桌面）。那是说话不是唱歌，唱不了。

## 没核的（别当成已知）

- UTAU 音源的技术规格。
- 浏览器里怎么把 UTAU 音源唱出来：要一个重采样 / 拼接引擎（UTAU 生态里叫 resampler / wavtool；OpenUtau 自带的 WORLDLINE 之类）。有没有现成的 WASM 版、许可如何、手机上够不够快——全没查。
- 有没有现成的つくよみちゃん 神经网络歌声模型（DiffSinger / NNSVS / ENUNU 等）以及它们的条款。
- 条款页里关于机器学习模型公开的细则。

## 想法（AI 写的，待 user）

- WebRings 的心智模型是 Nokia 彩铃编辑器：一行音符。给这行音符配上假名歌词，就能让つくよみちゃん 把旋律唱出来——「人声轨」可以是和罐头音色并列的一种音源，走已经拍过的「插件化 day 1」「重音源进 IDB」。
- 许可上她是目前见过的最干净的角色人声：商用可、做合成软件可、只要署名块和四条禁止用途。
- 和朗读库（`@internal/read-aloud`，2026-10-01 在建）没有代码复用关系——说话和唱歌是两套引擎——但语音包的分发 / 校验 / 缓存管道（模型仓 + 逐片哈希 + Cache `pwa-models`）可以共用。
- **听感归 user 的耳朵**（本仓红线：音色像不像、好不好听 AI 不许报确信）。第一步如果要做，应该是 Lab 里的一次性实验：下载音源，在电脑上用现成的 UTAU / OpenUtau 唱一句 user 背得下来的旋律，让 user 听。
