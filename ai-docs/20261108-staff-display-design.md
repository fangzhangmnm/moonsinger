## 1. 现状一句话

排版器（`src/render/engrave.ts`，1656 行，核心是一个 1200 行的函数）是纯函数、在 worker 里跑——这两点是对的，别动。问题是它同时在干**四件事**：

1. 排可印的谱（音、符杠、歌词、记号、小节线、分页）；
2. 画编辑器的控件（眼睛 / 喇叭两颗钮、每段底下的虚线框、曲段的「‹ › 本段 ⋯」、纸角的小钮、「1=C」淡提示、空着时的浅色提示、合租那家的括号、隐藏声部的细线）；
3. 做「看法」变换（按 C 调看、合租叠成一行、只看一位 / 隐藏、听模式全叠起来、自动谱号、自动八度线）；
4. 吐十几张点击框表（音、休止、歌词、记号、谱号、歌手牌、曲段控件、虚线框、两颗钮、级数标签、括号、小节……）给谱面手势去查。

四件事缠在一起的代价，今天的审计已经看到：每加一样编辑器控件要改六处；PDF 靠一张「减掉这些 class」的名单维持所见即所得；谱面手势是一条按位置排的 if 链；「按 C 调看」在排版器和谱面手势里各算一遍。排谱本身的毛病（记号撑开音距、纵向一层层固定留位、密音不压、连音不齐）也是因为**没有一个独立的「横向间距」和「纵向堆叠」阶段**可以单独改——它们散在那 1200 行里。

## 2. 四层（目标结构）

```
谱（Song）
  │
  ▼  ① 看法层 ViewSong（纯函数，可逆）
  │   按 C 调看 · 只看 / 隐藏 · 合租叠起 / 展开 · 听模式全叠 · 自动谱号 · 自动八度线
  │   出：view song + 反查表（看法里的第几条第几个 → 谱里的哪条哪个）
  ▼
  ▼  ② 排版层 Engrave（纯函数，worker 里）—— 只排「印出来是什么样」
  │   2a 切单元（时值、临时记号、小节）      2b 横向间距（列 → 理想宽 → 碰撞最小距 → 折行）
  │   2c 纵向堆叠（天际线，贴着往外摆）      2d 出图元 + 锚点表
  │   出：Printable = 图元（线 / 字形 / 字 / 路径）+ 锚点（每个音 / 休止 / 记号 / 歌词位 / 谱行 / 小节 在哪）
  │       **没有一个编辑器控件，没有一张点击框表**；PDF 原样印，不减任何东西
  │       〔刀 1 审后〕第三样输出 = **注解**（图元带 `ann` 类：推定的灰字、速度 ↑↓、句号、类别色、角标、写错的说明、页框）——只给写谱人看、屏幕画、PDF 不印；
  │       它们不是控件（没有手势），位置是排版内部算的、还要参加 2c 的避让，所以留在这一层。PDF 只认 `ann` 这一个类，不记名单
  ▼
  ▼  ③ 覆盖层 Overlay（主线程，DOM）—— 编辑器自己的东西，按锚点摆
  │   两颗钮 · 虚线框 · 曲段控件 · 纸角小钮 · 「1=C」提示 · 空着的提示 · 合租括号 · 隐藏声部细线的「点我放出来」
  │   光标 · 选区 · 鬼音符 · 播放线 / 小节底色（这几样今天已经在 ink 层了，W-17 第 1 刀）
  │   都是真的 DOM 按钮：碰撞箱大小、长按、右键、无障碍标签一处定，不再在排版器里算矩形
  ▼
  ▼  ④ 手势层 Hit —— 一张「谁先谁后」的表，不是 if 链
      先问覆盖层的按钮（DOM 自己接事件，根本不进这张表）→ 再按锚点查谱上的东西（音 / 休止 / 歌词 / 记号 / 谱号 / 空白）
      反查表把「看法里的」换回「谱里的」（按 C 调看的拖音高、合租虚拟行的下标）只在这一处
```

每层的判据只有一个问题：**「印出来有没有它？」** 有 = ② 排版层；没有 = ③ 覆盖层。「印出来是什么样」要不要随看法变（按 C 调看印不印？和弦级数印不印？）= ① 看法层的开关，一处决定、两边（屏幕 / PDF）同一份输入。

## 4. 排版层内部怎么分（这是你这两天要的排谱改进住的地方）

### 4a 字和谱分开缩（§11「舒适 / 紧凑只缩谱」）

现在所有字号都是「几个线间距」（歌词 LYRIC_EM × sp、声部名 PART_EM × sp、歌名 2.8 sp…），所以紧凑把字也缩了。改法：排版吃**两个尺子**——`sp`（五线谱的线间距）和一套**字号表**（歌名 / 作者 / 曲段名 / 声部名 / 歌词 / 速度字 / 小节号 / 级数，单位是毫米或像素，和 sp 无关）。舒适 / 紧凑只换 sp；字号表另有自己的档（先只有一档）。歌词暂时也不缩（你说的「先尝试保持原样」），挤了走现成的「按节奏排、歌词让路」那套。

### 4b 横向间距：列 → 理想宽 → 碰撞最小距 → 折行（W-49、密音、连音）

> 〔11-09 更正，Claude Fable 5.1〕下面第一句「挂在它上面的记号的宽」是我读代码读错的：量过，力度 / 渐强 / 风格 / 速度 / 重音 / 音内起伏都不占宽。真正把音拉开的是「一列的宽 = 这一刻各声部刚开始的音里最长的那个」。四步的骨架不变，第 2 步的「理想宽」改成「看正在响的音里最短的那个」。事实和改后的算法见 §8 和施工单。

现在一个音的宽 = 它自己的时值宽 + 临时记号 + **挂在它上面的记号的宽** + 歌词宽的大者——所以记号撑开音距。改成三步：

1. **列**：同一时刻所有声部的东西是一列（现在按 tick 对齐已经是这样）。
2. **理想宽**：只看时值（对数曲线：四分 3.6、每翻倍加 0.75，底 2.2）。**曲线的斜率和底是版式的参数**——「密音压紧」= 短时值那头更陡、底更低；连音组内按**记谱时值**等分（三连音三个一样宽），组的头尾落在别的声部的列上（本来就是列对齐）。
3. **碰撞最小距**：每一列的东西各有左右轮廓（符头、临时记号、附点、符尾、歌词、挂着的记号各在自己的高度上）；相邻两列的距离 = 理想宽，**只在同一高度上两样东西真会撞时才加到不撞**。记号在谱上方，和下一个音的符头不在同一高度 = 不撞 = 不撑；只有下一个音也挂了记号、两个记号真会叠，才撑开——这就是你说的「协商」。歌词已经按这个思路做了（按节奏排 + 让路），把它推广到所有挂着的东西。
4. **折行**照旧（「挤一挤」规则不动），行内多出来的宽按理想宽的比例分（现在是这样），不按最小距分（不然密的一段会被均匀撑开）。

顺带能治截图清单里的：同一行小节宽窄乱跳（最小距只在撞时加）、鼓那行三十二分挤成一团别处松（曲线按密度）、三连音不均不齐（组内等分 + 列对齐）、每段末尾补齐的空小节和满的一样宽（空小节 = 一个「全休止」列，理想宽按全休止给、最小距几乎为 0）、6/8 整小节休止居中（全休止列的画法）。

### 4c 纵向堆叠：天际线，贴着往外摆（§18 第二刀 + 截图清单的一半）

现在每一行先按「有力度就留一整层力度位、有记号就留一道」留固定的道，再把东西摆进去——所以 `< >` 飘得高、`p` 压在级数上、`ppp` 压在符杠上、每个声部都先空出一层。改成**天际线**：

- 一行谱从五线谱和符头 / 符干 / 符杠 / 加线出发，算出一条「现在最高到哪」的轮廓（天际线），下面同样一条。
- 挂着的东西**按离音的远近顺序**一样一样摆：跳音 / 保持（符干另一侧，贴符头）→ 重音那一组（谱上方）→ 音内的 `< >`（贴着这个音的最高点）→ 力度字和渐强渐弱（整行一条道，但道的高度 = 这一行天际线在它们下面那段的最高点 + 一点，不是固定值）→ 风格 / 速度 / 反复跳转（再上一道，同样按天际线）→ 和弦级数（§4d）。每放一样，天际线更新。
- 行高 = 最后的天际线上下沿。**行距真不够才加，加的是这一行自己的**（现在已经「按内容」，但是按固定道数估的，不是按真放下的东西）。
- 下面同理：歌词基线 = 下面天际线 + 一点；第二行歌词、八度线（8vb）照旧。

### 4d 和弦级数（§17）

字体：谱上分析和声用的那种**衬线罗马数字**（I / ii / V7 / ♭VII），不用界面字体。位置：你说「和弦的右下角」；有歌词时右下会撞歌词 → 天际线自然把它托住（§6 问你撞了往哪让）。「1=F」字号跟 §4a 的字号表，不再刻意小。

## 5. 切几刀、每刀交付什么、怎么验

每刀单独一版、单独能推、单独有守卫；顺序是按「先把别人的东西从排版器里搬出去，排版器才好动」排的。

## 6. 要你拍的（一个回合）

1. **先切哪一刀**：我建议**刀 1（覆盖层）先**，再刀 3 / 刀 4 排谱——排版器里少了编辑器的东西才好动间距；但如果你更想先看到排谱变好，可以刀 3 先、刀 1 后，代价是刀 3 改的地方刀 1 还要再碰一遍。
2. **和弦级数右下角撞歌词时往哪让**：往右（挪到下一个音前面）、往上（挪到谱上方）、还是有歌词的声部级数一律写上方？
3. **样张歌**：排谱三刀每刀要一首真歌当样张反复看。你截图那首《Once upon a Tale》最合适。本仓是公开仓，歌放进仓 = 公开；放在仓外的私有夹（不进 git）也行，就是测试只能在你机器上跑。你选。
4. **隐藏的声部在 PDF 里位置照留**（现在的规矩，为了和预览分页一致）：覆盖层做完之后预览和 PDF 可以完全一样，这条还要不要？不要 = PDF 不留空，预览也不留（隐藏的只剩名字那一条细线的位置）。
5. **密音压紧的档**：跟着舒适 / 紧凑走（紧凑 = 更陡），还是单独一个开关？
