> created 2026-11-12 by Claude Opus 5.5（MoonSinger小弟）· as-of v0.17.8 / 2026-11-12
> 底 = 统筹的第一遍 `ai-docs/20261112-silent-conversions-inventory.md`。这一份逐处对过代码（`src/format/project.ts`、`src/format/migrate/index.ts`、`src/format/musicxml.ts`、`src/score/desk.ts`、`src/engine/`、`src/performers/`），只读，没改代码。
> 「哪天加的」= 那段代码在 git 里第一次出现的日子（`git log -S`）；改过名的写最早那个名字的日子。
> 规矩 = 家族根 `CLAUDE.md` 硬规则 #9「文件就是语义」。「哪一层」照施工单「15 补」：**底线** = 程序里藏着的数 / 偏移 / 默认 / 对照表，改变了文件里某个数的意思，或者文件里根本没有这个数；**理想** = 算法本身（文件里只要求记下用的是哪一版、依据哪个标准）。

## 〇、先说结论（五条）

1. **升级链一共 7 步，全部静默**，其中两步删掉了文件里明写着的数：休息室 2→3 删掉每位乐手的力度 dB 表；开文件时把老歌里的句号整个丢掉。
2. **开文件顺手改的 14 处**，其中 5 处有提示条，0 处有对话框。还有 3 处是**存的时候**顺手改的（哼的字统一、乐器的谱上叫法换成现行目录、老文件里的 mp3 再存就不带了）。
3. **「没写 = 默认」影响出声的 16 组**。最大的一组是统筹点名的「整位乐手没写」：新歌没存过之前，程序当成小月相 + 她的全套默认；**存一次之后整份明写进文件**。所以这一组只出现在没存过的新歌、和手改过 / 缺了休息室文件的歌里。
4. **写的那一侧**：出声的东西（休息室、录音房）存的时候基本是明写的；「只写不是默认的」集中在谱的扩展（score.json）和视图态，影响画面不影响声音，一共 19 个键。
5. **第 14 条要先知道的一件**：「乐手没写响度」的退路和「新建乐手」写进文件的响度是**两个常数**（今天都是 −6）。只改一个，新歌会在第一次存的那一刻跳 6 dB。统筹 11-12 晚「14 放行」已说「同一个默认」，第 14 条照这个并成一个数。

## 三、「没写 = 程序里的默认」——读的那一侧

### 3-0（统筹点名排第一）整位乐手没写

- **什么时候会有**：一个声部的角色在休息室里没有快照（`lounge/<角色>.json` 不在）。实际只有三种：① 新歌**还没存过**（内存里）；② 新加的声部还没存过；③ 文件被手改过、缺了那份。别家的 MusicXML 进门会造一位「不认识的」乐手（2-16），不算这一种。
- **读的那一侧**（`project.ts`）——全当成小月相 + 她的全套默认：
  - `activeInstrument` → 小月相完整版（模型包按 `TSUKUYOMI_MODEL`）；
  - `candidates` / `candidateJson` / `activeOrDefaultCandidate` → `defaultRole`：小月相 + 小月相（元音）两位、上场的是完整版、力度表 / 演奏法 / 记号怎么唱 / 唱法旋钮 / 署名全用程序里的默认表；
  - `activeCalibrationDb` → **`UNWRITTEN_CALIBRATION_DB`（−6）**；
  - 署名推演照样算小月相在唱（`credits.ts`）。
- **写的那一侧**（`buildEntries`）：存的时候对每个声部 `roleOf(...)` → 没有快照就把 `defaultRole` 整份**明写进文件**（响度用 `BUILTIN_CALIBRATION_DB.tsukuyomi`，今天也是 −6）。存过一次，这一组就不再是「没写」。
- **注意**：读走的是 `UNWRITTEN_…`、写走的是 `BUILTIN_…`，今天碰巧相等。第 14 条把两个并成一个数。
- 哪天加的：`defaultRole` / `activeInstrument` 的退路 10-07；响度退路 10-08（当时叫 `DEFAULT_CALIBRATION_DB`），11-12 改名。告诉人：静默。影响：声音。哪一层：底线。

## 四、写的那一侧：「只写不是默认的」

出声的东西基本明写：

- 休息室：每个声部的角色整份写（没快照 = 默认整份写，见 3-0）。**例外**：老乐手身上缺的键（3-1 那些）存的时候不补，原样缺着再写出去。
- 录音房：每个声部的麦克风轨缺了就造一条明写（增益 0、声像 0、空链、出到总轨）；总轨缺了明写 `{ 0 dB, 限幅开, 空链 }`。**例外**：轨的 `bypass` 只写 true；效果的 `on` 只在关着时写 `false`；效果参数只写设过的。
- 总目录：每次都写渲染核心的版本和哈希（`manifest.core`）。

## 六、照判据回答：只有这个文件、没有我们的程序，复现声音还缺哪几样
