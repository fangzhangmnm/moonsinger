## A. 有意思的颜色（现在各管什么）

| 颜色 | 现在用在 | 现在的意思 |
|---|---|---|
| 蓝 `--accent` #2b6cb0 | 光标、选中的音、开着的钮、现在的模式、EQ 曲线、总轨卡片的边 | 「你在这儿 / 你在动的」 |
| 橙 `--play` #e0702a | 播放线、「听」开着的钮 | 「正在放」 |
| 歌手类别色（tab20） | 每行谱左边的细色条、名字前的小点、播放时正在响的音的圆（`--hl`） | 「这是哪一类歌手」 |
| 绿 `--start` #2f8f5b | 「从这儿放」的起点小旗 | 「从这儿开始」 |
| 红 `--danger` #b0412b | 删掉、「效果全关」亮着、左右相关为负 | 「危险 / 不对劲」 |
| 黄 `--warn` / 金 `--enc` / 蓝 `--info` | 提示条（库里的） | 提醒 / 加密 / 消息 |

## B. 中性

| 颜色 | 用在 |
|---|---|
| 墨 `--ink` #2a2a2a | 音符、字、示波器（很淡的墨色当背景）、小节底色（很淡） |
| 灰 `--muted` #8a8780 | 次要的字、说明、问号、刻度 |
| 线 `--line`、底 `--bg` / `--panel` | 边框、底色 |

## C. 淡色替代（你说可读性差的那一类）——每条要你拍：留着 / 换成别的提示

| # | 哪里 | 现在 | 意思 | 建议换成（不靠淡） |
|---|---|---|---|---|
| 1 | 歌名 / 曲段名 / 作者 / 声部名空着的提示 | 浅灰字 #b9b2a5 | 「这儿还没写，点了写」 | 留着（只是占位，编辑器里才画、PDF 不印） |
| 2 | 隐藏的声部缩成的细行 | 浅灰 | 「这里藏着一位」 | 细行上写名字 + 一个「藏」字小标 |
| 3 | 单声乐器的和弦下面那几个音 | 灰符头 | 「数据留着，但这位只唱最上面那个」 | 灰 → 空心符头 / 打 × ？ |
| 4 | 台上那位不认的记号（力度、演奏法、房子…） | 灰 + 半透明 | 「照画，但这位演不出来」 | 记号旁一个小「×」/ 斜杠 |
| 5 | 不唱的歌词（`lyric-mute`） | 灰 + 半透明 | 「这位不唱字」 | 括号括起来 |
| 6 | 「弹」的鬼音符预览、幽灵音 | 蓝灰 `--ghost` | 「还没写下去的预览」 | 留着（本来就是预览）/ 换成虚线符头 |
| 7 | 「词」模式下记号变淡、「符」模式下歌词变淡 | 半透明 .35 | 「这一层现在点不着」 | 留着 / 不淡，只是点不着 |
| 8 | 按不了的钮 | 半透明 .3–.4 | 「现在不能按」 | 留着（系统惯例） |

## D. 要你拍的

2. C 里每一条：留着淡色，还是换成「建议换成」那一列（或者你说别的）。
