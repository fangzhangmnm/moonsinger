# 选中、点、拖：现在代码里是怎么做的（只读核对）

> created 2026-11-13 by Claude Opus 5.5（MoonSinger小弟）· as-of v0.17.47（5f832ee3）· 只读了代码，一行没改。
> 给统筹对照 `ai-docs/20261113-selection-rules-design.md`（第一节 user 同意的表、第四节要核的四件事）。

先说几条总的：

- 下面的表都是「音」模式。「符」在谱面上和「音」完全一样，只差底下的键盘（`src/app/workspace.ts` `RULES`）。
- 长按 = 按住 0.42 秒不动。鼠标、笔动了 6 像素、手指动了 10 像素就算动了（`src/ui/score-view.ts` `armPress` / `move`）。
- 悬停：谱面上没有任何悬停处理，鼠标悬停什么都不发生。

## 一、按在音 / 休止上

| 手势 | 鼠标 | 笔 | 手指 |
|---|---|---|---|
| 点 | 光标到它后面，不选中、不响（`up` → `tapNote`）。Shift+点 = 把已有的选区扩到它 | 同鼠标 | 同鼠标（「词」里 = 开这个音的歌词框） |
| 长按、原地松手 | 选中它（`up` 里的 `selectHeld`） | 选中它（`longPress` → `selectHeld`） | 同笔 |
| 按下就拖 | 从按下的地方框选（`move`：鼠标没长按就动 = 转成框选） | 改音高（竖拖）/ 改时值（横拖），先动的方向定轴（`move` 的 drag） | 滚动谱面 |
| 长按后拖 | 改音高 / 时值 | 扩选到笔下面那个音（`selDrag`） | 扩选到手指下面那个音 |
| 右键 | 不在选区里 = 先选中它；然后开选区菜单（`contextmenu`） | — | — |

按住音的时候它会响，松手停（拖音高时跟着换音）。

在选区里面的音：

- 点 = 选区没了，光标到它后面。
- 长按后原地松手 = 选区菜单，不重选。长按后拖到别的音 = 从这个音重新扩选（`longPress` 的 `selDrag.menu`）。
- 笔按下就拖、鼠标长按后拖：只改**被按住的这一个音**，选区里别的音不跟着动（drag 只记一个下标）。
- 选区两头的把手（`.sel-handle`）：鼠标、笔、手指都能拖，= 扩 / 缩（`mkHandle`）。

## 二、按在记号、歌词、空白上

| 按在 | 点 | 长按 | 按下就拖 | 右键 |
|---|---|---|---|---|
| 力度、渐强渐弱、风格这类（`Layout.dyns`；只在「音」「符」） | 它的小菜单（`markMenu`） | 拿起来；拖 = 挪到别的音或休止上；原地松手 = 小菜单（`startLift` / `endLift`） | 鼠标 = 框选；笔 = 直接拿起来挪；手指 = 滚动 | 小菜单 |
| 谱头（谱号 / 调号 / 拍号；速度） | 谱头面板（点在四周放宽的那一圈也算，`headerHitAt`）；速度 = 速度框 | — | 鼠标、笔 = 框选（松手时没动过才算点，`boxTap`） | 空白菜单 |
| 演奏法（跳音、重音、保持…） | 没有自己的点击区：点在上面 = 点在空白，或者落到附近的音上 | 同空白 | 同空白 | 同空白 |
| 歌词（在「词」里） | 开那个音的歌词框（`lyricAt`） | 有字的：拿起来；拖 = 挪 / 合；原地松手 = 选中这个音 | 鼠标 = 框选；笔 = 直接拿起来；手指 = 滚动 | 空白菜单 |
| 歌词（在「音」里） | 当空白：光标落到最近的落点 | 空白菜单 | 框选 / 滚动 | 空白菜单 |
| 空白 | 光标放到那一行最近的落点；落点是行末 = 光标画在行末（`placeCaretAt`） | 光标放到那里 + 空白菜单（`blankPress`） | 鼠标、笔 = 框选；手指 = 滚动 | 空白菜单 |
| 歌手名、歌名、作词作曲、曲段名、和弦级数 | 开各自的牌或框（`tap` 的前几步，任何模式都认） | — | — | 歌手名 = 歌手牌 |

框选（`boxSelect`）只看按下的那一行谱：符头中心落进框里的音 / 休止，从第一个到最后一个选成一段；一个都没框住 = 光标回到按下的地方。框跨到别的行不算。

别的模式：

- 「词」：不拖音；记号不能点也不能拿。
- 「听」：点只认看谱的（歌手名、翻纸…）；长按 / 右键 = 「从这儿放」的小菜单；拖 = 滚动。
- 修改锁锁着：能放光标、能选中；不拖音，不开记号、歌词（`lockedRules`）。
- 合租叠起来的那一行：只读；点 = 展开这一家，光标落在点的地方（`expandFamilyAt`）。

## 三、键盘上和选中有关的

| 键 | 没选中（只有光标） | 只选了一个音 / 休止 | 选了好几个 |
|---|---|---|---|
| 音键 | 写在光标处：先吃掉光标后面紧挨着的休止，不够才把后面的推后（`overwriteInsert`） | 叠进去或拿掉（单声乐器 = 换音高）（`xorSingle`） | 整段换成一个一样长的音，然后选中它（`fillSel`） |
| 0（休止） | 后面是休止 = 往前吃掉那么长；后面是音 = 插进去、后面推后 | 变成一样长的休止 | 整段换成一样长的休止 |
| — | 拉长光标前那个音（先吃后面的休止） | 长一步 | 不动 |
| ⌫ | 前面是音 = 变成一样长的休止，光标退到它前面；前面是休止 = 按长短档删、后面合拢 | 短一步，空出来的变休止 | 整段变成一样长的休止 |
| Delete | 删光标后面那一个 | 删掉、后面合拢 | 删掉、后面合拢 |
| Shift+← / → / Home / End | 从光标起选一个 / 选到这一段头尾（`selext` / `seledge`） | 扩 / 缩 | 扩 / 缩 |
| 叠（小键盘，按一下锁住） | 选中光标前那个音（变成「只选了一个」）；再按 = 回到它后面 | — | — |
| Shift+1–7 | 这一级叠到光标前那个音上，已经有了就去掉 | — | — |

## 四、不好点或者点不中的

1. **和弦下面的音**：鼠标、笔的点击区只有最上面那个符头和休止（`hits` = `Layout.notes` + 休止；`Layout.chordHeads` 不在里面），竖着只放宽 0.9 个线距。点在离最上面远的符头上 = 点在空白，拖了就是框选。手指按指尖大小找，离得近的能点中。
2. **符干、符尾、连音线、连线、连音括号**：都不是点击区。点符干尖 = 点在空白。
3. **演奏法**：见第二节，没有点击区。
4. **力度记号压在音上**：点到的是记号（`tap()` 先查记号，再查音）。
5. **歌词行和下一行的高音挨着**（「词」里）：点歌词位时先看是不是点中了音，点中音就算音。

## 五、统筹要核的四件事

1. **小节是不是整张纸共用的：不是，每位歌手各数各的。**
   - 每条轨按自己的拍号、自己插的「|」、写满自动换来数小节（`src/render/frame/units.ts` `unitsOf`）。拍号也是每一行谱头各写各的：谱头面板写着「只管这一个声部这一段」；只有开头的速度是整张纸一起改（`src/score/song.ts` `setMark`）。
   - 横向按时刻对齐（`src/render/spacing.ts`：一列 = 同一时刻的各行），所以拍号一样、没人多插或少插「|」的时候，小节线自然对齐。有一位多插了一个「|」，它那一行的小节线就落在别处，从那儿起重新数。
   - 折行只在「有小节线、并且没有哪一位的音跨过这一拍」的列后面（`src/render/engrave.ts` 头注释）。
   - 小节号：每一行取这一行第一位有东西的歌手的数（`engrave.ts` 小节号那一段）。播放时的小节底色取第一位不是房客的歌手的数（`engrave.ts` 5¾ 那一段，`Layout.measures`）。
   - 所以：第三节第 2 条「一跨行就按整小节算」要的那个「小节」，数据里没有一份共用的，得现算（比如按第一位的数，或者按各行小节线时刻的交集）。
2. **光标在音上时打字：没有「光标在音上」这种状态。** 光标永远在两个东西之间，点一个音 = 光标到它后面。
   - 接着打字 = 在那儿新写一个音：先吃光标后面紧挨着的休止，没有休止就把后面的推后（`song.ts` `writePitch` → `overwriteInsert`）。
   - 唯一的例外：光标后面第一个占时值的是「还没有音高的音」= 填它（`fillTarget`）。
   - 要换掉一个音，得先只选中它（长按、鼠标长按松手、Shift+←、叠）。这时按音键 = 叠进去或拿掉（XOR），单声乐器 = 换音高（`xorSingle`）。
3. **单行粘贴：只有一种，看有没有选区**（`src/score/clipboard.ts` `pasteTokens`）。
   - 有选区 = 把选中的那一段换成贴的内容；长短不一样时，后面的跟着挪。
   - 没选区 = 插在光标处，后面的推后。不吃休止，这一点和打字不一样。
   - 光标在后面补齐的淡色小节里：先把前面空着的落成休止，再贴。
   - 两层剪贴板：系统剪贴板里的字和上次复制的不一样 = 当简谱文字读进来；一样 = 用 app 里存的原样那一份（`main.ts` 粘贴那一段）。
4. **单行复制：带歌词，也带挂在音上的记号。**
   - app 里那一层 = 选中的那一段原样切下来（`copyTokens`）：歌词、连音线、音身上的演奏法、叠音、中间的小节线、句号和记号都在。另外往前带上紧挨着第一个音、挂在它身上的力度 / 渐强渐弱 / 风格 / 踏板（`clipFrom`）。
   - 系统剪贴板那一行简谱文字带歌词（`/字`）、连音线、力度（`[mf]`）、调号、拍号、速度，**不带演奏法**（`toJianpu`）。
