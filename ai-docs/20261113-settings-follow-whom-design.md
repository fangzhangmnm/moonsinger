# 每一项设置跟着谁：歌、账号（歌库）、设备

> created 2026-11-13 by Claude Fable 5.2（MoonSinger 统筹）。as-of 开发版 v0.17.33。
> 状态：**设计稿。** 跟账号 / 跟设备那一半 user 回了（第一次连上歌库用甲、两个循环跟设备、界面语言跟账号）；第五节是重想之后的提案，等 user 对分类点头。两半并成一件再排施工，没排之前不施工。

## 起因

user 2026-11-13（原话）：

- 「习惯我建议跟着账号，只有极少数跟着设备。理一下吧」
- 「自动翻页反而是跟着设备的。weebpaint专门有分类和图标标记，你看一下」

现在写歌软件里，这台设备的四样看谱习惯（习惯看的谱、移调辅助、中央 C 叫 C 几、和弦写法）记在浏览器里。iPad 上选了，电脑上要再选一次。

## 一、判据（照画画软件的）

每一项设置答两问：

1. 换一台机器，它该不该跟着你走？
2. 换一个人用这台机器，它该不该跟着换？

- 纯口味的：跟账号。
- 和硬件、屏幕大小、这台机器上发生的事绑着的：跟设备。
- 这首歌自己的：写在歌的文件里。

## 二、分类表

| 跟谁 | 哪些 | 为什么 |
|---|---|---|
| 账号（歌库） | 习惯看的谱、移调辅助、中央 C 叫 C 几、和弦写法 | 纯口味，换台机器还是你 |
| 账号（歌库） | 「初始设置问过了」 | 跟着习惯走，不然每台新设备都再问一次 |
| 设备 | 谱面缩放 | 屏幕大小 |
| 设备 | 自动翻页、提前翻多少 | 屏幕一次能看几行（user 定） |
| 设备 | MIDI 那几样 | 这台机器接的硬件 |
| 设备 | 音源库装没装、删没删；渲好的声音 | 这台机器上的缓存 |
| 设备 | 上次开的哪首、连的哪个歌库 | 这台机器上发生的事；登录之前就要读 |
| 设备 | 修改锁解没解 | 家规定的：跟设备、一天过期 |
| 设备 | 诊断记录 | 这台机器的事 |
| 这首歌 | 页面设置里选过的每一项；谱、乐手、混音 | 文件就是语义 |
| 只管这一次 | 视图范围（本段 / 全部）这类 | 不记 |

**user 2026-11-13 定的两样**（原话：「然后两个循环跟设备跟设备，界面语言跟账号」）：

- 两个「循环」（编辑器的、歌库播放条的）：跟设备。
- 界面语言：跟账号。

## 三、「跟账号」具体是什么

- 存在你的歌库里（OneDrive 上写歌软件自己的那个文件夹；用硬盘文件夹当歌库的，就存在那个文件夹里）。哪台设备连上同一个歌库，看到的习惯都一样。
- 走同步库现成的「设置」通道，画画软件用的就是它。写歌软件不自己碰网盘。
- 两台设备同时改了同一项：后改的算数。这只对设置这样；歌的内容不这样，照旧弹冲突。

### 没登录的时候

- 习惯照旧记在这台设备上，和现在一样。

### 开机不闪

- 设备上留一份账号里那几样的副本。开机先照副本画，歌库连上之后以歌库为准；不一样就换过来。
- 副本只是缓存。删了不丢东西，连上歌库就补回来。

### 第一次连上歌库时（user 2026-11-13 定：甲。原话「第一次量上歌库的时候用甲」，「量」= 连，语音）

设备上已经选过习惯，账号里还什么都没有。两种做法：

- **甲（定了）**：把这台设备上已选的存进账号，底下说一句「这台设备上的习惯已经存进账号」。
- 乙（不做）：再弹一次「初始设置」卡，卡上先填好这台设备上已选的，你点「好」才存进账号。

账号里已经有习惯、和这台设备上的不一样时：照账号里的，说一句「习惯照账号里的」。

### 做了之后会变的

- 手机和电脑不能各用一套习惯了。想在某一台上不一样，只能在歌里单独选。
- 你现在的 iPad 更新到这一版时，按上面「第一次连上歌库」走一次。

## 四、界面上怎么看得出来

照画画软件：设置里每一行后面一个小图标，按住或悬停出一句话。

| 图标 | 意思 | 那句话 |
|---|---|---|
| 音符 | 跟这首歌 | 跟这首歌走，存在歌的文件里 |
| 唱片箱 | 跟账号（歌库） | 跟你的歌库走，哪台设备打开都一样 |
| 屏幕 | 跟设备 | 跟这台设备走，不同步 |

- 三枚图标共享图标库里都有（`music-note`、`music-library`、`device`），不用新画。
- 设置面板里标「歌库」「设备」两种；页面设置里的都是「这首歌」，在面板标题旁标一次，不逐行标。
- 设置面板原来的规矩是「只管这台设备上的软件」（2026-11-12 分六页时定的）。习惯跟账号之后改成：设置 = 不属于某一首歌的东西，分「跟你的歌库」和「跟这台设备」两种，靠每行的小图标分清。
- 「初始设置」卡开头那句「记在这台设备上」跟着改：登录了写「存在你的歌库里」，没登录写「记在这台设备上，登录后跟着你」。

## 五、页面设置第一格：重想之后的提案——拿掉，新建时写下来（等 user 对分类点头）

第一稿写的是把「跟着软件」改名「照我的习惯」。user 2026-11-13 看了之后（语音，原话）：

- 「对，就是核心辅助的显示，就是这些打印到页面上的显示，我们歌里都要能覆盖。还有就是这个中英文，我们是不是一直都没做？就我们这个歌里应该能选择中英文语言。」
- 「…就相当于你点那个纸的显示模式，然后改，就相当于有不同的选项，还有一个照我的习惯。但是其实说就是大部分时候你都是调成你的习惯就行，不会主动选照我的习惯，因为照我的习惯是我们上次那一轮混乱之后我说的就是这些选项都给一个跟的默认，但其实最一开始的设计是你这个默认是只创建新歌的时候写下来，就是说我还是比较倾向于写下来，然后之后这张谱就一直是这个样，别人觉得看起来不顺眼就。要不我们分下节吧，就是说我还是分一下哪些是可以跟着软件设定的，哪些是软件设定的默认值只是控制新建的文档，然后你新建了之后就写下来锁定的。」
- （随后打字）「照我的习惯我还是觉得这个在用户交互上设计怪怪的，你再考虑一下我的情况。」

统筹的读法（已当面说，他可改口）：「核心辅助」= 和弦辅助这类辅助；「分下节」= 分一下类。

**统筹重想之后的判断：**

- user 的情况：一个人写歌，几台设备，习惯跟了账号之后每台设备都一样。「跟着」这一格对他唯一起作用的时候，是以后改了习惯、所有没单独选过的老歌一起变样。这正是他不想要的。
- 别扭的根子：下拉里别的格子说的是「这首歌是什么样」，只有这一格说的是「这首歌不规定，看谁在看」。两种东西摆在同一个下拉里。
- 所以不改名，整格拿掉，回到他最早的设计：新建那一刻把习惯抄进歌里，之后歌里写什么就是什么。

**分类（提案）：**

| 类 | 哪些 | 怎么办 |
|---|---|---|
| 新建时写下来，之后不跟 | 看什么谱、移调辅助、和弦辅助、和弦写法、中央 C 叫 C 几、演奏法和表情、小节号、歌词排法、纸张、音符密度、谱上的语言 | 歌里写什么就是什么，谁打开都一样；页面设置每一行只有实打实的选项 |
| 一直跟着软件 | 排版规则里的数；每种纸自己的边距、每档密度的谱高（没单独设的时候） | 不是选择，是软件怎么排；软件改进了老歌跟着变 |
| 不进歌 | 跟账号的、跟设备的（第二节） | 见第二、三节 |

**跟着要定的几处：**

- 习惯的作用变成一个：新建歌那一刻的种子。四样习惯之外的几项，种子是软件的默认。
- 页面设置顶上一颗钮「套用我的习惯」：把那几样写成现在的习惯。是动作，不是状态。取代现在的「全部跟着软件」。
- 老歌里这些项现在写的是 `"default"`：以后这个值不再有定义。照文件纪律，读不懂的值按「没写」处理 = 像新建一样补（照打开那一刻的习惯），下次存的时候写成具体的值。不弹框，不留按版本分的路。
- 「谱上的字」那一行（跟着界面 / 中文 / English，v0.17.3 起就有）：改名「谱上的语言」；「跟着界面」那一格同样拿掉，新建时写下当时的界面语言。
- 「初始设置」卡和设置「界面」页的说明改成「只管新建的歌」。
- 边距、谱高现在的第一格「跟着软件」：意思其实是「这种纸自己的边距」「跟着音符密度」，留着，名字改成这个意思。
- 这会拆掉第 17 条（v0.17.21–22）「每项可选跟着软件」的一半：`src/look` 里「歌里是 default → 设备的习惯 → 软件的默认」三层读法，变成「歌里的值」一层；习惯只在构造新歌时用。

## 六、这件事会长成什么（给以后加设置的人）

- 以后每加一项会记住的设置，都要答第一节那两问，登记在一张表里：键、跟谁、为什么。没登记的键测试会红。
- 表只有一份。读写都走一个出口，按表里写的「跟谁」去对的地方读写。别处不许直接碰设备键或同步库的设置通道。
- 「跟账号」的键没有歌库时落到设备上；有歌库时以歌库为准、设备上留副本。这条规矩写在出口里一次，不在每个键上各写一遍。

## 七、施工的轮廓（user 点头之后再细化成施工单）

1. 只读清点：现在所有会记住的键，一个不漏，按第二节的表标上「跟谁」；交统筹审。
2. 一张登记表加一个出口；先把现有的设备键原样搬到出口后面，看上去不变，守卫钉住「没登记的键不许用」。
3. 接上同步库的设置通道；四样习惯和「问过了」改成跟账号；没歌库时落设备、有歌库时留副本。
4. 第一次连上歌库那一下（甲或乙）。
5. 设置面板每行的小图标；「初始设置」卡开头那句。
6. 界面语言搬到账号；两个循环留在设备（user 定了）。
7. 第五节定了之后并进来：新建时写下习惯；页面设置拿掉「跟着」那一格、加「套用我的习惯」；读老歌里的 `"default"`。
8. 仓说明的持久层白名单改成指向那张登记表。

动同步那一层之前，施工方先读模式库的总纲和同步库的接入说明；第 3 步的接法先发统筹看。同步库现在钉的是 2.3.2，要不要顺带升，到时候另问。
