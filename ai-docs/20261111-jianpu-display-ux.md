## 1. 原则

1. **全量、不静默**（§55，进了 CLAUDE.md）：每个 token 和它身上的每样东西都画出来；可以小、可以用课本写法，不能没有。隐藏的声部 = 细行。
2. **显示和 token 一一对上**（§53）：一个 token 可以画成几个字形（横线、一拍一个 0），几个 token 不许合成一个字形（「休 6」不行）。
3. **不靠删来安静**（§28、§33、§39、§43）：靠轻重层次；重复就是视觉节奏（团子的满篇跳音、满篇三连都照画）；乱来自不规则，不来自多。
4. **有歧义就提示**（§62）：能有几种读法的，右下角小三角，点开换。
5. **点一下就说明**（§28、§58、§74）：记号、修饰、力度点开说它是什么。
6. **时长是对数的**（§38）：时值靠离散的档 + 字形，间距只松松地跟，不一比一。
7. 年龄只是逼出好设计的参照：认知轴管交互、教育轴管显示（§15）；不做儿童产品（§15）。

## 3. 谱头与八度

- `1=♭A  4/4  ♩=100`；小调写 `6=D`（§47）；中途换调 / 换拍号 = 在那一点写新的（默认，§70）。
- **八度基准 = 每行自己的「1=」，字母上下加点**；**按乐器音域自动定**（目录里的音域 / 记谱习惯；查不到退回「点最少」）；数字上下一个点可以、偶尔两个，极端才挪基准；在变化的那一点画出来（§57 §69）。

## 4. 音和时值

- 数字 1–7、0 休止；高八度点在上、低八度点在下划线下面；临时升降 ♯4 ♭7 ♮3（标准）。
- 下划线按拍分组；数字 = 四分、横线 = 加一个四分、附点 = 加一半；6/8 下划线三个一组（AI 记忆，没拿真课本核，§47）。
- **整小节休止 = 一拍一个 0**（帮唱的人倒数，§53）。
- **连音**：小字数字压在下划线上、下划线断开让位（§44）；没下划线的 = **带钩细括号**，放在下划线下面一层（§46 §69）；三连**每组都标**（§70）。

## 5. 数字上方的记号（从数字往上）

- 数字**一律不分粗细**（§51）。
- **顿音（跳音）= 窄小的楔形**，贴着数字（简谱的点被八度占了；五线谱照旧小点）（§58 §59 §68）。
- **单音轻重**（互斥，一个音一种）：强音 `^`、重音 `>`——都是常规粗细的线（§60）；**次重音 = 细一号的 `>`**（§61 §63）；弱化 `˘`（§51）；**幽灵音 = 数字小字**（§52）。帽子在顿音上面。
- 保持 `–`；换气 `V`；出声的换气 `V 吸`（§70）。
- 延音线 / 圆滑线 = 弧线；**一字多音 = 歌词后面的延长横线**（弧线只给真的圆滑线，§57）。
- 气声 = **数字 + ×**（认的黑 ×、不认的灰 ×；音高看得见，§57）。

## 6. 力度道（最上面一道）

〔2026-11-11 夜更正：这一节头三条（中文写中文字、突强 / 强后弱写中文、英文界面才用字母）作废，改成一律字母 pp…ff、sfz、fp；中文叫法留在说明里。楔形两条和「力度道和演奏法道之间留够」不变。〕

- 中文：**极弱 / 很弱 / 弱 / 中弱 / 中强 / 强 / 很强 / 极强**（ppp…fff；不用「最」，§49 §54）。
- **突强 / 强后弱**（sfz / fp）写在力度道（§65）。
- 英文界面 = **标准字母 + 点一下说明**（§74）。
- 渐强 / 渐弱 = 楔形；渐到 = 虚线楔形（默认）；音内起伏 = 这个音上方的小楔形（§70）。
- 力度道和演奏法道之间留够，不打架（§56）。

## 7. 和弦、多声部、鼓

- 每个声部一行；**和弦竖叠，只压高、不缩宽**（§54）；琶音 = 竖波浪（§47）。
- **左边挂的东西（琶音、升降号、以后的倚音）让位**：当这个音左边的最小占地，前面有空就不挪，会撞小节线 / 前一个音才推这一个音（§67）。
- **折叠成和弦**（每轨选项）：**能还原就折**——名字多对一没关系；标准排法（最低音起、其余一个八度内依次往上、不重复）；转位写斜杠（C/G）；最低音的八度用点；默认读法 = 根音是最低音的优先，输入法候选换，挑中的记进文件；**有歧义 = 右下角小三角**；和弦名用窄字、按实际宽度占位（§59 §60 §62 §64）。还原不了的照画数字。
- 合租：简谱里不并成一行，同一家左边一条竖线包住（§47）；**合租一家合起来认和弦**（§70）。
- 鼓 = `X`，鼓的幽灵音 = 小 `x`（§52）；滚奏 = 数字下面三道短斜线（默认，§70）。

## 8. 排版

- 密度：比 v1 紧，团子人声一行约六小节（§50 §54）。
- 密的声部自己挤紧（短音只占字宽），不撑开全体（§51）。
- 一行最多拉宽约 1.3 倍，放不满就让右边空着（§51）。
- 舒适 / 紧凑 = 两组排版参数（横向弹簧、字边留白、行距、声部间距、歌词距离），所有谱种共用一个深模块（归 Fable，§71）。
- 验收：Once A 段扬琴折叠 + 琶音让位后，bongo 每小节八分等距（§73）。
