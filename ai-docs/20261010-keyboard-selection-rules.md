## 规则

### 1. 光标（没有选区）：写音默认覆盖休止

- 在光标处写一个音 / 休止（时值 d）：光标后面**紧挨着的休止**先被吃掉，最多吃 d 那么长；吃一半的休止留下剩下的那截。
- 休止不够 d：够的那截吃掉，**差的那截才把后面的往后推**。
- 只吃休止：碰到音、人插的「|」就停（不越过小节线）；中间不占时值的记号（力度 / 句号…）原样留着。
- 「—」（拉长刚写的那个）同样先吃后面的休止，不够才推。
- ⌫ 撤回刚写的那一笔：被吃掉的休止原样放回去，后面的不挪（「撤回本次输入」本来的意思）。
- 光标下 ⌫ 删别的音：**照旧**（没定，见文末）。

### 2. 选了好几个：输入 = 替换整段

- 按音键 / 休止：选区里的音全变成休止（时值不动，人插的「|」和记号留着）→ 选区收成选区开头的光标 → 按规则 1 写（吃掉刚变出来的休止）。结果 = 新音在头，剩下的空间是休止，光标在新音后面，接着写就接着覆盖。
- 新音接过原来第一个音的歌词（只改音高时歌词不丢，10-08 替换模式留下的规矩）。
- 原来的「替换模式」（选区当窗口、写字头、写不出选区）去掉。
- 「—」= 不动；⌫ = 删掉选中的（照旧）；整组移调 / 改时值 = 选区条那一排微调。

### 3. 只选了一个音（或一个休止）= 改这个音

- 音键 = XOR：没有这个音高 = 叠上去；有 = 拿掉；最后一个也拿掉 = 变成一样长的休止；在休止上按 = 变回音。单声乐器的声部 = 换音高（叠不了）。
- 休止键 = 变成一样长的休止。
- 「—」= 长一步（一步 = 长短旋钮现在那一档）：先吃后面的休止，不够才推。
- ⌫ = 短一步：空出来的那截变成休止，后面的不挪；短到不能再短 = 不动。pad 上 ⌫ 的字换成「短一步」，「—」写「长一步」。
- ← → = 换到前一个 / 后一个音（继续在改）；Esc / 点别处 = 回到光标。
- 选中一个音（点它、或者用「叠」）就是这个状态，pad 上「叠」亮着。

### 4. 「叠」键 = 锁定式（Caps Lock）

- 按一下 = 选中光标前那个音（进入规则 3）；再按一下 = 回到那个音后面的光标。没有「只管下一个音」的单次档、没有按住期间。
- 电脑键盘 Shift+1–7 叠音照旧（叠到光标前那个音上）。
