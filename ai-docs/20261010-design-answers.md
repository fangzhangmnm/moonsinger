## 高音下加 8 是什么

高音谱号下面挂一个小「8」= **谱上写的音，实际低一个八度响**。吉他和男高音的谱都这么写：音落在五线谱里面好读，不用一串下加线。
同理：上面挂「8」= 实际高一个八度（短笛）；上面挂「15」= 高两个八度（钟琴）；低音谱号下面挂「8」= 低一个八度（低音提琴、贝斯）。
它只管画：数据里存的永远是实际音高，换谱号不改音。铃这种很高的，「自动」会给它挑「高音 15」或「高音 8」，谱上就不会挂一大串上加线。

## 混音（混音纪元的事；先定功能，再管界面）

### 每条轨默认有哪些旋钮（按「平衡 → 摆位 → 频率 → 动态 → 空间」的顺序）

| 步骤 | 旋钮 | 说明 |
|---|---|---|
| 平衡 | 推子、静音、独奏 | 已有 |
| 摆位 | 声像 | 已有；以后可以加「宽度」（加倍 / 齐唱的轨用） |
| 频率 | 低切 + EQ | 见下面四个投标 |
| 动态 | 压缩（一个「压多少」） | 阈值、比率、起落自动；可选「被谁压」= 侧链（人声一出来 pad 自动让一点） |
| 空间 | 混响发送（一个旋钮） | 发到全曲共用的一条混响总线，不是每轨一个混响（省算力，也更像在同一个房间） |

总轨：增益 + 限幅（已有）。每轨一共约 8 个控件。

### 每条轨的标准 EQ：四个投标

1. **调音台三段 + 低切**：低切（可调频率）、低架（约 100 Hz）、中频（可扫 300 Hz–5 kHz）、高架（约 8 kHz）。小调音台都这样，学会到处通用。4–5 个旋钮。
2. **两刀加一扫**：低切、高切、一个只能往下挖的可扫中频。专门对付「糊」：多数打架靠切低频加中间挖一刀就解决。3 个旋钮。
3. **按乐器自动低切 + 一个倾斜**：低切默认放在这件乐器音域最低音再往下一点（仓鼠的音域数据；月读按她的音域），谱上 / 卡片上写明，能改；再加一个「厚 ↔ 亮」倾斜旋钮。1–2 个旋钮，最 Nokia。
4. **完整的参量 EQ + 曲线图**：五段随便拖。最强，最重，最不 Nokia。

**我推荐 3 当默认、展开是 1。** 你说的 pad 糊掉：自动低切先把 pad 的低频砍掉（pad 的低频最占地方），再在人声那一段给 pad 挖一点，或者让人声侧链压 pad。

## 颜色（tab20）

tab20 = 10 种颜色，每种一深一浅。建议：
- **颜色跟乐器类别走**（仓鼠的分类）：人声、键盘、弦、木管、铜管、弹拨、合成 / pad、打击、鼓、音效，正好 10 类各一个色；同一类的第二位歌手用浅的那一个。
- **画在哪（克制）**：① 每行谱最左边一条细竖色条；② 歌手名字前一个小色点；③ 播放时正在响的音的高亮圆用这一轨的颜色，几个声部同时响时分得清；④ 录音室这一轨卡片顶上一条色边。
- **不画在**：音符本身（保持黑色，好读、好印）；光标和选区（保持现在的蓝，不和类别色混）。PDF 默认印黑白。

## 乐手名写在每行左上？

- 好处：不占谱前那一列，谱可以从最左边开始；每行都看得见是谁。
- 坏处：和谱上方的东西打架。力度现在一律写在谱上面（v0.8.9），行首还有速度、风格记号，左上角正好是它们的位置；每行还要多占一点高度；出版总谱没有这么写的。
- **建议**：名字留在左边，但每行都写；第一行全名，后面写简写（老规矩），加上颜色条。所以简写还要。唯一的例外是横卷：横卷没有「行首」，左边的名字会滚走，横卷里名字应该钉在屏幕左边、贴着每条谱的左上。

## 鼓轨的大概思路

- **一条鼓轨 = 一位鼓手 = 一整套鼓**（GM 鼓组），不是每件鼓一个歌手。
- **谱 = 标准鼓谱**：打击乐谱号（两条竖线）；每件鼓固定在五线谱的一个位置（底鼓在第一间、军鼓在第三间、踩镲在上加线并用 × 符头……打谱软件的通例）。数据 = MusicXML 原生的「无音高音符 + 是哪件鼓」，不是音高。
- **同一拍几件一起 = 叠音**（已有）。手在上、脚在下的两层符干只是画法，以后再说。
- **输入**：光标在鼓轨上时，底座的音键换成鼓件格（底鼓、军鼓、闭镲、开镲、三个嗵鼓、吊镲、叮叮镲……常用的在前，多了滚）；按一下写一下，时值 = 长短档；两键同按 = 叠。
- **演奏法**：开镲 / 闭镲、边击这些在 GM 里本来就是不同的鼓件，不用新记号；力度、重音、幽灵音（军鼓最常用）、风格记号的强弱全部照旧能用。
- **节奏型**：一小节鼓型反复 = 用反复记号或复制。以后可以有「鼓型库」（仓鼠出数据，每个风格一两个经典鼓型，点一下填进一小节），是加分项，不是第一步。
- **播放 / 混音**：走 SoundFont 鼓组，每件按自己的键，固定不变调（已有）；一条鼓轨一个通道，整套一起推。要单独处理底鼓（比如让它压贝斯）以后再拆。

## 鼓的「挂件」是什么

挂件是你 10-10 提的「这里放炮」：在一个音或一个小节上挂一小段谱，而不是让炮手在一条轨上数休止。我在 wishlist 整理里把它归到鼓轨那一轮，只是因为它最常用来放一次性的打击（大炮、锣、吊镲一击、定音鼓收尾），不是鼓轨本身的东西。你说是不成熟理念，就先放着。

## 钢琴「声部层」是什么，有没有毒

**是什么**：一条谱上同时走两条节奏不同的线，符干一上一下。例如右手按住一个二分音符的根音，上面旋律走八分。MusicXML 叫 `<voice>`。

**毒在哪**：现在一条轨 = 一串 token，编辑器像文本编辑器：一个光标、插入后面往后挪。声部层 = 一条轨里两串并行，光标得知道在哪一层；在一层里插音不能挪另一层；两层的小节要各自对齐；复制、粘贴、选区、替换模式、歌词挂在哪一层、力度归哪一层、编排和反复展开……现有的每个功能都要学会「两层」。等于在一条轨里再塞一个多轨编辑器。这个毒是真的。

**每个音画强度**：同意是坑。和弦现在也是几个音一个强度，钢琴其实大多就是这样：一只手按下去差不多一个力度。

**多几轨钢琴反而干净？我同意，而且建议这样**：
1. **数据**：钢琴 = 几条普通的轨（右手 / 左手，需要的话再一条「按住的音」）。每条都是现在的一串 token，所有功能现成可用；每条有自己的力度，「旋律比伴奏响」自然就有了。
2. **踏板记号**：钢琴上「根音按着、上面在走」，真实弹法多半是踩踏板，不是手指按住。加一个踏板记号（Ped. … *，MusicXML 原生）：踏板踩着的时候音一直响到松开。时间线里只是把音尾延长到松踏板，很便宜，而且是标准记谱。这一样就能盖住大部分「按住根音」。
3. **画法（以后、可选）**：同一位演奏者的两条轨可以「合写」到一条谱上，画成两层符干。数据不动，只是画。这和你 wishlist 里「两位歌手不重叠时写在一行」是同一件事。

结论：**不做数据上的声部层；多几轨 + 踏板 + 以后的「合写」显示。**

## 不用挂件，小花怎么写

**是的，就是一条 99% 都是休止的轨。** 真实的管弦乐分谱就是这样：炮手那一份是「休止 120 小节」，然后一下。配三样就不痛：
1. **显示**：连续的整小节休止合成一个「多小节休止」（一条粗横线上写 120，打谱软件通例，MusicXML 原生）；全部视图里整行都是休止的谱可以缩成一条细线（「每行只画有声的」那个 wish 的安全版：只缩不删）。
2. **输入**：在这条轨上点第 N 小节 = 光标跳过去，前面的休止自动补上，不用一个个敲。
3. **数据**：休止就是休止，别家软件照样认。

挂件只是在这套上的语法糖（数据少存一点），不是必须的；先做这三样，挂件可以永远不做。

## 「全量摇摆」是什么

摇摆（swing）= 八分音符不平均：前长后短（大约 2 : 1），爵士、Swing、部分流行的律动就靠它。现在的风格记号只改拍子的**强弱**，不改**时间**，所以选了 Swing 也是直的。
「全量」= 三种演奏者（乐器、元音版、月读）都用**同一个**时间扭曲函数：月读的唱谱必须和乐器的音落在同一时刻，不然 v0.7.35 那种「两条路算得不一样、对不上拍」会再来。已经写成三连音的不再摇；摇多少（0.5 = 直、0.67 = 三连音感、0.75 = 很重）由风格记号给，仓鼠的数据里有范围。没做，没拍。

## 音内渐强 / 渐弱 / 鼓起：最大值 = 原来的音量、只乘一个 ≤ 1 的包络，这样是标准写法吗

**没有统一的标准**：谱上的发夹只说「在这个音里变强 / 变弱」，变多少、以谁为准是演奏者的事。
- 鼓起（messa di voce，<>）的常见讲法是：轻起，长到最响，再收回去；最响的那一刻通常就是写的力度。
- 单个 <：常见是从轻处长到写的力度（或朝下一个力度去）；单个 >：从写的力度往下收。

你说的做法 = **写的力度是这个音的最高点，包络只往下乘**。这是合理的读法，而且有工程上的好处：一个音永远不会比写的力度更响，混音里不会冒出意外的峰。代价：带 < 的音开头会比写的力度轻，想要开头就响得写高一级。

现在的代码是另一种：< 往上走到 +6 dB（超过写的力度）、> 往下到 −6 dB、<> 中间到 +6 dB。要改成你说的（< 从 −6 dB 长到 0；> 从 0 收到 −6；<> 从 −6 到 0 再回 −6）只是 `perform.ts` 里的几行加上测试，旧歌会变（带 < / <> 的音整体轻 6 dB）。**要改的话说一声。**

### 合租怎么区分（user「合租可以是双手大谱号，里面的音画一起，可以想想怎么区分。然后展开之后每一条轨都是单独编辑逻辑独立的」）

数据不动：每条轨还是自己的一串 token，编辑、撤销、选区、复制全照旧。「合租」只是**画法**：几条轨画在同一条谱（或同一个大谱表）上。

**在一条谱上分清是谁的**（按常用程度排）：
1. **符干方向**（记谱的老规矩）：第一位房客符干一律朝上，第二位一律朝下。两位以内这就够了，印出来也对。
2. **休止只画领头的那位**：其他房客的休止不画（或画很淡）。这一条最要紧：99% 是休止的小花轨合租进来，谱上只多出它那几个音，不会多出一排排休止。
3. **颜色（克制）**：符头用这位歌手的类别色（tab20 那套）。只在合租的谱上用，单独一条谱的照旧黑色；印的时候默认黑白。
4. **焦点**：光标在哪位房客身上，那一位正常画，别的房客画淡一点。点到谁的音，光标就去谁那条轨；谱左边写一排小字（右手 · 按住 · 左手），点字也能换。
5. **撞在一起**：同一时刻两位的音挨得太近 = 像二度那样错开；同音高同时值 = 共用一个符头。
6. 歌词、力度：歌词只给领头的那位；力度记号第一位写谱上面、第二位写谱下面。

**合着能不能直接写？** 建议能：写进焦点那位的轨（pad、电脑键盘照常）。想看清楚或者大改 = 「展开」，每位一条谱，跟现在一样。

**钢琴**：大谱表合租。上面那条住右手（可以再住一位「按住的根音」），下面那条住左手；每位都是独立的轨（各自的力度、演奏者、混音通道）。加上前面说的踏板记号，「按住根音、上面走旋律」不用改数据模型就能写。

**格式**：合租 = 一个可选的分组（哪几条轨住一起、单谱还是大谱表），存在 score.json，不升版本。导出 MusicXML 时，合租的那几条轨可以写成一个声部里的几个 `<voice>`，钢琴谱的标准写法，别家软件打开就是一份双手钢琴谱；读别家的多声部钢琴谱，也能反过来拆成几位房客。

**代价**：每位房客一个演奏者 = 一个合成器实例，内存比一条轨多。要不要让同一件乐器的几位房客共用一个实例，做的时候再量。

### 「数小节」：对齐的小帮手（只是点子，user「我先不approve any」）

1. **点哪个小节就写到哪**：在一条稀疏的轨上点第 N 小节，光标跳过去，前面自动补休止，不用一个个敲。
2. **影子**：编辑一条轨时，把另一条轨（比如旋律）的音淡淡地画在后面，对着看。
3. **在这里也加一下**：长按别的轨上的一个音，菜单里「在 X 轨这个时刻加一个音」，自动补好前后的休止。
4. **小节号**：每行开头印小节号（出版谱的老规矩）；光标在哪个小节显示一下；「跳到第 N 小节」。
5. **多小节休止**：连续整小节休止画成一个（粗横线上写数字）。炮手那一份就是「休止 120 小节」加一下。
6. **补齐到这儿**：把这条轨补休止补到另一条轨的光标那一刻，几条轨的尾巴对齐。
7. **抄节奏**：从别的轨只拷「什么时候有音」（不要音高），当成骨架再改音高。

### 摇摆放在一号轨？

是。摇摆是风格记号（Swing / 爵士…）的一部分；风格记号和速度、反复一样，写在这张纸最上面那位歌手那一行（「一号轨」），管整张纸所有歌手。所以不用另找地方，摇摆跟着风格走。

### 有了八度谱号，8va 还有用吗？自动怎么做、什么粒度

有用，两者管的范围不一样：
- **八度谱号 = 整段都高 / 低**：这件乐器（或这一段）整体就在那个音域，比如钟琴、短笛、低音提琴。换一次管一整张纸。
- **8va 线 = 临时冒出去几个音**：大部分在正常音域，偶尔爬上去几个音、一两个小节。为了这几个音换谱号读起来更累（换谱号是大动作），记谱的老办法就是画一段 8va。

**粒度（建议，没做、没拍）**：
1. **谱号 = 纸（曲段）级**：现在就是这样，每张纸挑一个、翻纸有滞后。
2. **8va = 一串连着的音（一个乐句）级**：在已经选好的谱号下，找连续两个以上、每个都要三条以上加线的音（往下就是 8vb），给这一串画 8va；还要三条以上就画 15ma。离得很近的两串（中间隔一个音或一个休止）并成一段，免得一截一截的；起止尽量落在休止或小节线上，不在连音线中间断开。
3. **门槛**：这种音太多（比如超过这张纸的三分之一），说明这一段整体就高，应该换谱号而不是 8va。这一步归第 1 级的自动谱号管。
4. **手写优先**：自己画的 8va / 谱号记号说了算，那一段里不再自动。自动出来的不存进谱（同自动谱号，随时重算）；导出 MusicXML 时照样写出去给别的软件看，读回来认得出是自动的、不变成手写的。
5. **开关**：谱号小菜单里一个「自动八度线」开关，默认开（同自动谱号）。

### 「只看一号轨」

在做：视图里加一个开关「只看一号轨」（每张纸最上面那位歌手，速度 / 风格 / 反复都写在它上面）。和歌手牌的「只看它」是同一套，只是一键到位。

## 第四批（同一晚，edited by Claude Opus 5.5）

### 共用合成器：已经是这样，而且算法上等价

user：「同一件乐器的几位房客共用一个实例 要，优化一开始就做彻底」「不合租的也是能共用就共用这样算法上是等价的吗，还是反而麻烦？」

录音房现在就是这么做的（不分合租不合租）：同一份音源（按内容哈希认）只载一次，采样数据和音色表只占一份内存；每条轨拿一个轻量的「播放器」（TinySoundFont 的 `tsf_copy`：共用那份音源，各自记着正在响的音）。所以：
- **省的是内存**（采样数据，iPad 上要命的那部分）。几条轨用同一件乐器 = 只多几个播放器，很小。
- **出声逐样本一样**：每条轨的音本来就各算各的，再各自进自己的混音通道（增益、声像、效果、侧链照旧分开）。
- **不省的是计算**：同时在响的音还是要一个个算，共不共用都一样。
- 不麻烦：合租以后也走同一套，不用另写。唯一不能共用的是「通道」本身——要是几位房客合成一个播放器，它们的声音就混在一起，分不开推子和效果了。

### 合租：发起处写名字（user「其实我想的是和大炮一样在发起的地方写名字或者缩写…撞了就显示同一个音。只要大炮标签不挤一块就行」）

同意这个方向，比符干方向 / 颜色省事，也更像真谱。做的时候的几个点（不是定案）：
- **什么算「发起」**：这位房客停了一阵（比如一整小节以上都是休止）之后的第一个音；曲段开头也算。
- **标签写什么**：简写（仓鼠 v12 刚给了 123 件的出版谱简写，如 Glock. / Timp.）；同一件乐器有几位房客的再带号（Glock. 2）。
- **不挤**：标签放在谱上方一道，和风格记号那套一样两条道错开；还挤就往后让到下一个音（不挡着音）。
- **之后靠什么认**：符杠只连同一位房客的音；撞了（同一时刻同一个音）画一个符头；剩下的靠旋律走向，读谱的人自己看。

### 歌词不想影响音符的位置（看了你 OneDrive 里的 Greensleeves）

**现在是怎么排的**：每个音那一列的宽 = 节奏要的宽和这个字（加连字符）宽的较大的那个。所以长的字会把音推开（B 段 Green / slee-ves 那几个音间距不匀就是这个），而字是在音下面居中的，往左也会伸到前一个音的地盘里，挨着的两个字还会叠（A 段第二小节的 me wrong）。出版谱的老规矩就是「歌词挤开音符」，现在照这个做，只是还不够好。

**如果要「音符位置只看节奏」**，歌词得让路，建议按这个顺序让（每一步还放不下才走下一步）：
1. **左右借空**：旁边的字没用满的地方借过来，字往左往右挪一点，不再死死居中。
2. **压窄**：这个字横向压到七八成，或者小一号。
3. **上下错开**：和旁边打架的字放到下一行（两条歌词线交错，像两段歌词那样）。
4. **实在放不下**：照样写，画灰、点开说一句「挤了」（纪律：做不到的明说），不偷偷推开音符。

**我建议**做成纸的设置里一个开关：「排版：按歌词（歌词挤开音符，现在这样）/ 按节奏（音符只看时值，歌词让路）」。打字的时候（尤其英文）用按节奏，音符不跳来跳去；要印的时候可以切回按歌词。默认先保持现在这样，等你说。
