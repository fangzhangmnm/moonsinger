## 高音下加 8 是什么

高音谱号下面挂一个小「8」= **谱上写的音，实际低一个八度响**。吉他和男高音的谱都这么写：音落在五线谱里面好读，不用一串下加线。
同理：上面挂「8」= 实际高一个八度（短笛）；上面挂「15」= 高两个八度（钟琴）；低音谱号下面挂「8」= 低一个八度（低音提琴、贝斯）。
它只管画：数据里存的永远是实际音高，换谱号不改音。铃这种很高的，「自动」会给它挑「高音 15」或「高音 8」，谱上就不会挂一大串上加线。

## 混音（混音纪元的事；先定功能，再管界面）

### 每条轨默认有哪些旋钮（按「平衡 → 摆位 → 频率 → 动态 → 空间」的顺序）

| 步骤 | 旋钮 | 说明 |
|---|---|---|
| 平衡 | 推子、静音、独奏 | 已有 |
| 摆位 | 声像 | 已有；以后可以加「宽度」（加倍 / 齐唱的轨用） |
| 频率 | 低切 + EQ | 见下面四个投标 |
| 动态 | 压缩（一个「压多少」） | 阈值、比率、起落自动；可选「被谁压」= 侧链（人声一出来 pad 自动让一点） |
| 空间 | 混响发送（一个旋钮） | 发到全曲共用的一条混响总线，不是每轨一个混响（省算力，也更像在同一个房间） |

总轨：增益 + 限幅（已有）。每轨一共约 8 个控件。

### 每条轨的标准 EQ：四个投标

1. **调音台三段 + 低切**：低切（可调频率）、低架（约 100 Hz）、中频（可扫 300 Hz–5 kHz）、高架（约 8 kHz）。小调音台都这样，学会到处通用。4–5 个旋钮。
2. **两刀加一扫**：低切、高切、一个只能往下挖的可扫中频。专门对付「糊」：多数打架靠切低频加中间挖一刀就解决。3 个旋钮。
3. **按乐器自动低切 + 一个倾斜**：低切默认放在这件乐器音域最低音再往下一点（仓鼠的音域数据；月读按她的音域），谱上 / 卡片上写明，能改；再加一个「厚 ↔ 亮」倾斜旋钮。1–2 个旋钮，最 Nokia。
4. **完整的参量 EQ + 曲线图**：五段随便拖。最强，最重，最不 Nokia。

**我推荐 3 当默认、展开是 1。** 你说的 pad 糊掉：自动低切先把 pad 的低频砍掉（pad 的低频最占地方），再在人声那一段给 pad 挖一点，或者让人声侧链压 pad。

## 颜色（tab20）

tab20 = 10 种颜色，每种一深一浅。建议：
- **颜色跟乐器类别走**（仓鼠的分类）：人声、键盘、弦、木管、铜管、弹拨、合成 / pad、打击、鼓、音效，正好 10 类各一个色；同一类的第二位歌手用浅的那一个。
- **画在哪（克制）**：① 每行谱最左边一条细竖色条；② 歌手名字前一个小色点；③ 播放时正在响的音的高亮圆用这一轨的颜色，几个声部同时响时分得清；④ 录音室这一轨卡片顶上一条色边。
- **不画在**：音符本身（保持黑色，好读、好印）；光标和选区（保持现在的蓝，不和类别色混）。PDF 默认印黑白。

## 乐手名写在每行左上？

- 好处：不占谱前那一列，谱可以从最左边开始；每行都看得见是谁。
- 坏处：和谱上方的东西打架。力度现在一律写在谱上面（v0.8.9），行首还有速度、风格记号，左上角正好是它们的位置；每行还要多占一点高度；出版总谱没有这么写的。
- **建议**：名字留在左边，但每行都写；第一行全名，后面写简写（老规矩），加上颜色条。所以简写还要。唯一的例外是横卷：横卷没有「行首」，左边的名字会滚走，横卷里名字应该钉在屏幕左边、贴着每条谱的左上。

## 鼓轨的大概思路

- **一条鼓轨 = 一位鼓手 = 一整套鼓**（GM 鼓组），不是每件鼓一个歌手。
- **谱 = 标准鼓谱**：打击乐谱号（两条竖线）；每件鼓固定在五线谱的一个位置（底鼓在第一间、军鼓在第三间、踩镲在上加线并用 × 符头……打谱软件的通例）。数据 = MusicXML 原生的「无音高音符 + 是哪件鼓」，不是音高。
- **同一拍几件一起 = 叠音**（已有）。手在上、脚在下的两层符干只是画法，以后再说。
- **输入**：光标在鼓轨上时，底座的音键换成鼓件格（底鼓、军鼓、闭镲、开镲、三个嗵鼓、吊镲、叮叮镲……常用的在前，多了滚）；按一下写一下，时值 = 长短档；两键同按 = 叠。
- **演奏法**：开镲 / 闭镲、边击这些在 GM 里本来就是不同的鼓件，不用新记号；力度、重音、幽灵音（军鼓最常用）、风格记号的强弱全部照旧能用。
- **节奏型**：一小节鼓型反复 = 用反复记号或复制。以后可以有「鼓型库」（仓鼠出数据，每个风格一两个经典鼓型，点一下填进一小节），是加分项，不是第一步。
- **播放 / 混音**：走 SoundFont 鼓组，每件按自己的键，固定不变调（已有）；一条鼓轨一个通道，整套一起推。要单独处理底鼓（比如让它压贝斯）以后再拆。

## 鼓的「挂件」是什么

挂件是你 10-10 提的「这里放炮」：在一个音或一个小节上挂一小段谱，而不是让炮手在一条轨上数休止。我在 wishlist 整理里把它归到鼓轨那一轮，只是因为它最常用来放一次性的打击（大炮、锣、吊镲一击、定音鼓收尾），不是鼓轨本身的东西。你说是不成熟理念，就先放着。

## 钢琴「声部层」是什么，有没有毒

**是什么**：一条谱上同时走两条节奏不同的线，符干一上一下。例如右手按住一个二分音符的根音，上面旋律走八分。MusicXML 叫 `<voice>`。

**毒在哪**：现在一条轨 = 一串 token，编辑器像文本编辑器：一个光标、插入后面往后挪。声部层 = 一条轨里两串并行，光标得知道在哪一层；在一层里插音不能挪另一层；两层的小节要各自对齐；复制、粘贴、选区、替换模式、歌词挂在哪一层、力度归哪一层、编排和反复展开……现有的每个功能都要学会「两层」。等于在一条轨里再塞一个多轨编辑器。这个毒是真的。

**每个音画强度**：同意是坑。和弦现在也是几个音一个强度，钢琴其实大多就是这样：一只手按下去差不多一个力度。

**多几轨钢琴反而干净？我同意，而且建议这样**：
1. **数据**：钢琴 = 几条普通的轨（右手 / 左手，需要的话再一条「按住的音」）。每条都是现在的一串 token，所有功能现成可用；每条有自己的力度，「旋律比伴奏响」自然就有了。
2. **踏板记号**：钢琴上「根音按着、上面在走」，真实弹法多半是踩踏板，不是手指按住。加一个踏板记号（Ped. … *，MusicXML 原生）：踏板踩着的时候音一直响到松开。时间线里只是把音尾延长到松踏板，很便宜，而且是标准记谱。这一样就能盖住大部分「按住根音」。
3. **画法（以后、可选）**：同一位演奏者的两条轨可以「合写」到一条谱上，画成两层符干。数据不动，只是画。这和你 wishlist 里「两位歌手不重叠时写在一行」是同一件事。

结论：**不做数据上的声部层；多几轨 + 踏板 + 以后的「合写」显示。**

## 不用挂件，小花怎么写

**是的，就是一条 99% 都是休止的轨。** 真实的管弦乐分谱就是这样：炮手那一份是「休止 120 小节」，然后一下。配三样就不痛：
1. **显示**：连续的整小节休止合成一个「多小节休止」（一条粗横线上写 120，打谱软件通例，MusicXML 原生）；全部视图里整行都是休止的谱可以缩成一条细线（「每行只画有声的」那个 wish 的安全版：只缩不删）。
2. **输入**：在这条轨上点第 N 小节 = 光标跳过去，前面的休止自动补上，不用一个个敲。
3. **数据**：休止就是休止，别家软件照样认。

挂件只是在这套上的语法糖（数据少存一点），不是必须的；先做这三样，挂件可以永远不做。

## 「全量摇摆」是什么

摇摆（swing）= 八分音符不平均：前长后短（大约 2 : 1），爵士、Swing、部分流行的律动就靠它。现在的风格记号只改拍子的**强弱**，不改**时间**，所以选了 Swing 也是直的。
「全量」= 三种演奏者（乐器、元音版、月读）都用**同一个**时间扭曲函数：月读的唱谱必须和乐器的音落在同一时刻，不然 v0.7.35 那种「两条路算得不一样、对不上拍」会再来。已经写成三连音的不再摇；摇多少（0.5 = 直、0.67 = 三连音感、0.75 = 很重）由风格记号给，仓鼠的数据里有范围。没做，没拍。

## 音内渐强 / 渐弱 / 鼓起：最大值 = 原来的音量、只乘一个 ≤ 1 的包络，这样是标准写法吗

**没有统一的标准**：谱上的发夹只说「在这个音里变强 / 变弱」，变多少、以谁为准是演奏者的事。
- 鼓起（messa di voce，<>）的常见讲法是：轻起，长到最响，再收回去；最响的那一刻通常就是写的力度。
- 单个 <：常见是从轻处长到写的力度（或朝下一个力度去）；单个 >：从写的力度往下收。

你说的做法 = **写的力度是这个音的最高点，包络只往下乘**。这是合理的读法，而且有工程上的好处：一个音永远不会比写的力度更响，混音里不会冒出意外的峰。代价：带 < 的音开头会比写的力度轻，想要开头就响得写高一级。

现在的代码是另一种：< 往上走到 +6 dB（超过写的力度）、> 往下到 −6 dB、<> 中间到 +6 dB。要改成你说的（< 从 −6 dB 长到 0；> 从 0 收到 −6；<> 从 −6 到 0 再回 −6）只是 `perform.ts` 里的几行加上测试，旧歌会变（带 < / <> 的音整体轻 6 dB）。**要改的话说一声。**
