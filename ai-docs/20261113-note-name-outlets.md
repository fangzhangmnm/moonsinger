# 给人看的音名、和弦名、调名：全部出口（施工单第 19 条 19-0，只读）

> as-of v0.17.30 / 2026-11-13 · created 2026-11-13 by Claude Opus 5.5（MoonSinger小弟）· 交统筹审，审过才动代码

**怎么查的**：读代码（`pitchName` / `noteName` / `shownOctave` / `KEY_LABEL` / `keyText` / 和弦读法 `label` 和 `name` 的每个用处，界面字表里扫写死的音名），再在真浏览器里核了一遍：一首降 E 大调的新歌，三种谱 × 移调辅助开 / 关 × 中央 C 叫 C3 / C4 / C5，各记一次键上的字、音域旋钮、「1=」旋钮、谱头。

**例子统一用**：歌是降 E 大调；键盘「1=」跟谱（= 1=E♭ 大调）；看的是实际音高 E♭4（中央 C 上面那个降 E）。

**三个前提**：
- 移调辅助只在五线谱上起作用（`IN_C_APPLIES`）：简谱本来就是首调，字母谱写的就是实际音名。下面写「移调辅助开」时，简谱 / 字母谱和关着一模一样。
- 中央 C 的叫法：v0.17.28 起，八度数字只从一个出口出（`score/pitch.ts` 的 `noteName` / `shownOctave`）。下面每一处都核过；八度数字不经过它的，表里没有找到。
- 调名（1=E♭、E♭ 大调）、和弦的级数（V7、ii）、和弦的根音名（G7、C/E）都不带八度，中央 C 的叫法管不到它们。

## 五、自己打架的地方（同一屏上两处说法不一样）

1. **简谱、字母谱下键上的大字是音名**（K1）：谱上写数字，键上大字写 E♭4。你已经说归键盘那一轮（W-69）。
2. **五线谱 + 移调辅助开**：谱换到 C 调画，键上：
   - 大字现在写级数「1」（K1）；
   - 小字写实际的 E♭4（K2）；
   - 升降滑时写实际的 E4 / D4（K3）；
   - 音域旋钮写实际的 F3–G5（K4）；
   - 「1=」旋钮写实际的 1=E♭（K5）。

   照第 19 条第 7 点（user：「和谱一样，写 C」），大字改成换到 C 调的音名（C4），小字留实际的 E♭4。那时还要你一个一个定，可能打架的是：
   - 升降滑时的字（K3）：写换到 C 调的，还是实际的？
   - 音域旋钮（K4）：写换到 C 调的音域，还是实际的？
   - 「1=」旋钮（K5）：照写 1=E♭，旁边加「键上按 C 调写」小标——就是第 7 点里说的那一处。
   - K6 / K7：都是调名，照实际。
3. **和弦的根音名**：目前只出现在两个地方，两处都和眼前的谱一致，没有打架。
   - 候选小表（S8）：跟着移调辅助走。
   - 简谱的分解和弦（S7）：简谱不受移调辅助影响。

   第 19 条做「标根音」时，谱上叠音上方的字会多一种根音写法，它也要照换到 C 调之后的写（第 5 点）。现成的出口是 S8 那份读法（排版在换到 C 调之后算的）。
4. **中央 C 叫法**：表里所有写八度数字的地方（K1–K4、S3、S4、S5 字母谱）都照它，没有找到漏网的。
