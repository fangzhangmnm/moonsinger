## 1. 一句话

**乐器目录是唯一「选」的地方；乐器设置页只调台上这一件；声部叫什么归声部管理。** 新建声部直接进目录。

## 4. 目录要长的三样（`src/ui/finder.ts`）

### 4.1 顶上两行格子

两行都是**一样大的方块**：乐器图标（目录的图标 sprite）+ 下面一行小字名字；一行几格按屏宽，放不下横着滑，不按字长折行（家规：按钮堆看到就改成格子）。

- **常用**：小月相、钢琴（user 点过头的两件）。另外六件（原声吉他、电贝斯、弦乐合奏、鼓组、合成器 Pad、长笛）是 AI 提的、**user 没批**——先不放，交接清单里问。名单是一张常数表（概念的编号），新文件 `src/gm/favorites.ts`，加减只改表。
- **这首歌的乐器预设**（原来的「这首歌里用过的」）：内容按 §5 的 R4。台上那位高亮；别的声部的预设角上写「在 ⟨声部名⟩ 上」。
- 点一格 = **试听它**（格子高亮、右边键盘弹的就是它），底下出一条确认条「选这个：⟨名字⟩」；再点同一格或点确认条 = 换上。和目录里别的乐器同一个两步（先听、再选），不另造一种点法。
- 长按 / 右键预设格 = 小菜单「复制一份」「删掉」（台上的不能删；别的声部的预设在这里只能拷、不能删）。
- 即兴（歌库里只弹着玩的目录）：只有「常用」一行，没有预设一行、没有确认条。

### 4.2 人声里小月相排第一

展开「人声」这一件时，「谁能演」里小月相排在 Ooh / Aah 前面（user「小月相的优先级肯定是高于那两个 O 和 A」）。

### 4.3 自己的 .sf2 在目录里挑

- 目录里一颗钮「从自己的 .sf2 文件…」（预设一行的末尾）。选了文件 = 列表最上面出现一组「⟨文件名⟩（N 件）」，按 乐器 / 变体 / 鼓组 分小节，一件一行。
- 点一行 = 试听（切出这一件载进试听台，右边键盘弹它）；「选这个」= 换上（= 现在 `addPicked` → `finishAdd` 那条路：切子集、子集留在这台设备上、歌里只记来源）。
- 字节留在宿主（`main.ts` 的 `instPicked` 改名 `ownFile`），目录只拿预设清单。`FinderPick` 加一种 `{ kind: "sf2"; bank; program; name }`；宿主的 `audition` / `cast` 认它。
- 换上之前改名的那个「叫」框不要了：名字 = 预设名。
- 关目录 = 这组消失、字节放掉。

## 5. 乐器预设的规矩（数据；`src/format/`，红线区——只加一个可选字段）

名词：一个声部的角色里有一串**候选**（`CandidateV2`，by value：谁来演 + 全部设置），其中一个在**台上**（`active`）。界面上候选叫「乐器预设」。内置的两位（`CANDIDATE_ID.full` 小月相、`.light` 元音版）每个声部天生就有。

- **R1「调过没有」是算出来的，不是到处记得去标。** 候选加一个可选字段：

  ```ts
  /** 换上台那一刻这位的「设置指纹」（settingsPrint）。现在的指纹还等于它 = 换上来以后没调过。
   *  没有这个字段（旧歌 / 旧版 app 造的）= 当作调过。 */
  asCast?: string;
  ```

  `settingsPrint(c)` = 这位候选去掉 `id` / `castAs` / `asCast` 三个键之后，按键名排好序的 JSON 的 sha256 前 16 位（`src/format/sha256-sync.ts`）。名字、出声的那一件、响度、移调、每一张表、效果链、署名，连同以后才有的不认识的键，全在里面。
  `isUntouched(c)` = `c.asCast` 是字符串且等于 `settingsPrint(c)`。内置两位没有这个字段：它们的「没调过」= 指纹等于出厂那一位（`defaultRole(hum, role)` 里同一个 id 的候选）的指纹。
  **为什么不用一个「没调过」的布尔**：旧版 app（或别的设备上没更新的开发版）打开这首歌、调了响度，它不认识这个布尔、原样写回——新版会把一位明明调过的预设当成没调过、换乐器时删掉。指纹不会：设置变了指纹就对不上，对不上 = 当作调过 = 留着。
- **R2 换乐器时，下台的那位**：`isUntouched` 且不是内置 → **同一次提交里删掉**（连同没别人引用的嵌入字节，`pruneSounds`）；否则留着。一步撤销两样一起回来。三条换上台的路都走同一个函数：从目录选（`castPick`）、点预设（`useCandidate`）、自己的 .sf2（`finishAdd`）。
- **R3 新换上台的那位**：造好之后写 `asCast = settingsPrint(它)`。从目录选的小月相用的是内置那位，不写。
- **R4 「这首歌的乐器预设」一行列谁**：
  - 本声部：台上那位，加上所有 `isUntouched` 为假的候选。
  - 别的声部：`isUntouched` 为假的候选；指纹和已经列出来的相同的不再列（七个声部都是同一套旧设置的小月相 = 一格）。
  - 内置两位没调过 = 不列（它们在「常用」一行）。
- **R5 点别的声部的预设 = 拷一份过来再换上**：`structuredClone` → 本声部里新的 id → **不带** `asCast`（拷来的是调过的，留着）→ `castAs` 一起拷、声部的名字 / 乐器概念跟着换（`withRoleConcept`）→ 嵌入的字节按 sha256 本来就共用一份。原声部那位一个字节不动。永远是新加一位，**不覆盖**本声部已有的任何候选（包括内置的）。
- **R6 复制一份**（同一个声部里）= R5 的特例，名字后面加「 2」，复制出来的那份上台。
- **R7 删**：人点的；台上的不能删（先换）；内置的不能删。
- **旧歌**：没有 `asCast` 的候选全部当作调过——**换乐器不自动删任何旧东西**。
- 「备用的预设也能调」：这一版 = 点一下换上台再去设置页调。要不要「不换上台直接调」等 user 回话。

format 层新函数（都是纯函数，`src/format/project.ts`）：`settingsPrint(c)`、`isUntouched(extras, role, id, hum)`、`withSwap(extras, role, nextActive, hum)`（换上台 + 按 R2 处理下台的那位 + 按 R3 给新的写 `asCast`；`withActive` 留给撤销 / 迁移用，界面三条路改走它）、`withCandidateCopy(extras, fromRole, fromId, toRole, hum)`、`songPresets(extras, song, role)`（R4，给目录那一行）。契约 `contract.ts` 记字段；`test/fixtures/format/shape.json` 更新；不拨版本拍子（同 `castAs`、`finder` 的先例）。

## 7. 边角

1. **标准名下拉去掉会错过什么**：少了「出声用 A、谱上按 B 的标准名和 MusicXML 标识」的一键做法（比如用长笛的声音、谱上叫 Soprano）。改名还在（声部管理）；MusicXML 标识跟着目录选的乐器走。等 user 回话，默认去掉。`src/score/roles.ts` 留着（新声部的默认角色还用它）。
2. 定稿着（锁着）：目录和设置页照现在的护栏（进得去、改不了）。
3. 同一个声部里可以有两位同一种引擎的候选（R5 / R6 会造出来）：先写一条单测核实「角色里有两位小月相、设置不同、台上是后一位 → 出声用的是后一位的设置」。不行 = 停下来报，别绕。
4. 不碰：出声引擎、`src/singer/audio.ts`、同步、歌库。
