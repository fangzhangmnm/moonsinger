## 0. 先看这个：量出来的事实（刀 3 的前提改了）

设计稿 §4b 和愿望单 W-49 写的是「挂在音上的记号把音距撑开」。**量了，不是。** 在 v0.16.32 的排版器上（`sp = 10`，按节奏排，单位 = 线间距，量的是同一行相邻两个十六分音符的列距）：

| 情况 | 列距 |
|---|---|
| 十六分，单声部 | 2.2 2.2 2.2 … |
| 第一个音挂重音 / 前面有 fff / 起渐强 / 前面有风格记号 / 音内 `<>` / sfz / 前面换速度 | 2.2 2.2 2.2 …（**都不变**） |
| 十六分 + 另一声部一个全音符 | **5.1** 2.2 2.2 2.2 … |
| 十六分 + 另一声部四个四分音符 | **3.6** 2.2 2.2 2.2 **3.6** 2.2 … |
| 十六分 + 另一声部整小节休止 | **5.1** 2.2 2.2 … |
| 第一个音带换气 / 带升号 | 3.0 / 3.5（这两样真占宽） |
| 八分三连音，单声部 | 2.85 2.85 2.85 … |
| 八分三连音 + 另一声部八分音符 | 2.85 **5.7** 2.85 2.85 **5.7** … |

原因在 `src/render/engrave.ts` 第 2 步「合成列」：`c.w = Math.max(c.w, u.w)`——**一列的宽 = 这一刻各声部刚开始的音里最长的那个的宽**。别的声部正好是长音或整小节休止，这边一串短音的第一个就被拉到那个长音那么宽。user 看到的「第一个音拉得很长」「同一行小节宽窄乱跳」「鼓那行三十二分挤成一团而别的声部松」「三连音不均不齐」都是这一条。力度 / 渐强 / 风格 / 速度 / 八度线在 `unitsOf` 里本来就是零宽。

另一处：带临时记号的音，符头画在 `c.x + accW + 0.35`，别的声部同一时刻的符头在 `c.x + 0.35`——**同一时刻各声部的符头不对齐**（差 1.3）。

排版一次多久（本机，样张歌《Once upon a Tale》：7 声部 3 段 563 个音）：中位 10 ms。三刀做完不许超过 20 ms（§6 性能门）。

## 1. 刀 3：横向间距——一列多宽

### 1.1 一句话

**一列到下一列多远，看这一刻正在响的音里最短的那个；同一行里前后两样东西真会撞才顶开。** 别的声部的长音只是跨过好几列，不再把这一列撑大。

### 1.2 算法已经写好：`src/render/spacing.ts`（Fable 写的纯函数，24 条单测 `test/spacing.test.ts`）

这次 Fable 把算法本体和守卫一起交了，Opus 的活是**把它接进排版器**，不是重写它。模块头注释是规矩的全文，要点：

- **列**（`SpCol`）：同一时刻各行的东西。两种：**音列**（`items` = 这一列里每一行的一样东西：左伸 / 右伸 / 时值）和**固定列**（`fixed` = 宽；小节线、调号、拍号、行中谱号、句号、不占宽的记号列 = 0）。
- **弹簧**（`idealGaps`）：音列到下一列的理想距离 = `宽(最短的正在响的音的时值) × 这一段占它时值的几分之几`。「正在响」含从前面延续过来的。谁都没在响（各行都是整小节休止）= 最宽 `emptyBar`。
- **顶杆**（`rodsOf`）：同一行里前后两样东西，距离 ≥ 前一样的右伸 + 后一样的左伸 + `pad`。固定列隔开所有行。
- **摆一行**（`placeLine` / `fitLine`）：弹簧 ×(1 + s)，顶杆是下限；排满 = 解 s；超了 = 压，最多压 `squeeze`（现在的 `SQUEEZE = 0.15`），还超 = `over`（换行）。固定列不拉不压。
- **时值 → 宽**（`curveOf(dense)`）：松 = 原来的数（四分 3.6、每翻倍 +0.75、十六分以下 2.2）；密 = 十六分 1.9、三十二分 1.6（user 11-08「很密的十六分和三十二分…压密一点」「正常人都会画密」→ 默认密）。连音 / 附点按**实际时值**落在折线上（八分三连音比八分紧）。**这两张表的数是起点，样张出来 user 看着调，只改表。**

改它的规矩：改 `spacing.ts` 的行为 = 先改 / 加 `test/spacing.test.ts` 里对应的那条；这份单测有两条做过反证（把弹簧换回「刚开始的音里最长的」→ 红 5 条；去掉同一行的顶杆 → 红 1 条）。

### 1.3 怎么接（都在 `engrave()` 的 `drawPaper` 里，第 1–3 步）

1. **`unitsOf` 不再算宽里的「让位」**：`Chunk.w` 不再提前算。每个 chunk 改成带三样：`left`（临时记号 1.3；琶音记号再 +0.9；幽灵音括号再 +0.6——照现在画的地方量）、`right`（符头宽 `W.noteheadBlack / Whole / X…`；附点 +0.6；换气 +0.8；出声的换气 +1.2 / +2.1）、`ticks`（已有）。按歌词排（`song.lyricFit === "lyrics"`）时，歌词算这一位**另一行**上的一样东西（行号另编，比如 `歌词行 = 谱行 + 0.5`）：左伸 = 右伸 = 字宽的一半（中心对着符头中心），带连字符的右伸再 +0.7——这样「长字把音推开」走的是同一套顶杆，不另写。
2. **整小节休止**（真写的休止，一段正好占满一个小节、从小节头开始）和**补齐的淡色休止**：`SpItem` 不给 `dur`、左右伸都给 0。它们不参加间距。
3. **第 2 步合成列之后**，把 `cols` 映成 `SpCol[]`：`c.chunk` 的列 = 音列，`items` 的 `row` = 这个单元画在哪条谱行（声部 2 = 它主人那一行，同一张谱上才会撞）；别的列 = 固定列，`fixed` = 现在的 `u.w`（小节线 1.6 / 反复线 / 调号 `keyWidth` / 拍号 / 行中谱号 / 句号 1.0 / 速度 0.3 / 其余 0）。然后 `gaps = idealGaps(spCols, paperLen, opts)`、`rods = rodsOf(spCols, opts)` 整张纸各算一次。`opts = { curve: curveOf(song.denseShort !== "off"), ...SP_DEFAULTS }`。
4. **第 3 步折行**换成：按小节攒段（`breakableAt` 照旧）；每攒够一段，用 `fitLine(spCols, gaps, rods, 行首列, 这段末列 + 1, 这一行能用的宽, { squeeze: SQUEEZE, justify: false })` 试——`over` = 这一段放不下，换行（行里还什么都没有 = 照旧逐列折）。横卷（`o.scroll`）= 不折，宽给无穷大。行首宽 `headerOf` 照旧。
5. **右端对齐**那一段删掉，换成：每一行定下来之后 `fitLine(..., { justify })`，`justify` = 现在那句条件的反面（不是最后一行且用了 ≥ 60% 才拉满；超了一律压）。`col.x = 行首 + xs[i]`；**`col.x` 从此 = 对齐线**。chunk 单元的 `w` = 到这一行下一列的距离（最后一列 = `end − x`），下游用 `c.w` 的地方（音内起伏的宽、点击框、落点）含义不变。
6. **符头对齐**：`nhX(c) = P(c.x + 0.35)`（去掉 `accW`）；临时记号画在 `nhX − 让位`（现在是 `c.x + 0.2`，等于符头左边 1.45；改成从 `nhX` 往左量，数不变）。歌词中心 `cx = u.x + 0.6`（原来是 `u.x + u.accW + 0.6`）。全文件搜 `accW` 逐处过。`Chunk.accW` 留着当「左伸里临时记号那一截」用，不再进 x。
7. **整小节休止的画法**：不管什么拍号一律全休止字形，画在这个小节两条小节线的正中（`measures` 里有这个小节的左右 x），不画附点；点击框跟着。补齐的淡色休止照旧不画。
8. **开关**：`Song.denseShort?: "off"`（没有 = 压紧，默认）。存档 = `score.json` 可选字段 `denseShort`（照 `barNumbers` 的先例：`src/format/contract.ts`、`project.ts` 的 `KNOWN_SCORE_KEYS` 和读写两处、`test/fixtures/format/shape.json`；不拨版本拍子）。编辑 = `song.ts` 里照 `setBarNumbers` 写一个 `setDenseShort`（一步撤销）。界面 = 纸的设置面板里「小节号」那一行下面加一行「短音符压紧：开 / 关」。PDF 走同一个 `song`，自然一致。

### 1.4 边角（定了，别现场发挥）

- **连杠 / 符尾的右伸**：没连杠、符干朝上的短音，符尾往右伸约 0.7。能在这一步拿到「连不连杠」（第 7 步的分组只看拍位，不看 x）就把它加进 `right`；拿不到就先不加，写进施工记录，刀 4a 把符干算法抽出来时补。
- **行首**：`placeLine` 已经让第一列的左伸往右让；行首宽 `headerOf` 之后直接接它。
- **写字头的零宽列**（`head`）、力度 / 风格 / 八度线 / 反复的零宽列 = `fixed: 0`。它们和后面那个音同一时刻，隔开所有行不影响结果（单测「固定列隔开所有行」）。
- **一个音跨小节拆成几段**：每段各是一个 chunk，各有自己的 `ticks`，照常。
- **合租叠起来的虚拟行、鼓谱**：都是普通的行，不特殊处理。
- **不动**：纵向任何东西（刀 4）、字号（刀 2）、`src/format/` 除了 `denseShort` 一个字段。

### 1.5 守卫和验收

## 2. 刀 4：纵向天际线——贴着音往外摆

### 2.1 一句话

**先把音符本身排好、量出这一行「现在最高 / 最低到哪」，再把挂的东西按离音的远近一样一样贴上去；行距只在真放不下时加，加的是这一行自己的。** 现在是反过来的：先按「有没有力度 / 有没有反复」留固定的道（`geoOf` 里的 `lane0`、`DYN_LANE`、`navD`、`tempoD`、`grooveD`），高度按整行最高的音估，再把东西摆进道里——所以 `<>` 飘得高、`p` 被远处一个高音抬上去、力度字压在符杠上（估的符干长和真画的不一样）。

### 2.2 两步走

**4a 纯重构（版面一个像素都不许变）**：把第 7 步「符干、符杠、符尾」的**几何**抽成纯函数（新文件 `src/render/stems.ts`）：输入 = 一条谱行里的音（x、各符头的谱上位置、时值、拍位、声部 1 / 2、鼓谱的符干规矩），输出 = 每个音的符干朝向、符干尖的位置、连杠分组和斜率、符尾——**全用相对五线谱的局部坐标**（谱上的级数 / 线间距，不带行的 top）。第 7 步改成只管把结果画出来。守卫 = 版面快照 + PDF 指纹原样全绿（不许重冻）。顺手把刀 3 留的「符尾右伸」补上。

**4b 天际线**：

1. **算行距之前**先有每条谱行的两条天际线（上、下）：按 x 分桶（0.25 个线间距一格），每格记「往上 / 往下最远到哪」（相对五线谱顶线 / 底线，线间距）。进天际线的东西：五线谱本身、行首的谱号 / 调号 / 拍号、符头、加线、符干尖、连杠（两端之间直线）、符尾、休止、临时记号、附点、连音括号和数字、延音线 / 连线的弧（包围盒）、换气逗号。这些都只依赖 x 和局部几何（4a 之后拿得到）。
2. **挂的东西按固定顺序摆**，每摆一样就更新天际线，后面的贴着新的摆：

   | 顺序 | 东西 | 摆在哪 | 对齐 |
   |---|---|---|---|
   | 1 | 跳音 / 保持 | 符干另一侧，贴符头（照旧） | 符头中心 |
   | 2 | 重音 / 强音 / 次重音 / 弱化 | 谱上方，这个音自己那一段天际线 + 0.4 | 符头中心 |
   | 3 | 音内 `<` `>` `<>`、sfz、fp | 谱上方，**这个音自己那一段**天际线 + 0.5（不再整行一条里道） | `<>` 从符头左缘到这个音的宽；sfz / fp 符头中心 |
   | 4 | 力度字、发夹、cresc. / dim. 字、渐到的虚线 | 谱上方，**它自己占的那一段**天际线 + 0.4（字的下伸算进去）。用发夹连着的一串（字—发夹—字）共用一条基线 = 这一串里最高的那个 | 力度字照旧对着后面那个音 |
   | 5 | 八度线 8va / 15ma | 这一段天际线 + 0.6，一段一条水平线 | — |
   | 6 | 房子 / Segno / Coda / D.C.… / ×3 | 它那一段天际线 + 0.6 | 照旧 |
   | 7 | 速度记号 | 它那一段天际线 + 0.5 | 照旧 |
   | 8 | 风格记号 | 同上，在速度之后摆（撞了自然叠上去；`GROOVE_LANE` 那套错开退役） | 照旧 |
   | 9 | 小节号 | 行首那一段天际线 + 0.3 | 照旧 |
   | 10 | 和弦级数 | **和弦的右下角**（user 11-08 拍）：x = 符头右缘 + 0.3、靠左对齐；y = 这一段**下**天际线再往下贴 | — |
   | 11 | 歌词 | 一行歌词一条基线 = max(版式的最小值, 这一行歌词占的那些段里下天际线最低处 + 字高 + 0.5) | 照旧 |
   | 12 | 8vb、第二行歌词 | 歌词 / 下天际线之下 | 照旧 |

3. **行高** = 版式的最小值（`SPACING` 里的 `staffAbove` / `rowH…`，照旧是下限）和最后的天际线上下沿取大。没挂东西的行不多留。上下两行之间按各自的最高 / 最低算，**不做两行轮廓的咬合**（以后想更紧再说）。
4. **注解（`ann` 类：推定的灰字、速度 ↑↓、句号、角标…）最后摆，只找空，不许推任何可印的东西、不许加行高。** 理由：注解屏幕画、PDF 不印；它要是能改版面，预览和 PDF 就不一样了。实现上 = 注解那一遍只读天际线、不写。
5. 顺手（user 截图清单里的）：很长的延音线不要贴着符头走直线——弧高跟长度走（0.12 × 长，夹在 0.5–1.6 个线间距之间）；第 2、3 行的记号一律以**符头中心**对齐（user「还是居中对齐」）。
6. 退役：`extentOf` 的估算、`lane0 / DYN_LANE / navD / tempoD / grooveD / ottD` 这套固定道、`GROOVE_LANE`、`topAt`（和弦级数原来靠它，天际线取代）。`dynYAt / noteDynYAt / navYAt / tempoYAt / grooveYAt / ottYAt` 这几张「行 → y」的表换成「这一样东西 → y」。

### 2.3 守卫和验收

- **4a**：版面快照 + PDF 指纹不变（不重冻）；`test/stems.test.ts` 给抽出来的函数补几条（符干朝向、连杠斜率、鼓谱）。
- **4b「局部不变」**：音符 / 符干 / 连杠 / 临时记号 / 休止 / 歌词的字，**相对各自五线谱顶线的位置**，4b 前后逐个相同——只许挂件的位置和行的上下留白变。做法：快照比较器加一种「按谱行归一」的比法（每个图元的 y 减去它所在谱行的 `staffTop`；跨行的竖线不比）。x 一个都不许变。

## 3. 刀 2：字和谱分开缩（紧凑只缩谱）+ 小字

### 3.1 一句话

**排版吃两把尺子：谱的尺子 `sp`、字的尺子 `tp`。舒适档两把一样长（版面不变）；紧凑档只有 `sp` 变小，字和控件还是舒适档那么大。** user 11-08「舒适和紧凑，能不能只改变谱的大小…文字的大小，还是原来那么大」「紧凑的话，歌词先尝试保持原样」。

### 3.2 怎么做

- `src/score/paper.ts` 加 `textScaleOf(p) = STAFF_MM / staffMmOf(p)`（舒适 = 1，紧凑 = 1.4）。`EngraveOpts.textScale?: number`（默认 1）；屏幕（`score-view.ts geo()`）、PDF（`score-pdf.ts printOpts()`）、排版 worker 三处用同一个函数给。量字的尺子（`measureLyric`）的字号 = `LYRIC_EM × sp × textScale`——三处一起改，不然断行不一样。
- 排版器里 `const ts = o.textScale ?? 1, T = (v) => v * sp * ts`。下表「跟字」的：字号用 `T()`，它周围留的地方（那一条的高、字和谱之间的缝）也按 `ts` 放大；「跟谱」的不动。刀 4 之后字的包围盒直接进天际线，大多数「留多少」不用手算。

  | 东西 | 跟谁 | 备注 |

  | 歌名、作者栏、编排那一行、曲段名 | 字 | `TITLE_H`、`PAPER_H` 这几条的高跟着 |
