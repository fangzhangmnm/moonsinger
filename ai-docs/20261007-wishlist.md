## W-11 段分隔（双小节线 ‖ 之类）（added 2026-10-07 by Claude Fable 5.1；之后 Opus 做）
- user 2026-10-07：「wishlist两条，1是段分隔（类似||?）也许可以输入两次小节来快捷输入」。
- 起点：小节线是人插的「|」token（从那里重新数）；段分隔 = 另一种小节线（MusicXML `<barline><bar-style>light-light`），快捷输入 = 连按两次「|」把前一个升级成「‖」。和 W-6 一起交 Opus。

## W-8 谱上的表情记号（mp / mf、渐强渐弱、跳音、重音…）和曲线不打架、只有一份真相（added 2026-10-07 by Claude Fable 5.1）
- user 2026-10-07：「顺便wishlist，我希望sheet上面的表情标记比如mp mf 大于小于号，跳，重音，不要和曲线打架，不要两套ssot。也许可以用曲线自动生成我不知道这样做好不好。这个也许也和数据结构决策有关。想想fl studio里面比mxl多了什么」。
- **user 2026-10-07 定**（契约 §7 第 7 条）：曲线是真相（绝对值、SI、by value 的默认数在候选快照里）；记号从曲线算出来写进 MusicXML，是低保真可视化 + 备份（同速度文字）；丢了曲线才由记号反生成。AI 的「记号为真相、默认演绎不存」作废（默认演绎 = 藏在 app 的约定 = 反弃坑红线）。
- FL Studio 比 .mxl 多的三样：每个音的演奏属性（力度 / 释放 / 微调 / pan）= 我们的曲线；设备上的时间线自动化（按小节拍走，不挂音符）= 录音房的事、以后；音频片段 = 采样库不做，人录的音频以后接住（数据契约 §8）。
