- **W-22 移调乐器：谱面音高 vs 实际音高（约定混乱的大坑）**（added 2026-10-08 by Claude Opus 5.5；仓鼠会话转述 user：「wishlist，导出和编辑显示的时候想一下怎么处理这个约定混乱的大坑」）：
  起因：讲到移调乐器时 user 问「我弹的时候都修正了没有移对吧？」——降 B 单簧管 / 小号写 C 响降 B、中音萨克斯写 C 响降 E、F 调圆号写 C 响 F、低音提琴 / 吉他 / 电贝斯低八度、短笛 / 钢片琴 / 木琴高八度、钟琴高两个八度。
  现状：MoonSinger 里按哪个键响哪个音 = **数据和谱面都是实际音高**；user 的 .mxl 里没有 `<transpose>`。要想的（不是定案）：① 编辑器要不要在实际 / 谱面音高之间切换显示；② 导出 MusicXML 要不要给声部写 `<transpose>`（chromatic / diatonic / octave-change，如给管乐队分谱）；③ 导入别人的谱要认出 `<transpose>` 和吉他的「高音谱号下加 8」（现在都不认）；④ 音域提示永远按实际音高画（仓鼠的 `range` 已是实际发声）。
  数据：仓鼠可以给每个概念加可选的 `transposition`（谱面 → 实际差几个半音，带出处：降 B 单簧管 −2、中音萨克斯 −9、次中音萨克斯 −14、F 调圆号 −7、低音提琴 / 吉他 −12、短笛 / 钢片琴 / 木琴 +12、钟琴 +24），要时找它。

## W-60 古人做好的记谱哲学 / meta：以后参考着玩（远期，不是要求；added 2026-11-11 by Claude Opus 5.5）

- user 11-11（简谱 meta 讨论，引 AI「中世纪的定量记谱法里，三分叫“完全”，记号是一个圆圈；二分叫“不完全”，记号是半个圆」）：「这种古人帮我做的哲学，meta，都wishlist，以后参考着玩」

  2. **形状音符（shape note，19 世纪美国南方）**：不同形状的符头代表唱名，给不识谱的人唱圣诗。→ 和玩具琴「数字外面套形状」、三岁档「角色 = 音高」同一个思路（§11、§34）。
  3. **Tonic Sol-fa（19 世纪英国）**：用 d r m 这样的唱名字母记谱，至今英国 / 非洲合唱团在用。→ 字母简谱的一种（§5、§11）。
  4. **简谱的来历**：卢梭提过数字记谱，19 世纪法国的 Galin–Paris–Chevé 把它做成教唱法，经日本传进中国。→ 简谱本来就是「给不读五线谱的人唱」的发明。
  5. **刻谱的老压缩**：「sim.」（以下照此）、长渐变写「cresc. - - -」、反复记号、八度线——几百年来不删信息也让纸面安静的办法（§33）。
  6. **Chernoff 脸（1973）**：用一张脸的五官画多维数据 = 图元的老例子，也带着它的老毛病（部位抢眼、显眼程度不均）（§34）。

## W-82 音源库里各件乐器并不一样响；我们的引擎不支持调制器；量响度的正确做法（added 2026-11-12 by Claude Fable 5.2；user 问出来的，只记账）
