## 一、user 同意的规矩（2026-11-13 夜）

一句话：**亮着框的就是选中的，选中的才能拖，点空白取消。**

| 你要做的 | 鼠标 | 笔 | 手指 |
|---|---|---|---|
| 让一个东西亮框 | 悬浮上去；点一下就留住 | 点一下 | 点一下 |
| 拖亮着框的东西 | 按下就拖 | 按下就拖 | 拖框边上的把手 |
| 选一段 | 从空白处拉框 | 从空白处拉框 | 点一个，再拖框两头的把手 |
| 从空白处拖 | 拉框 | 拉框 | 滚动谱面 |
| 点空白 | 取消选择，放光标 | 同左 | 同左 |
| 长按 | 只出菜单 | 只出菜单 | 只出菜单 |

user 把这一句话和这张表原样引回来，写的是「同意」，接着说「然后想一下如何支持多声部选择」。

表里已经带着的三处改动（统筹的读法：跟着表一起同意了）：

- 点一下音就选中它。以前是轻点只放光标、长按才选中。
- 手指拖音用把手，不直接拖符头；笔和鼠标直接拖。
- 鼠标拖音不用再长按。以前（10 月）定的是鼠标长按才拖音。

## 二、配套的几条（统筹的提法，和表一起给 user 看过，他没有单独回）

- 拖音是上下改音高；拖记号是左右挪位置。横着拖音改长短去掉。
- 碰撞箱就是看到的大小。叠在一起时小的优先：记号压在音上，点到的是记号。选中时画的框就是碰撞箱本身。
- 顿音、重音这类演奏法各有自己的箱，点一下出说明。
- 在一行里拉框：框碰到的符头里，从第一个到最后一个算一段，中间的记号跟着走。

## 三、多声部怎么选（统筹的稿，等 user）

user 以前说的：

- 2026-11-07：「我不想做 pattern，我们就复制粘贴…做一个刷 pattern，就是对于鼓架，就是你可以选择多个轨，然后以小节为单位复制粘贴，就是说不编程，但是可以有一些快速的复制粘贴方法」
- 2026-11-11：「钢琴格可以并列多个鼓轨，复制的时候。一次多选」「其实五线谱的多track复制我们也一直没做，这个非常头疼，记账」

提法：

1. **选区永远是一个整齐的块：几行 × 一段时间。** 一行里的选区照第一、二节，精确到音。
2. **一跨行，就按整小节算。** 框碰到几行、碰到哪几个小节，选中的就是这几行的这几个整小节，框自己吸到小节线上。理由：
   - 几行一起复制，要紧的是贴过去之后这几行还对得齐。按小节切，不会把哪一行的长音切成两半。
   - user 最早要的就是「以小节为单位」。
   - 代价：想跨行只选半个小节，做不到，要一行一行来。
3. **怎么选到多行**：
   - 鼠标、笔：拉的框竖着盖到几行，就是几行。
   - 手指：点一个，框上下也有把手，往下拖就多一行。
   - 点小节号 = 选中这一小节的所有行。
   - 合租在同一行谱上的几位：框到这行谱，就都算上。
4. **多行的块能做的**：复制、剪切、删除、粘贴、整体上下移（有音高的行一起移，打击乐的行不动）、「再来一遍」。打字不作用，说一句。
5. **粘贴一律盖，不往后推。** 删除和剪切留下休止。往后推会让这几行互相错位。
6. **粘到哪几行**：块最上面那一行贴到光标所在的那一行，其余按谱上的顺序往下数。
7. **贴不下就整块不贴，并说明原因**（下面的行不够；有音高的贴到打击乐的行上，或者反过来；目标那几小节的拍号不一样）。不悄悄丢掉哪一行。
8. **「再来一遍」**：选中一个块，按一下，就在它后面紧接着贴一份，选区跟过去。连按几下就是刷 pattern。

没想的：歌词跟不跟着音走（先照现在单行复制的做法）；不挨着的几行一起选（先不做）。

和后面的大事的关系：块 = 几行 × 一段时间，以后钢琴卷帘里是几个音高 × 一段时间，是同一个形状，不挡路。

## 四、要施工方照代码核的

1. 小节是不是整张纸共用的（每一行的小节线对得上、小节号是同一套）。第三节第 2 条靠这个。
2. 光标在一个音上时打字，是换掉这个音，还是接在后面。
3. 现在单行的粘贴是盖还是往后推；有没有两种。
4. 现在单行复制带不带歌词、带不带挂在音上的记号。

## 五、照现状表对过之后（2026-11-13 夜）

现状表 = `ai-docs/20261113-selection-gestures-current-rules.md`（施工方只读核的）。

### 四件事的结论

1. 小节不是整张纸共用的：每位歌手各数各的，只是横向按时刻对齐。拍号一样、没人多插小节线时，各行的小节线自然对齐。
2. 没有「光标在音上」这种状态：点一个音 = 光标到它后面，接着打字 = 在后面新写一个（先吃后面的休止，没有就推后）。要改一个音本身，得先只选中它，这时音键 = 叠进去或拿掉。
3. 单行粘贴：有选区 = 换掉那一段；没选区 = 插进去、后面推后。
4. 单行复制带歌词，也带挂在音上的记号。

### 单行这一版怎么落（施工方照这个做）

1. **亮框是一种状态，三种来源**：鼠标悬浮（临时的，移开就灭）；点一下（留住）；拉框或拖把手（一段）。
2. **点一个音或休止 = 它亮框，光标到它后面。** 接着按键盘，照现状表第三节「没选中（只有光标）」那一列走，和现在点一下之后完全一样。（这是甲。统筹推荐、先照它做；user 选乙就换成「只选了一个」那一列。）
3. **「只选了一个」那一列**（音键叠进去或拿掉、长一步、短一步）只从「叠」键进，现在就是这样。长按不再进。
   - **2026-11-14 凌晨 user 选了乙**（「点一下音再按音键，是接着写，还是改它本身 应该是改吧」）。第 2、3 条从 v0.17.54 起读成：
     - 点一个音或休止 = 它亮框 + 变成「只选了一个」；接着按键盘照现状表第三节「只选了一个」那一列走。
     - 再点一下已经选中的这一个 = 收成它后面的光标（接着写），和「叠」键再按一下是同一个动作。这一条是统筹配的默认，user 没说。
     - 「只选了一个」不再只从「叠」键进：点一下也进；单声的声部因此有了「只选一个」的正路；长按开菜单留下「只选了一个」不再算副作用。
     - 语气是试探的（「应该是改吧」）：实现做成一处，好退回甲。edited by Claude Fable 5.2
4. **亮着框的才拖得动**：
   - 鼠标：悬浮亮着就能按下直接拖。音 = 现在的拖法；力度这类记号 = 现在的拿起来挪。
   - 笔：先点一下亮框，再按住它拖。
   - 手指：点一下亮框，框边上出一个把手，拖把手 = 上下改音高。直接在谱上拖还是滚动。
   - 按在没亮框的东西上拖，和按在空白上一样（鼠标、笔 = 拉框；手指 = 滚动）。
   - 选了一段时拖其中一个：这一版照旧只动被按住的那一个。整段一起动记进「攒着的」。
5. **拉框**：鼠标、笔从空白处按下拖。这一版还只在一行里；跨行等多声部那一版。
6. **长按只出菜单**：按在音上 = 先亮框再开选区菜单；按在记号上 = 它的小菜单；按在空白 = 空白菜单。原来靠长按做的三件事各有新路：选中一个 = 点一下；拿起记号 = 点亮再拖；扩选 = 把手或拉框。
7. **碰撞箱**：和弦里每个符头都点得中；演奏法有自己的箱，点一下 = 亮框加一句说明；力度压在音上时点到的是力度（现状，留着）；符干、符尾、连线不做。亮框画的就是碰撞箱。
8. 「词」「听」、修改锁锁着时的规矩照现状不动：锁着能亮框、不能拖。
9. 鼠标 Shift+点、键盘 Shift+方向键照旧。横着拖音改长短这一版不动（第二节里「去掉」那一句 user 没回，先不做）。

### 多声部那一稿（第三节）跟着改的三处

- 「按整小节」的小节：块的两头落在**这几行都有小节线的时刻**。平常的歌就是每一条小节线。
- 粘贴的落点 = 光标所在小节的开头；贴上去是把那几个小节换掉，等长，不推。
- 复制带歌词和挂在音上的记号，照单行的做法。

## 六、多声部这一版（user 2026-11-13 夜定了两处）

**盖过**第三节第 2 条和第五节末尾关于「按整小节」的说法：跨行不吸小节线。第三节别的提法（怎么选到多行、块能做什么、粘到哪几行、「再来一遍」、点小节号）user 看过、没有单独回，先照着做。

### 选区是什么

- 选区 = 几行 × 一段时间。一个音或休止算不算在里面，看它的**起点**在不在这段时间里。只有一行时，和现在的「一段」是同一回事。
- 这段时间的两头落在音的起止上，不吸小节线。
- 起点在这段时间之前、响进来的长音不算。起点在里面、尾巴伸出去的算，整个带走。

### 怎么选到

- 鼠标、笔：从空白拉框。框碰到哪几行的符头或休止，就是哪几行；这段时间 = 碰到的里面最早的起点到最晚的终点。
- 框跨了折行的两组谱：同样的算法，行 = 两边碰到的行合起来。
- 手指：点一个；框左右的把手改这段时间，上下的把手加行、减行。新加进来的那一行 = 它在这段时间里起头的那些音。
- 鼠标 Shift+点别的行里的音：扩到那里，时间和行一起扩。
- 点小节号：选中那个小节的时间 × 所有看得见、能改的行。小节照小节号所在那一行的数。
- 合租叠起来的一家是只读的，没展开的不进选区。修改锁锁着：能选、能复制，不能改。

### 选中之后

- 画：每一行各画自己的框。
- 打音符键、休止键、长短键：不作用，说一句「选了好几行时只能整块操作」。
- 退格和 Delete：每一行里选中的变成一样长的休止，不合拢。（单行的 Delete 会合拢；多行合拢会让各行错位。）
- 上下移：有音高的行一起移，打击乐的行不动。
- 复制、剪切：记下每一行的内容，和它的起点离这段时间开头多远。歌词和挂在音上的记号照单行的做法带着。剪切 = 复制，再变休止。
- 系统剪贴板那份文字：一行一份，换行隔开。

### 粘贴

- 落点：光标所在的时刻和光标所在的那一行。
- 行怎么对：块最上面那一行贴到光标那一行，其余按谱上的顺序往下，一行对一行。只数看得见、能改的行。
- 每一行的内容落在「光标的时刻 + 它的偏移」处，把那一段时间里原来的东西换掉。等长，不往后推。
- 落点切到休止：把休止切开。
- 落点的开头或结尾切到一个音的中间：这一版算贴不下。
- **贴不下 = 整块不贴，并说明是哪一行、为什么**：下面的行不够；有音高的贴到了打击乐的行上，或者反过来；落点切到一个音的中间；目标行锁着或只读。
- 一步撤销。贴完选中贴上去的那一块。

### 再来一遍

- 选中一块，按一下：落点 = 这段时间的结尾、同样的几行，照粘贴的规矩贴。贴不下照样整块不贴。贴完选区跟过去，连按就是刷 pattern。
- 放在选区菜单里；键盘上给哪个键，施工方定，写进说明。

### 不做

- 不挨着的几行挑着选。
- 落点切到音的中间时把音切开（记进「攒着的」）。
- 改歌的文件格式。这一版只动运行时的选区和剪贴板；往歌里写还是走现有的口，另加一个「把一行里一段时间换掉」的口。
