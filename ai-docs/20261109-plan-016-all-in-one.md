> 「一个声部在一段里怎么画」分三处放（纸头谱号记号 / 那张纸的 `<staves>2` / `papers[].autoOttava`），看着散，但每一处都有出处，合成一处反而要多养一套读法，不合并（理由写在 `contract.ts`）。
> **查出来、这一版修了的四处**：
> 1. **以前定稿的歌存不了**（这一轮带进来的）：歌里有句号、或者用过旧的「声部默认谱号 / 声部关八度线」，新版一存（比如导出副本）就被定稿护栏拦下、报「内容却变了」、劝人改稿。内容没变，只是旧写法换成了新写法。同一个护栏还有个老毛病：音的内部编号重排也会触发。修法 = 打开时把指纹换成这一版写法的（真被改过内容的照旧作废，有测试）。
> 2. **大谱表那一段里中途换谱号的记号，存一次就悄悄没了**（老毛病，这一轮因为大谱表可以按段随手选而更容易碰到）：现在照写照读。画大谱表时仍然不看它。
> 3. **和弦名里没有标准名的那八种**（7sus4、add9、6/9、7♭9…）在文件里写的就是谱上显示的那几个字：以后谁改了显示的写法，老歌就认不出了。改成一张冻住的表，有测试守着。

### E. 输入规矩（11-11 夜 Fable 会话；属于下一轮，不进这一轮施工；出处 = 谈话日记 §75–§77；added by Claude Fable 5.2）

**拍了**
1. 中间默认永远不推；推和拉是明着的动作（「要推的话，得有一个专门的机制来推」）。

4. 键盘上不加推的键（「键盘现在已经够挤了」）；推归小节线菜单和选区。
5. 小节线把手：只有光标所在的小节有一个；鼠标移到小节线上端才亮；听模式 / 打印不画。
