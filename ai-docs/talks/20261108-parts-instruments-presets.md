## 5. 「交给」是干什么的（user 纠结）

- user：「以及我不太明白交给他这个东西的意义有什么，因为我们已经有选择歌手了，就这个能不能和选择歌手的？嗯，所以说关键是给歌手更换乐器，歌手管理和选择歌手这个比较混乱。」
- user：「我基本从来没用过这个设定，就相当于即使是换，我也是重新配置设计，重新配置乐器，然后重新设置。」
- user：「如果我想快速的换说，比如这一段是给这个乐器演奏，还是给那个乐器演奏，比如说是笛子还是熏。对吧？然后这些笛子和熏我都调好了，这样我就不用一次一次的进去找，而是能快速的切换。它可能唯一只有这个功能，其实不是特别常见。」
- AI 的说法：「换乐器」= 这一行**所有段**换成别的出声；「交给」= **只有这一段**的音搬到另一行（用那一行的乐器和混音台那一条）。按段切笛子 / 埙有两种做法：
  - A. 两行：笛子、埙各一个声部，这一段放谁那一行谁演（= 交给；不改数据，混音台各一条，总谱的老写法）。
  - B. 同一行中途换乐器（像长笛手换短笛，谱上写「换短笛」；要新数据，混音台共用一条；和周账 F-218「乐器 / 演奏手法 / 音色三层 + 同一家合租」同一道题）。
- AI 推荐：现在用 A，「交给」放声部管理；B 和鼓那一轮一起设计。
- 状态：**user 没明确拍 A / B**；AI 按推荐先做 A。

## 6. 歌手和乐器分开，是不是坏设计（user 纠结，核心）

- user：「我们停下来，critical 的想想。」
- user：「对，最常用的是挑乐器，常用的是调好，有时是快速来回比。对，所以说其实就是相当于你平时挑新乐器的时候，是直接从乐器挑，由乐器生成歌手。然后只有说你换乐器的时候，你退役，就相当于你换乐器的时候，你旧歌手会自动退役，对吧？这个逻辑没写好。关键是你这个歌手和乐器分开来，这个心智模型，我就一开始拍的，它实际上是不是一个很坏的设计？你能帮我批判性的想一下吗？」
- user：「对，就是说声部和乐器，然后歌手可能实际上本质是一个乐器预设，就相当于你留好。因为其实我们后面有个情况就是合成器，我们合成器会扭半天，所以我的想法是你更换乐器和更换歌手，但是我又不希望是你这些，因为你一开始默认生成的歌手是人声嘛，我就不希望多一大堆被替换下来的人声，所以这个你怎么看？」
- AI 的判断：
  - **数据里拆开是对的**：「是什么乐器」（谱上写的名字，跟着乐器概念走）和「谁、怎么演」（哪份声音 + 设置，by value）是两层——同一件长笛可以是 GS 的、自己的 .sf2、以后的物理建模；署名、打包、找不到声音时明说，都按后一层算。
  - **界面上拆成两个词是错的**：摆出了「歌手」「乐器」「上场」「候选」「用过的」好几个词，user 脑子里只有一件事：这一行用什么乐器、调成什么样。
  - **换乐器时旧的没有规矩**：每挑一次旧的都留着，越积越多，只能手动 ×。
  - **调好的只在这一行里用得到**：第一行调好的笛子第二行看不到。
- AI 提的改法（数据层不动，只改界面和规矩）：
  - 界面上的词只剩「**声部**」（谱上那一行）和「**乐器**」（它用什么出声，连同设置）；「歌手」不再当界面词。
  - 挑乐器 = 从目录挑，挑了就生成这一行的乐器（= user 说的「由乐器生成歌手」）。
  - 换掉的旧乐器：**没调过的，换掉就不留**（目录里随时能重新挑回来，什么都没丢；新声部默认的小月相没动过 = 换掉就没了，不会堆一堆人声）；**调过的，留在「这首歌里调好的」**（= 预设；合成器扭了半天的那种），点一下连设置换回来，不要了点 ×。
  - 「调过」= 挑进来以后在乐器设置页里动过任何一样（死规矩，不猜）。
  - 调好的**整首歌共用**：第二行也能挑第一行调好的笛子（拷一份过去，各调各的）。
- 状态：**等 user 拍**（退役规矩 + 整首共用）。v0.16.21 那一批先把目录顶上那排改叫「这首歌里调好的」。

## 8. 四颗小钮 → 两颗大钮

- user：「然后是四个小按钮，首先它们非常的小，没法按，这是不对的。我们应该大一点，就是至少要比那些小扳手、本段这些东西大。然后其次是能不能做成智能按钮，或者说我们约定一下，就是说按是静音，长按或者双击是。独奏，然后就是做两个这样的符号，他们得大，非常好点，要粗的手指也能点。」
- user：「右上角那个本段，这个也比较谜语的，应该是只看本段。我觉得这些东西要不都变成图标，反正就是我们图标库里有很多眼睛嘛，就是我们做个眼睛。对吧？眼睛有合上、张开和只看这个，然后声音也是有合上、张开、只看这个」
- AI 方案：两颗大钮（眼睛 / 喇叭）；点 = 隐藏 / 静音，长按（电脑右键）= 只看 / 独奏；不做双击（做了每次单点都要等 0.3 秒）。图标：眼睛开 / 闭用库里现成的 `visibility-show` / `visibility-hide`；「只看」= 睁开的眼睛 + 对焦框四个角；喇叭开用 `volume`；静音 = 喇叭 + ×；独奏 = 喇叭 + 同样的对焦框四个角；「本段」换成那个「只看」的眼睛。代价：名字那一栏宽一点（PDF 那一栏也一样宽，钮不印）。
- user：「嗯，四颗按钮，按你说的做。对，名字难会长一点，但这个也是真的没办法，因为你必须得按这个，你必须得要玩家能舒适的按这个。」
- 状态：**user 拍了，排在 v0.16.21 后面做**；三个新图标进图标库待过目层。
