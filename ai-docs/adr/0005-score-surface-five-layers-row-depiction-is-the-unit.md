# ADR-0005 谱面分五层；能热插拔的单位是「一行的画法」；写法归核心、只有一种；键盘不认谱面

> created 20261111 by Claude Fable 5.2 · status: **accepted**（分层、写法只有一种 = user 2026-11-11 夜拍；另外三条细化是 Fable 的设计，状态逐条写在第 1 节）
> 全文、接口草案、这份设计自己的弱点 = `../20261111-score-surface-architecture.md`（下面叫「设计稿」）。讨论纪要 = `../talks/20261111-two-display-modes-meta.md` 第 75–83 节。施工单 = `../20261111-score-surface-construction-plan.md`。
> 和 ADR-0004 的关系：0004 说插件只挂五处接缝，其中一处是「（以后）显示的接口位」，没说那个位长什么样。本 ADR 把它定下来。0004 其余不变（乐谱数据模型、时间线、指令引擎、键盘库是核心，不插件化）。

## 0. 一句话

从手指到纸分五层：**键盘 → 输入法 → 核心 → 谱面 → 纸面**。每层只知道自己的事。以后加一种谱（简谱、三岁档）= 加一种「一行的画法」；加一块不是纸的谱面（tracker、钢琴格）= 加一块谱面。两种都不动核心、不动键盘。往谱里写音的规矩只有一种，住在核心里，不跟着谱面换。

## 2. 决定

### 2.1 五层，谁知道什么

| 层 | 知道 | 不许知道 | 对外只说 |
|---|---|---|---|
| 键盘（前端库） | 键、锁、旋钮、滚轮这些交互 | 音乐；谱面；谱种 | 哪个键，按下 / 松开 / 滑动 |
| 输入法 | 乐理（读表）；每个键现在有没有意义 | 像素；现在是哪种谱面 | 指令；试听哪个音 |
| 核心（谱 + 光标 + 指令引擎） | token、时刻、写法 | 像素；键；谱种 | 新的编辑状态 |
| 谱面 | 像素 ↔ 哪个音 / 哪个时刻；手势 | 键 | 指令；「这里要开菜单」 |
| 纸面的框架 | 纸、分行分页、歌词、间距、版面家具 | 五线、数字、任何字形 | 版面数据 |
| 一行的画法 | 自己的字形；纵向的意思 | 别的行；纸；分页；键 | 这一行的图元、点击框、占多宽多高 |

「不许知道」做成测试（查 import）。完整的表在设计稿第 3.1 节。

### 2.2 能热插拔的单位是「一行的画法」，不是整页的引擎

纸面 = 一个公共的框架 + 若干种行的画法。框架管纸、分行分页、歌词让路、间距、隐藏声部的细行；画法只管一行里的字形和这一行纵向的意思。谱种（五线谱 / 简谱）是一张表：哪种声部用哪种行。

〔2026-11-11 夜按第一刀的侦察补两句〕「画」一次吃一条轨在这张纸上的所有行（跨行的连线、发夹要前一行的东西），出来仍然是每行一张图元表。框架可以认 token 和记号的种类（那是核心的词），不许认字形和纵向的意思。

user 列的五样不是同一种东西：简谱、三岁档 = 同一份谱换一种画法；tracker、钢琴格 = 换一块谱面（不是纸）；它们各接在不同的层上（设计稿第 4 节）。

### 2.3 横向 = 时间，一张纸只算一遍

所有声部先各自报「每一列要占多宽」，框架一起分配横坐标，再交回去画。每一行出一把时间尺（时刻 ↔ 横坐标），光标、播放线、点击落点、歌词都用它，不各算各的。

### 2.4 写法归核心，只有一种

往谱里写一个音怎么写（盖谁、停在哪、剩下的变什么），是核心的规矩，不是谱面的。同一首歌在五线谱、简谱、以后的 tracker 里按同样的键，谱的变化一样。

### 2.5 键盘不认谱面

键盘只出键事件；键的意思由输入法给；哪个键现在没意义也是输入法说、键盘照着灰。换谱面不换键盘。

## 3. 没走的路（别再提）

- **五样各做一个整页的「显示引擎」并排**（任务书 `../20261111-display-engines-brief.md` 第 3 节的框法）：歌词让路、分页、间距、隐藏声部的细行每种谱各做一遍；而且五样不是同一种东西，装不进同一个接口。
- **先抄一个简谱的整页引擎，以后再合**：简谱早出来一刀，之后每个版面功能做两遍，合回来那一刀很可能一直不做。（Fable 推荐不走；user 11-11 夜说可以开始施工。）
- **每种谱面各有自己的写法**：同样的键在两种谱面里结果不同，要学两套。user 定了同一条写法。
- **键盘跟着谱面换含义**：键盘就得认识谱面，以后每加一块谱面都要动键盘。

## 4. 代价和过渡

- 前两刀（排版分家、谱面视图分家）user 看不见任何变化。换来的是以后每加一种谱只写一种行的画法。
- ~~五线谱的横向间距先留着旧算法（过渡）~~〔2026-11-11 夜更正：写这句时没对代码核。五线谱从 v0.16.33（11-09）起就走共用的间距模块 `spacing.ts`，没有旧算法；合成列、折行、摆第一刀直接归框架。〕现在唯一的过渡 = 「一行最多拉宽约 1.3 倍」这个参数：简谱第四刀先用上，五线谱先关着。**退场 = 施工单第六刀**（打开之前给 user 看对照样张）。第五刀做完时由统筹把第六刀提上来；被搁下就在总表里记成欠账，不许无声地一直过渡下去。
- 没有「纵向 = 音高」的谱（简谱）不提供竖着拖改音高。
- 谱面这一层这一轮不建抽象（只有纸面一个实现），只收窄它向 app 要的东西。第二块谱面真要做的时候再建，到时按它会长成什么重看。
