- **改了源码一定 `npm run build`，dist 和源码同一个提交**；`serve` 不构建、部署只发提交进去的 dist。

- 对 user：中文、人话、不说代号和路径；问话先答再干活；要 user 定的事一个回合问完、每条带「选了会怎样、不选会错过什么」；不给 user 终端命令；不追问 user 真机试了没有。
