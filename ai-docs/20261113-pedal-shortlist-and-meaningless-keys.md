## 一、短名单草稿：没写踏板记号时「留住音」的乐器

**判据**（user 2026-11-13，统筹转述的原话）：「关键是看人类的意图吧。就我前面说，钢琴的踏板和竖琴的踏板的区别，就是一个是你不自动停是一个意图，一个是需要一起停是一个意图。」

- **留住**是特意做的（钢琴：要踩踏板才留）→ 默认**不留**。
- **止音**是特意做的（竖琴：要用手才止）→ 默认**留住**。
- 名单里没有的、自己的音源文件 = 不留（统筹 11-3 的数据定法）。

### 2. 两可（不替 user 判，写两边的后果）

「留住」= 写的时值到了也不停，响到下一次同一个音再弹、写了抬起、或这一段结束。「不留」= 照写的时值停（乐器自己的收尾照样有）。

## 二、「哪些键没意义」只读表（愿望单 W-65 第 1 步）

只读，不改代码。「没意义」分两种灰（统筹的做法）：**A = 现在没意义、按不动**；**B = 台上这位 / 这种画法不用它、照样能写**。最后一列是现在代码里的样子。
「现在」那一列里：灰不灰（样式表、键盘代码里的 disabled / off / is-unplugged / is-locked、「换谱表」藏不藏、符号格的「不认」）是读代码核过的；「按了说一句」「按了不做事」那几格是读代码和仓里的说明推的，没在真 app 里一个个点过。

### 编辑状态

- **S1** 写音（音键那一面），光标在音后面，没有选中 —— 基准
- **S2** 符号格那一面开着
- **S3** 「弹」（人自己拔开，只响不写）
- **S4** 修改锁锁着
- **S5** 正在选乐器（乐器目录 / 乐器页开着）
- **S6** 选中了好几个 · **S7** 只选中一个音 / 休止
- **S8** 光标前面没有音（纸头）· **S8b** 这张纸上还没有音
- **S9** 台上是单声的（小月相 / 元音版 / 没人上场）
- **S10** 台上固定敲一个键（音效固定原速、鼓件：谱上画 × 符头）
- **S11** 台上这位不认这个记号 / 这种踏板
- **S12** 简谱 / 字母谱 · **S13** 这个声部不是大谱表
- （「词」「听」时键盘不在底座上，不列）

### 顺带看到的（这次不改）

1. **← → 在「弹」、锁着、选乐器时也灰着**（见第一张表）。它们不写谱，照总闸的判据不该灰。是现在的毛病，不是新加的。
2. **「换谱表」在不是大谱表时是藏起来**，和「位置不动、不藏」那条做法不一样。
3. 两种灰现在已经有两套样子：A = `disabled` / 透明 0.3、按不动；B = `.ignored` +「不认」小标、照样能写。表里新加的 B（简谱下的谱号、八度线，不管速度那一行的速度 / 反复）可以照用 B 那一套，只是「不认」两个字要换成说这一种原因的字——要不要换、换成什么由统筹定。

## 三、统筹要的另一张小清单：绕过「出声之前那道查」直接拿乐手规格的地方

出声之前那道查 = `core/render.ts` 的 `performerInfoOf` 调 `perfSpecProblems`（规格里每个数过 `Number.isFinite`，不是数 = 这位进「不出声」清单）。直接拿 `activePerfSpec` 没过这道查的：

- **按键试听的力度**：`main.ts` `dynAtCursor`（光标处的力度）用 `dynamicsVel` / `wedgeStepVel` 算按键试听的力度。这两个是怪值时力度会是 NaN，送进录音房的试听声。`softVel` 不在这条路上。
- **乐器页**：`app/panels/inst-settings.ts` 那几张表（「记号怎么演」、力度记号的表、改一档）直接显示规格里的值。怪值 = 字上显示怪值；改一档的那一处会拿它算。只显示、不进音频。
- **「不认」的判断**：`main.ts` `ignoredFor` 只看 `gapSec > 0`，怪值 = 当成不留缝，不出错。
- 这次不改，照统筹说的只列。11-3 里会加统筹要的那条测试（更新版本的文件、`softVel` 写成字符串 → 这位在「不出声」清单里、写着这个键，别的声部照放，不抛）。
