# 踏板和余音：设计

> created 20261112 by Claude Fable 5.2（MoonSinger统筹）· as-of 开发版 v0.17.x / 2026-11-12
> 给施工的会话照着做；方向是 user 定的，细则是统筹定的（哪句是谁的，下面分开写）。动歌的文件，所以先有这一页。

## 1. user 的原话（2026-11-12）

- 「其实我觉得机关枪的实质是，滚奏的快的时候你把尾音给吃掉了，就是它尾巴的包诺，这个有办法系统的解决吗？包括以后如果我们要做古筝什么，每个音会很长，对吧？」（「包诺」= 包络，语音。）
- 「尾音这个东西本来就是 MIDI 的规范，对吧？…如果一开始的实现是错的的话，不应该念旧。」
- 「那么几种踏板也做一下，钢琴也需要，你找个合理的地方排期」
- 「设计：有些乐器默认开踏板，有些乐器默认关踏板，乐器设置里面披露，分自动，默认开。默认关三种。但是用户写了延音踏板之后就无视默认，按用户的来」
- 「钢琴应该是不默认踏板的，但是其他的你可以想一下。我觉得有些乐器反而是你踩下去才是让它停吧」

## 2. 已经量到的（施工记录里有全表；摘要在愿望单 W-85）

- 引擎照规范：松开后按乐器自己写的时间收；同一个键再按不掐上一下；到同时发声上限（每条轨 256 个）先掐松得最久的。军鼓连着敲 = 每一下单独渲再加起来。
- 一松开就收得快的：钢琴、尼龙吉他、颤音琴、筝。松开后照样响很久的：竖琴、Santoor、钟琴。
- 规范管不到、归我们定的只有一件：**谱上的音多长，键按多久**。现在 = 照写的时值按住，到了就松。引擎认延音踏板，谱和乐手设置里没接。

## 3. 一句话

「键按多久」有三个来源，先后是：**谱上的踏板记号 → 乐手的默认 → 照写的时值**。这一轮把前两个接上。

## 4. 数据

### 4.1 谱上的记号（进歌，MusicXML 原生）

```ts
type PedalKind = "sustain" | "sostenuto" | "soft";   // 延音 / 持音 / 弱音
interface PedalTok { kind: "pedal"; id: number; which: PedalKind; act: "down" | "up" | "change" }   // change = 换踏板，只有延音有
```

- 不占时值，和力度记号一样挂在后面那个音 / 休止上；能挂在一段最后（做法照「挂在一段结尾的力度」）。
- 按声部、按纸（曲段）算：每张纸开头三种踏板都是抬着的；纸尾还踩着 = 放的时候在纸尾抬起。不跨纸（同渐强渐弱、反复）。
- 大谱表的声部：踏板管这位的两条谱。
- 不起作用的记号（已经踩着又踩一次、没踩就抬——包括「这位默认踩着，又写了一个踩下」）：**照画、画灰、点开说为什么**，出声不变；不丢、不替人改（同被盖掉的力度字）。

### 4.2 乐手的默认（进歌，按值存在上场那位的配置里）

- `articulation.pedal?: "auto" | "down" | "up"`——user 定的三格：自动 / 默认踩着 / 默认不踩。
- `articulation.softVel?` / `softDb?`：弱音踏板轻多少（数由施工起、写明是谁起的，user 的耳朵定）。
- **没写这个键 = 不踩**（统筹定）：已经存在的歌，声音一个样本都不变；**新上场的乐手写明「自动」**。旧的乐手在乐器页能改成自动。依据是连断那一轮的做法（底色没写 = 0 = 旧歌不变）；这不是念旧——以前的做法不违反规范，只是没有这个默认。
- 「自动」落在哪一边 = 乐器目录里新的一栏（见第 9 节）。目录里没有这一栏的乐器、自己的音源文件 = 不踩。

### 4.3 「键按多久」（纯函数，放和导出共用同一张音符表）

输入：音符表（写的起止，已经过跳音 / 缝 / 呼吸）、这一段的踏板记号时刻表、乐手的默认（已经落成踩着 / 不踩）。输出：每个音真正松开的时刻、每个音的力度修正。

| 规矩 | 内容 | 谁定的 |
|---|---|---|
| 一 | **默认 = 每一段开头延音踏板的状态**（踩着 / 不踩）。之后谱上写了什么就是什么：踩下 → 踩着；抬起 → 不踩；换踏板 → 这一刻留着的音全松、接着踩着。一直管到这一段结束；下一段开头回到默认 | user（「写了延音踏板之后就无视默认，按用户的来」）；读成「开头的状态 + 之后照记号」是统筹的读法：写在第 9 小节的记号不会改第 1–8 小节的声音 |
| 二 | 延音踩着期间，音到了写的结尾不松，等到抬起 / 换踏板那一刻才松。那一刻键还按着的音不受影响，接着被新的一脚兜住 | 规范 |
| 三 | 被踏板留着的音，同一个音高又弹一次：旧的在那一刻松，照乐器自己的收尾收 | 统筹（照常见播放器的做法，也是真弦的样子） |
| 四 | 持音：踩下那一刻正按着的音被留住，到持音抬起才松；之后弹的音不归它管 | 规范 |
| 五 | 弱音：踩着期间起的音变轻（按力度敲的减力度，按音量曲线的减 dB）。只变轻；音色除了换到更轻的录音层之外不变，乐器页照实说 | 统筹 |
| 六 | 默认踩着 = 这一段一开头就踩着，没人写记号就一直踩到段尾：规矩二、三；另外**靠默认踩着的那一截里，跳音照写的松**（不写记号也有一个止音的办法；用户自己写的「踩下」之后照规范，跳音也被留住）；同时留着的音超过一个数，先松最早的（数由施工定，写进乐器页的说明） | 统筹 |
| 七 | 纸尾所有踏板抬起；上一张纸的尾巴照乐器自己的收尾响 | 统筹 |

- 谁认：按键盘发音的乐手（SoundFont）三种都认；小月相、元音版不认 → 记号画灰、明说（老规矩）。
- 按键试听不跟踏板（照旧只响那一下）。真 MIDI 键盘上的踏板是另一件事（愿望单 W-41）。

## 5. 画

- 延音：开头「Ped.」，后面一条线到抬起处，抬起处一个钩；换踏板 = 线上一个尖。持音：「Sost.」同样的线。弱音：施工出两种样子的图给统筹挑（「una corda … tre corde」两处字；或者「U.C.」加同样的线）。
- 位置：这一位最下面那条谱的下面，最外一道。简谱、字母谱同样在行的下面。
- 记号表里每种谱一栏；不相撞检查带上这一道；「显示 = 全量」：每个记号都画出东西来。
- 页面设置「演奏法和表情：不显示」时踏板算不算在内：算（它是表情）。提示和计数跟着。

## 6. 输入

- 键盘符号层「记号」页一个「踏板」键 → 小菜单，三种踏板各一行，字跟着光标处的状态（**算上默认**）：没踩 = 「踩下」；踩着 = 「抬起」「换踏板」。
- 菜单里的字带上效果，不让人去想踏板的机械（user：「我觉得有些乐器反而是你踩下去才是让它停吧」——扬琴的止音踏板就是反的）：「踩下（留住音）」「抬起（止音）」「换踏板（先止音、接着留）」。我们存的、说的都是「留不留住音」这个效果，不是哪件乐器的踏板往哪边踩。
- 有选区 = 「把这一段踩住」：头上踩下、尾上抬起。
- 点谱上的踏板记号 = 小菜单（换 / 删）；长按拖 = 挪；符号退格删。踩下和抬起之间一个音都没有 = 湮灭，说一声。
- 写了不起作用的记号（比如这位默认踩着，又写了一个踩下）：画灰，写上的那一下说一句为什么。

## 7. 乐器页

- 「延音踏板（没写踏板记号时）」三格：自动 / 默认踩着 / 默认不踩。自动后面写出这件乐器落在哪一边、依据是什么（目录里那一栏的原话）。
- 「弱音踏板轻多少」一行。
- 按住不会自己衰减的乐器（风琴、弦乐）选「默认踩着」：不拦，写明后果（每个音一直响到同一个音再弹或这一段结束）。
- 「记号怎么演」那张表加三行踏板。

## 8. 文件

- MusicXML：延音 `<pedal type="start|stop|change" line="yes" sign="yes">`；持音用 `type="sostenuto"` 起、`stop` 止，和延音用 `number` 分开；弱音 = 文字加 `<sound soft-pedal="yes|no"/>`。自己读回来靠 id 认。别的软件写的 `<pedal>` 读进来变成我们的记号；读不了的照旧数出来报给人。
- 版本：谱这一块 minor +1（老版本打开会提示一次；老版本存一次踏板就没了，音不丢——写进契约的注释）；休息室 minor +1（两个可选的键）。冻结样本各一份。形状快照更新。
- 渲染缓存：出声变了的只有用到踏板或默认踩着的歌，指纹本来就看谱和休息室，不用另管；施工确认一遍。

## 9. 「自动」的名单：要音乐目录多一栏

- user 定的：钢琴不默认踩着。
- 其余的判据（统筹的提法，user 说「其他的你可以想一下」）：看这件乐器**不去管它的时候**是什么样。拨了、敲了之后自己一直响、要人去止才停的 = 踩着（筝、竖琴、扬琴、钟琴、管钟…；扬琴的踏板是踩下去止音，正好说明它平时是响着的）；平时是止住的、要踩踏板或一直按着才响的 = 不踩（钢琴、电钢、颤音琴）；按住不会自己衰减的（风琴、弦乐、管乐）= 不踩。吉他这类两可的由目录那边判、写明依据。
- 数据归音乐目录那边出，app 里不写死名单。工单 = `ai-docs/20261112-hamster-workorder-pedal-default.md`。
- 没到货之前：自动一律落在「不踩」，乐器页照实写「目录里还没有这一栏」。

## 10. 怎么切

- **11-0 侦察（只读，交切线表给统筹）**：现在读到带 `<pedal>` 的 MusicXML 做什么；正式版打开带踏板的歌再存会怎样；音符表到引擎那一路「松开」是怎么发的、规矩三要不要引擎配合；「挂在一段结尾的记号」「一段范围的记号」现成的做法哪些能照用；默认踩着时同时留着的音最多会到多少（拿 user 的歌和一段快的琶音算）。
- **11-1 延音踏板全链路**：数据、键按多久、放、画、输入、MusicXML、版本、冻结样本。
- **11-2 持音、弱音**。
- **11-3 乐手的默认三格 + 自动（吃目录那一栏）+ 同时留着的上限**。
- 每刀交付 = 开发版 + 真 app 的图 + 测试清单；样子的事出图给统筹，统筹推给 user。

## 11. 测试的判据

- 「踩着踏板弹短音」和「把这些音的键一直按到踏板抬起」渲出来逐样本一样（今天验尾音用的叠加办法）。
- 换踏板那一刻松的是哪些音；持音只留踩下那一刻按着的；弱音只管踩着期间起的音。
- 默认：每一段开头的状态 = 默认；写了抬起之后就是不踩、一直到段尾；下一段开头回到默认；默认踩着时又写踩下 = 画灰、出声不变。
- 默认踩着的那一截：同音再弹松旧的；跳音照写的松；到上限松最早的。
- 没写 `pedal` 键的旧歌：逐样本不变（拿冻结的歌比）。
- MusicXML 往返、别家的 `<pedal>`、冻结样本、不相撞检查、「显示 = 全量」的守卫。

## 12. 不做

- 半踏板、踏板踩多深。
- 替人换踏板（按和声猜什么时候换）。user 的规矩：自动只许拦，不许替人管。
- 真 MIDI 键盘上的踏板（W-41）。
