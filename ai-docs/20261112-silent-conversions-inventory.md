## 判据

user：「如果你只有这个文件，没有我们的程序，你能不能成功的把整个音频给复现出来？」

现在的答案：**不能。** 缺的东西在第三、第四节。

user 随后把它分成了两层（同一晚）：「当然，这个是理想情况…关键就是说，如果我们这个程序没了，你通过文件的语义能知道这个东西有多小，而不是说你要复现的话，你必须要得到我们这个程序的源代码去看里面那有一个减六，这个是我无法接受的。」

- **底线**：文件里的数就是它写的意思；不许要人翻源代码才发现程序里还藏着一个数在改它。第三节里影响出声的那几组，和第四节里是「一个数、一张表」的那几样（小月相的块乘多少、力度深度、拍子轻重的表、鼓的着力点、限幅器的天花板），属于这一层。
- **理想**：只有文件就能复现声音。第四节里是「算法」的那几样（怎么唱、怎么合成、效果器的公式、声像怎么算）属于这一层：在程序里可以，文件里记下是哪一版、依据哪个标准。

## 二、开文件时顺手改的（不在升级链里）

静默的：

- 老歌里的句号记号：读到就丢掉。
- 退役的键读到不理、再存不带：乐谱 PDF 的字体「拼音」、句号的表、声部上的自动八度线开关。
- 老写法的「声部默认谱号」→ 每一段纸头各补一个谱号；没写谱号的老歌 → 当自动。
- 合租一家的先后重排（房客挪到主人后面）。
- 合租的主人不在、挂自己、主人也是房客 → 这层关系丢掉。
- 音的编号整首重编。
- 「1=」只写了调式的旧歌 → 当手动。
- 读第 1 版的文件（包里没有每张纸的谱）→ 把压平的那一份当成一张纸。
- 老文件里带着的 mp3（退役的定稿）→ 搬进这台设备的渲染缓存、不写回；记录不像样 = 当它不存在。

说了一声的（提示条，不是对话框）：

- 每张纸开头没写力度 → 补一个当时生效的，提示条说补了几个。
- 两个声部共用一个角色 → 后面那个拆成一位新歌手。
- 别家的谱里读不了的方向记号：按种类数出来。

## 三、「没写 = 程序里的默认」

影响出声的：

- 乐手的响度没写 = −6（施工单第 14 条要拿掉）。
- 乐手的力度没写 = 0.8。
- 力度表 pp…ff 没写 = 默认表；ppp、fff 没写 = 按这位自己的间隔往外推一档。
- 演奏法那一组数（重音多久、呼吸收多少、缝最多吃多少…）没写 = 默认表；小月相的「记号怎么唱」没写 = 默认表。
- 小月相唱法核心的旋钮没写 = 默认表。
- 分段唱没写 = 每句；移调没写 = 0；音和音之间的缝没写 = 0。
- 总轨没写 = 0 dB、限幅开、空链；插件的开关没写 = 开；混音轨旁通只写「开」。
- 编排没写 = 每张没藏的纸各放一遍。

只影响画面的：谱上的字的语言、小节号、歌词怎么排、版式、排法、视图里的一串——都是「只写不是默认的那一种」。

## 四、文件里根本没有、只在程序里的

- 小月相唱出来的块乘 0.89 ÷ 0.42。
- 小月相、元音版的力度深度 800。（11-12 统筹定的「不进歌的文件」，按这条规矩是定错了。）
- 力度 → 响度的公式：是 SoundFont 规范，但文件里没写依据的是哪个标准。
- 限幅器：天花板 0.98、提前看多久、起落多快。
- 声像怎么算（等功率）。
- 拍子轻重的风格：文件里只有风格的名字和幅度，每一拍多重的那张表在程序里；摇摆的比例同样。
- 鼓的着力点（提前多少秒开始放）：在音乐目录里，不进歌。
- 效果器：文件里是参数，公式在程序里；「自动低切」「按拍子的延迟」两个参数是程序现算的。
- 小月相怎么唱（唱法核心的算法）、元音表：文件里只记了渲染核心的版本和哈希、模型包的哈希。
- SoundFont 合成器的实现（打过补丁的 TinySoundFont）。
- 只影响画面的自动画法：自动谱号、自动八度线、合租怎么叠。
