## 1. 听的人凭什么觉得「小 / 嫩 / 像小孩说话」（原理，从主到次）

1. **共振峰高**：声道越短共振峰越高，Fₙ ≈ (2n−1)·c / 4L（成年女性 L ≈ 14.5 cm，小孩 10–12 cm → 高 20–40%）。耳朵靠它判断身体大小。
2. **基频高**：单独高不显嫩（花腔女高音不奶），要和 1 一起。
3. **嗓子软、带气**：声带闭不严 → 第一谐波比第二谐波强很多、高频掉得快（频谱倾斜陡）→ 甜、软、贴耳。
4. **咬字（可懂度）**——user 说的「拖粘」在这一条：
   - 高频那一半：齿音（s / sh / ts）的能量在 4–10 kHz，弱了 = 大舌头。
   - **时间那一半（更像 user 描述的）**：大人说话辅音短而利（爆破 5–20 ms、擦音几十 ms）、辅音→元音的共振峰滑动快（30–60 ms）、下一个字的口型在上一个字尾巴里就开始了（协同发音）、字有轻有重。小孩：滑动慢、辅音含糊、**每个字一样重、一个字一个字蹦**、**丢音拍（だんご → だご）**。唱歌合成天生有这个风险：元音要拉长到音符那么长，过渡段跟着被拉、辅音被挤、字字被拉成一样响，就是这个效果。
5. **唱高了元音会糊**：基频高过元音的第一共振峰（い う ≈ 300–400 Hz，あ ≈ 800–1000 Hz），那一段没有谐波，元音只能靠第二共振峰认 → 像小孩含糊的发音。真人歌手唱到那儿也会改元音。

- **丢音拍**：写成「だ ご」（没有 ん）15 处、「だ ん ご」16 处；「だ か ぞ く」（没有 い）4 处、「だ い か ぞ く」0 处；一个音上两个字的「‿」一次没用。丢音拍是小孩说话的典型特征；如果是为了对上音符数才丢的，「だ‿ん」「だ‿い」写在一个音上（唱法按平均分那个音，`src/score/lab-score.ts` ELISION）就能唱回来。**歌是 user 的，AI 不改歌文件。**
- 同一个字一遍遍重复（だ ご だ ご …）+ 下面的 `level`（字字往中位数拉）= 每遍唱得一模一样。

## 4. 唱法里管第 4 条的旋钮（`sing-core.mjs DEFAULT_OPT`，现在都是默认值、编辑器里没露）

| 旋钮 | 默认 | 管什么 |
|---|---|---|
| `attack` | 0.06 s | 元音开头原样拷贝、不拉伸的那一截（= 辅音→元音的过渡） |
| `tailIntoNext` | 0.04 s | 元音尾巴原样带进下一个辅音（协同发音） |
| `consonantCap` | 0.5 | 辅音最多占前一个音的一半（快音时辅音被挤） |
| `level` / `levelMaxDb` | 0.8 / 6 | 每个字的响度往全曲中位数拉 80%（字字一样重） |
| `portamentoMs` | 40 | 两个音之间音高滑多宽 |
| `breath` | 0 | 每个元音都换成最干净（不带气）的那几帧 |
| `vowelFrames` | [8, 16] | 元音取 piper 自己长度的 2 倍、夹在这个范围（帧 = 11.6 ms） |
| 元音图谱 `atlas` | 关 | 开了 = 元音颜色换成图谱里的标准元音（user 10-06「元音图谱一般般，先不做」） |
