## R. 第 2 版：user 11-07 拍了什么（以这一节为准；下面 §0–§7 是第 1 版的格子提案，留着当来历）

- **不做格子**：「我还是想显示的时候按照五线谱显示，就是我们有五线谱、简谱和钢琴格三种显示模式，以后都那么做」「我们都说了是一起显示，所以就没有格子这个选项了。就是如果非要做格子的话，最好也是能跟五线谱对齐」。→ 鼓照旧在（鼓）五线谱上看、在谱上改。
- **编辑 = 绝对位置，数据照旧相对时长**：「数据结构上面我们还是相对时长，但是逻辑上面我们是这个绝对的位置的记录」。读法（Claude Opus 5.5）：鼓的声部「只盖不推」——在某个位置敲一下 = 把那里的休止换成一下；删掉一下 = 留下一样长的休止；后面一个都不挪。和 10-10 旋律那次不冲突：当时否的是「每个音按绝对位置存」（「beats the whole idea」），拍的是「输入会默认覆盖休止空间…只有没有休止空间时才会推后面的」；这次数据不改，只是鼓的声部在「盖」这条路上走到底。
- **一对乐器 = 一条轨占两行**：「我其实比较想这样」；**两行各自能配音高**：「最好是你能配置两行的音高…有时候我想把音高给对一下」。
- **多响 = 现成的几档**（幽灵音 / 弱 / 普通 / 次重 / 重…），「不用连续的力度，我们现在五档够了」。
- **不做 pattern，复制粘贴**；愿望单「刷 pattern」（选几条鼓轨、按小节为单位复制粘贴，不编程）见 wishlist W-47。
- **导出成标准鼓谱：做**。user 问「它能认得出来哪个是哪个乐器吗」——认得出：MusicXML 里每件鼓单独登记成一件乐器（带 GM 鼓号，`<midi-unpitched>`），每个音标「哪件乐器 / 画在哪一线（`<unpitched>`）/ 什么符头」；MuseScore 按 GM 鼓号对到自己的鼓组。
- **滚奏 = 只管密度，不发明力度曲线**：user「现实中常识里的滚奏它是从零开始的还是从什么时候开始的？…如果是从零开始的话…你就不需要发明额外的记号和数据结构」。答：现实里滚奏不从零开始，是在当时生效的力度上一直敲；变化用普通的渐强 / 渐到写（「pp 滚奏渐强到 ff」）；真要从无声起，乐谱上有「从无声起」（niente）的写法——最多给力度记号加一档「无声（n）」。所以：滚奏记号 = 长音 + 斜线 + 密度（每秒几下），起点 = 那时生效的力度，终点 = 后面的力度记号，中间走已有的渐强 / 渐到。

### R2. 还要 user 拍的一问：在五线谱上怎么点到「第几拍 / 第几个小拍」

user 11-07「我们选择第几拍或者第几个小拍在它这里插入，就这个功能怎么做？…很多拍子会合成一个大的休止符里面，你就没法选了」。

- **A. 休止符里面也能放光标（推荐）**：鼓的声部上点进一个大休止，按点的横向位置、对齐到当前时值档放光标（「这个休止里的第几格」）；敲一下 = 自动拆开休止（前一段休止 + 这一下 + 后一段休止），后面不挪；显示上休止照拍号规矩合并 / 拆分。= 已有的「点空小节写到那里」推广到所有休止。
- **B. 谱下面一排很淡的小点**，一个点 = 一格（按拍号和时值档），点哪个点光标去哪——「和五线谱对齐的格子」。
- **C. 左右键在鼓的声部上按时值档一格一格走**（不一下跳过整个大休止）。
- 建议 A + C，B 等需要时再加。

### R3. 旋律「相对」、鼓「绝对」会不会让人晕（user 11-07 提的担忧，待拍）

user：「如果鼓谱长得和五线谱一样的话，你五线谱是相对位置编辑，鼓谱是绝对位置编辑，会不会让用户头很晕？你能不能帮我好好考古一下，当时我们为什么要拍相对位置编辑？然后我们再非常辩证批判的想一下」。

**考古（user 原话）**：08-18「起名哲学就是nokia的彩铃编辑器，我觉得这个比daw要干净许多」；10-06「一串token，拍」「bar是你人工插的token，而不是定好的护栏」「token还有一个好处是咿咿呀呀的时候不用管时值，之后可以调，而且一个时值判错了改的时候后面自动适应」；10-10 否决「每个音按绝对位置存」（「beats the whole idea」）→「输入会默认覆盖休止空间…只有没有休止空间时才会推后面的」。现在旋律的规矩 = 大部分时候盖、没地方才推（写音先吃休止；退格音 → 一样长的休止）；还会推的只剩：写音后面没休止、写休止后面是音、退格删休止（合拢）、Delete、改时值、粘贴。

**正反（Claude Opus 5.5）**：鼓的位置就是意思，「后面自动适应」对鼓是坏处；但同样长得像五线谱、规矩却不一样 = 「看起来一样、行为不一样」，撞「不静默、不潜规则」。参照（据 AI 所知，未逐条核）：MuseScore 写音默认覆盖、插入要专门操作；Dorico 有「插入模式」开关。

**选项**：A（推荐）「插入 / 覆盖」做成看得见的模式（光标样子不同、模式条上能切），旋律默认插入（现规矩）、鼓默认覆盖；B 全统一成现在旋律那套（鼓也没地方才推）；C 全统一成覆盖（等于推翻 10-10 的拍板，不建议）。补充：鼓的键盘本来就换成鼓名 = 另一处看得见的提示；R2 的「点进休止里放光标」对旋律一样有用，不做成鼓专用。

## 1. 现在别扭在哪（上次没做完的）

1. **写鼓要背号**：鼓也走旋律的音键，按下的音高 = GM 鼓号（36 大鼓、38 军鼓、42 踩镲……），键上写的是简谱数字。
2. **一对乐器拆两条轨**：木鱼高 / 低、邦哥高 / 低、康加、阿哥哥铃，只能各一条轨再合租。
3. **滚奏 = 一串三十二分音符**（已拍改成滚奏记号，见 §4）。
4. **固定敲一件的乐器不能调音**（邦哥调到哪个音）。
5. **导出给别的软件**：MusicXML 里鼓照有音高的乐器写，MuseScore 读进去是一堆音高，不是鼓。
6. 从反向镲那一拍中间起放，会从采样开头放（晚 1.4 秒）。

## 2. FL 的格子是什么（科普）

FL Studio 的 Channel Rack：**一行 = 一个声音**（大鼓、军鼓、踩镲……），**一列 = 一格时间**（默认十六分音符，一小节 16 格），格子点亮 = 这一格敲一下。每行下面可以拉开一条力度条（每一下多响）。一小段节奏叫 pattern，在 playlist 里摆来摆去、重复。好处：节奏一眼看得见（是「形状」），写鼓快，不用懂鼓谱。

## 3. 提案：谱照旧是谱，鼓的「键盘」换成格子

**核心一句话：数据一点不变**——谱上还是一串音符（存档照旧是 MusicXML + 现在的格式），格子只是同一份数据的另一种编辑方式（像钢琴卷帘之于五线谱）。所以不改存档格式、不和谱打架、撤销照旧、别的软件照样能读谱。

1. **在哪**：光标在鼓的声部上（台上是鼓组 / 鼓件 / 固定敲一件的音效）时，底座的键盘换成格子——和「音 / 符」两面键盘一样，是键盘的另一面；不是鼓的声部照旧是音键。合租的一家鼓 = 格子里一家人一起排（这就是 FL 的 Channel Rack）。
2. **行**：一行 = 一件鼓（一个鼓键）。行头写谱上名 / 简写，点行头 = 试听那一下。行的上下顺序 = 鼓谱上的高低（和 v0.16.4 的名字顺序一致：踩镲在上、大鼓在下）。一位演奏者可以占几行（§4.1 一对乐器）。
3. **列**：**按拍号自动分**：4/4 = 16 格（每拍 4 格）、3/4 = 12 格（每拍 4 格）、6/8 = 12 格（分两组、每组 6 格）；每拍之间粗一点的线。分辨率能换：八分 / 十六分 / 三十二分 / 三连音。一屏显示光标所在的那一小节（或两小节，见 Q5），左右翻小节，跟着光标走；放的时候有一根走带的竖线。
4. **点格子**：点 = 这一格敲一下；再点 = 去掉。
5. **多响（力度）**：见 Q3。
6. **滚奏**：一格按住往右拖 = 一个长音 + 滚奏记号（§4.3）。
7. **重复**：一键「把这一小节铺满这张纸」（FL 的 pattern 重复）；整段整段的重复用已有的反复记号 / 编排 ×N（见 Q4）。
8. **写进谱的规矩**（格子 → 音符）：同一格几件鼓同时敲（同一位演奏者）= 一个和弦；合租时各回各的轨。两下之间空着 = 自动补休止、合并成整齐的时值（鼓的时值本来没意义，按拍子写整齐）。**不在格子上的音**（十六分格子里写的三连音）：格子上画一个半透明的记号，点它跳到谱上去改——格子不改它。
9. **谱**：鼓谱照旧（五线鼓谱 / 一线谱），格子只管输入。

## 4. 一起解决的

1. **一对乐器一条轨**：「谁来演」除了「整套鼓」「固定敲一件」，多一种「鼓组里的这几件」（木鱼高 + 低、邦哥高 + 低）。格子里它占两行；谱上 = 它这几件在鼓谱上的线（五线鼓谱，或者按 MuseScore 的两线谱）。目录里「木鱼」这一类直接给出这一对（仓鼠出数据：哪些键是一对）。
2. **调音**：固定敲一件 / 一对乐器加一个「调音」设置（± 半音，可以细到音分），只改出声，谱上的位置不动。
3. **滚奏（已拍 A + 密度）**：长音 + 符干上的斜线 = 滚奏；放的时候按密度（每秒几下）敲满，每一下的力度单独跟着渐强 / 渐弱 / 渐到走；密度是演奏者设置（军鼓、定音鼓、吊钹各自默认），能调。MusicXML 存成标准的颤音记号（别的软件认得）。**待确认**：「开始强度其实就是0」= 滚奏渐强默认从无声起、不用先写一个 ppp？
4. **导出给别的软件**（Q6）：MusicXML 里鼓写成「不分音高」的标准写法（`<unpitched>` + 每件鼓一个乐器），MuseScore 读进去就是鼓谱。只动导出，不动存档。

## 5. 要你拍的（一次问齐）

- **Q1 格子放在哪**：A 光标在鼓上时底座的键盘自动换成格子（推荐：和现在「键盘跟着声部变」一个逻辑，谱留在上面看得见）/ B 全屏一页（像混音台，一屏看得多，但看不到谱）/ C 两个都要（底座 + 能拉成全屏）。
- **Q2 一对乐器**：一条轨两行（推荐，乐手就是一个人敲一对）/ 照旧一件一条轨、靠合租排在一起（每件单独调音量 / 效果方便）。
- **Q3 多响**：A 三档 = 轻（幽灵音）/ 普通 / 重（重音），点一下普通、再长按或上下拖换档（推荐：和谱上已有的记号是同一份，别的软件也认）/ B FL 那样每一下一个连续的力度条（细，但要新加数据、谱上表达不出来）。
- **Q4 重复**：用现有的曲段 + 反复记号 + 编排 ×N（推荐，不新造东西）/ 做 FL 那样的 pattern（新的数据结构，要格式改动）。
- **Q5 一屏几小节**：一小节 / 两小节 / 跟屏幕宽度自动。
- **Q6 导出成标准鼓谱**（别的软件认成鼓）这一轮要不要一起做。
- **Q7 滚奏**：「开始强度是 0」是不是「默认从无声开始渐强」。

## 6. 这一轮不做

- 旋律的输入方式不动（旋律照旧谱 + 音键，不走 FL）。
- 摇摆、人性化（随机偏一点）：已有风格记号的摇摆，格子先不加别的。
- 反向镲从中间起放（§1 第 6 条）：单独一件小事，排在后面。

## 7. 大概分几版做（拍了以后）

1. 格子本身（行 = 鼓键、列按拍号、点 = 敲、写进谱的规矩、播放竖线）。
2. 力度档 + 铺满这张纸。
3. 一对乐器（要仓鼠出「哪些键是一对」）+ 调音。
4. 滚奏记号 + 密度。
5. 导出成标准鼓谱（如果 Q6 要）。
