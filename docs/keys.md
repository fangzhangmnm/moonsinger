# 键盘

> 生成自 `src/input/keys.ts`

谱面上有三种状态：**写**（光标，打的音插在光标处）、**改**（选中了一段，打的音覆盖选中）、**弹**（「弹」开着：音符键只唱不写，其余键照写 / 改）。
按物理键位认（换输入法 / 键盘布局不乱）；Ctrl / ⌘ 组合只接存 / 另存为 / 打开，其余交给浏览器。

## 写音

| 键 | 写 | 改 | 弹 |
|---|---|---|---|
| `1–7（小键盘也行）` | 写一个音：调里第几级，落在离上一个音最近处 | 把选中的第一个音改成这一级，选中跳到下一个音 | 只唱不写 |
| `Shift+1–7` | 同上，往上找 | 同上，往上找 | 只唱不写（往上找） |
| `Q W E R T Y U` | 同上，往下找（数字正下方那一排） | 同上，往下找 | 只唱不写（往下找） |
| `0 / 小键盘 0` | 休止 | — | 照常 |
| `Enter / \|` | 小节线 | 在选中后面插小节线 | 照常 |

## 歌词框

| 键 | 做什么 |
|---|---|
| `Esc` | 收起，不贴框里的字 |
| `退格` | 框是空的：回到上一个音，把它的字拿出来接着删 |
| `Ctrl / ⌘+S` | 存 |
| `Ctrl / ⌘+Shift+S` | 另存为… |
| `Ctrl / ⌘+O` | 打开… |
| `空格 / Tab` | 这个词完了：贴上、跳下一个音（框是空的 = 只跳） |

| `Enter / 小键盘 Enter` | 贴上、收起 |
